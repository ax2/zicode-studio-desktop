# 工作台历史研究摘录

这些材料来自早期工作区，供查阅和移植。发行行为以产品分支和对应版本的公开验收记录为准。

## 复用内容

- coexistence 包含浏览器和视觉导入同时运行的统计与资产校验器。用同一设备和窗口对照空载、导入期间的首屏、换页、面板开关、内存与解码进程采样；验证原件和入库资产摘要。示例策略保留历史数值门限，冻结时间、测试机器、宽窄窗口与样本清单摘要由新的测试环境独立填写。将示例复制为同目录的 browser-coexistence-gates.json，再以 Bun 运行 verify-browser-coexistence.mjs，传入该次合成测试的 manifest.json。原始机器清单、样本和运行收据均由执行方单独管理。
- tool-tabs 保留目录与单个工具的两种图标及旧版标签栏的调用差异。适配时沿用当前产品的键盘导航、缩放和本地化。
- regressions 保存两项可移植回归用例。模型端点身份须区分协议路径、模型、提供方和认证模式，并等价处理尾部斜线及展示名变化；测试使用本地占位端点。工具导航应同时确保浏览器默认优先、视觉素材库与笔记均可发现。

## 从旧需求和验收中保留的检查方法

- 浏览器交互围绕收藏、下载、原生弹窗、页面快捷键、焦点和导航后的状态保持展开。在宽窄窗口分别核对页面内容、正在编辑的输入、滚动位置及键盘返回目标。历史快捷键和实现状态查相应正式版本。
- 视觉创作先明确输入角色与授权范围：换装分别指定人物和服饰，风格迁移分别指定内容与风格；文生图、图生图按模型实际支持的尺寸和格式核对。生成后预览、选择、存档，在任务终止、换页和重启后检查来源链和原件。游戏导出另用固定引擎版本和可重复导入工程验证；动图另查帧序、时长和产出格式。
- 工具和翻译入口同时核对搜索与直接启动、取消、重试、权限撤销、慢响应、最近使用顺序，以及结果显式保存至笔记或产物时的归属。升级测试分别记录进程退出、安装是否成功以及前后内容核验。

## 范围

此分支以公开 v0.7.0 为基线，仅在本目录添加研究材料。旧版本号、发行工作流实验、整份需求台账、已过期的完成状态、本地操作指令、机器信息、原始运行证据和构建生成物均从摘录中排除。
