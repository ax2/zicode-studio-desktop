# 场景与隔离

场景决定 Agent 的系统指令、工具边界、模型渠道和本地数据目录。

## 当前会话场景

聊天标题区域显示当前会话实际绑定的场景。设置页中的“Current session”必须与这里一致。

当前会话创建后，改变“新会话场景”不会迁移或重启当前会话。

## 新会话场景

“设置 → 常规 → 新会话场景”保存的是下一个新会话的默认选择。它和当前会话场景是两个独立状态。

## 配置隔离

每个场景有独立的：

- API Key；
- `models.json` 与模型可见性；
- Agent 设置；
- 会话与运行数据；
- 场景允许使用的工具。

如果 Finance 场景配置了 QVeris Key，Programming 场景不会自动继承。
