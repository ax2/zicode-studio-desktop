# 场景与隔离

场景决定 Agent 的系统指令、工具边界、模型渠道和本地数据目录。

## 当前会话场景

聊天标题区域显示当前会话实际绑定的场景。设置页中的“Current session”必须与这里一致。

当前会话创建后，改变“新会话场景”不会迁移或重启当前会话。

## 新会话场景

“设置 → 常规 → 新会话场景”保存的是下一个新会话的默认选择。它和当前会话场景是两个独立状态。

## 配置隔离

每个场景有独立的：

- API Key；
- `models.json` 与模型可见性；
- Agent 设置；
- 场景允许使用的工具。

如果 Finance 场景配置了 QVeris Key，Programming 场景不会自动继承。

## 工作区数据与系统配置

场景负责模型与 Agent 配置；**数据按工作区隔离**，而不是按场景：

- 会话、笔记、任务、自动化、金融研究与产物分别存放在
  `<工作区>/.zicode/{sessions,notes,tasks,automation,finance,artifacts}/`，
  切换工作区即切换对应数据；旧版本保存在应用数据目录中的数据会在首次
  启动时一次性迁移；
- 系统级配置（模型/Agent 配置、场景档案、远程访问、凭据索引、工作区
  元数据）统一存放在 `~/.zicode`；Pi 的命令配置不再写入 `~/.pi`；
- 应用数据目录（运行实例、日志、WebView 数据）保留在系统应用数据
  目录，不进入工作区。
