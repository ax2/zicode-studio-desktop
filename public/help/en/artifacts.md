# Artifacts

Artifacts keeps reports, datasets, and files generated by Finance and other plugins in one library. It behaves like every other application: navigation and filters use the function area, while content uses the main view.

## Find and inspect

- Search titles, summaries, types, and source plugins.
- Filter reports, charts, datasets, or files.
- Inspect content, provenance, creation time, format, and size.

The visible **Search artifacts** label remains after typing. On phones, Export and Delete use equal-width
buttons; creation time, format, size, and resource handle stack vertically so a long handle does not squeeze
its field name.

## Resource handles

An `artifact:<id>` handle contains no local file path. Applications and conversations can refer to it without copying a large object or exposing the data directory.

## Export and delete

Export creates a readable `.zicode-artifact.json` document containing both content and provenance. Delete uses optimistic version checking; a changed artifact must be reloaded instead of being overwritten.

## Scene isolation

Artifacts are isolated by the active scene. Finance artifacts do not appear in another scene. The Host rejects reads and writes when Artifacts is disabled or its storage permission is revoked.
