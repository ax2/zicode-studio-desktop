# Habit Tracker

Habit Tracker keeps a streak and history for daily habits and metrics —
useful for check-ins and weekly reviews.

## How to use

1. Click "Add habit", enter a name, and pick an emoji icon and color.
2. Tap the habit card each day you complete it; consecutive days build a streak.
3. Use the week view to move between weeks and review daily completion.
4. Unneeded habits can be deleted (with history, after a confirmation).

## Notes

- Check-ins are stored in the current workspace's local data and included in
  workspace backups.
- Streaks follow calendar days; missing a day resets the streak.
- There is a habit count limit; remove an old habit before adding more.
