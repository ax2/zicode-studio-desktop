# Image Tools

Resize, convert, rotate, or flip a single image, or arrange several images into a grid.

## How to use

1. Choose or drop one or more images (JPG / PNG / WEBP).
2. Configure the options:
   - Resize: contain / cover / stretch with a target size;
   - Format and quality: convert the output format and adjust compression;
   - Rotate / flip: by angle or horizontally/vertically;
   - Concat grid: set columns, gap, and layout for multiple images.
3. Click "Process" and review the preview.
4. Download the result or open it in a new tab.

## Output

The result shows the new dimensions, format, and size (for example
192×192 · PNG · 20.3 KB) so you can confirm it matches expectations.
