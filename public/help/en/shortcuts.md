# Keyboard shortcuts

## Conversation

- `/` focuses the composer when focus is elsewhere.
- `Enter` sends or steers.
- `Alt+Enter` queues a follow-up.
- `Escape` aborts the current run.

## Commands

Open the Command Palette from the navigation rail to run application and plugin commands. Command-only plugins do not need their own navigation button.

## Navigation

Use the left navigation rail to switch applications. The adjacent function area changes with the selected application while the main view shows its content.
