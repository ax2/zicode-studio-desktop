# Keyboard shortcuts

## Conversation

- `/` focuses the composer when focus is elsewhere.
- `Enter` sends or steers.
- `Alt+Enter` queues a follow-up.
- `Escape` aborts the current run.

## Commands

Open the Command Palette with `Ctrl+Shift+P` (or the command button next to the composer) to run application and plugin commands. Command-only plugins do not need their own navigation button.

## Search

- `Ctrl+K` opens session search from anywhere (the sidebar search box also works).

## Notes

- `Ctrl+S` saves the current note while the notes editor is focused.

## Navigation

Use the left navigation rail to switch applications. The adjacent function area changes with the selected application while the main view shows its content.
