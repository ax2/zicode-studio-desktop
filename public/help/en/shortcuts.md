# Keyboard shortcuts

## Conversation

- `/` focuses the composer when focus is elsewhere.
- `Enter` sends or steers.
- `Alt+Enter` queues a follow-up.
- `Escape` aborts the current run.
- `Ctrl+M` switches the model (model dropdown next to the composer).
- `Ctrl+T` cycles thinking effort (the "Think" tag next to the composer).
- `Ctrl+1` through `Ctrl+9` switch applications by activity-bar order.

## Commands

Open the Command Palette with `Ctrl+Shift+P` (or the command button next to the composer) to run application and plugin commands. Command-only plugins do not need their own navigation button.

Common palette commands include **New session**, **Switch workspace**,
**Compact** (compress the current conversation's context), and
expand/collapse-all tool actions.

## Slash commands

Type `/` in the composer to see and pick commands. Common slash commands:

| Command | Action |
| --- | --- |
| `/new` | Start a new conversation |
| `/settings` | Open Settings |
| `/help` | Show composer shortcuts |
| `/files` | Open the file browser |
| `/memory` | Extract memory from the current conversation (also available as a welcome-page action) |
| `/mode` | Cycle work mode (Ask / Craft / Plan) |

## Workspaces

- Open a folder as a workspace: click the workspace name in the workspace bar.
- Switch workspace: use the workspace bar "Switch workspace" button or the
  palette command; the current window switches in place and keeps the active
  application.
- Session/project "more" actions are reachable from the inline ⋮ button
  (focus with Tab, activate with Enter/Space).

## Search

- `Ctrl+K` opens session search from anywhere (the sidebar search box also works).

## Notes

- `Ctrl+S` saves the current note while the notes editor is focused.
- `Ctrl+N` creates a new note.
- `Ctrl+E` toggles edit/preview.
- `Ctrl+Shift+D` downloads Markdown.
- `Ctrl+Shift+C` copies Markdown.
- `Ctrl+D` creates a copy.
- `Ctrl+Enter` brings the selection or whole note into chat.
- `Ctrl+Shift+T` opens the trash.

## Navigation

Use the left navigation rail to switch applications. The adjacent function area changes with the selected application while the main view shows its content.

- `Ctrl+1` through `Ctrl+9` switch to the first nine applications in the
    activity-bar order (`1` = Chat, `2` = Tasks, `3` = Notes, `4` = Translate,
    `5` = Finance, `6` = ID Photo, `7` = Image Tools, `8` = Clipboard,
    `9` = Documents; the order follows which plugins are enabled).
