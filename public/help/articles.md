# 文章创作

文章创作（Articles）用于把 Markdown 文章发布到 Astro 博客和微信公众号，
一次创作、多处发布。

## 开始写作

打开「文章创作」，点击「新建文章」会生成一篇带 Markdown 前言的草稿：
填入链接标识（slug）、标题与正文并保存后，文章会出现在左侧列表。

## 配置发布目标

「发布设置」会打开设置中的「文章发布」页：微信公众号需要应用 ID、应用
密钥、站点地址与作者；博客服务器需要主机、用户名、密码与远程目录；还可
指定 Astro 源目录用于从源同步。

## 发布流程

- 同步到公众号草稿：把当前文章保存为公众号草稿，可在公众号后台继续编辑；
- 同步并发布到公众号：直接发布当前文章；
- 发布已有公众号草稿：用已同步的草稿发布；
- 发布到博客：把文章上传到配置的博客服务器；
- 从源目录同步：把本地 Astro 源目录中的已有文章拉入文章库。

## 提示

未配置凭据时，操作会给出明确的中文提示并引导你打开发布设置；公众号与
博客配置只在启用文章创作插件后显示。
