# 快捷键

## 消息编辑

| 操作 | 快捷键 |
| --- | --- |
| 发送或追加引导 | `Enter` |
| 排队后续消息 | `Alt+Enter` |
| 输入换行 | `Shift+Enter` |
| 发送普通斜杠文本 | 以 `//` 开头 |

## 界面

| 操作 | 快捷键 |
| --- | --- |
| 关闭 Help 或设置 | `Escape` |
| 打开命令面板 | `Ctrl+Shift+P`（或输入框旁的命令按钮） |
| 搜索会话 | `Ctrl+K`（或在会话栏搜索框输入） |
| 打开设置 | `Ctrl+,` |
| 切换文件面板 | `Ctrl+Shift+F` |
| 聚焦输入框 | `/` |
| 切换模型 | `Ctrl+M`（输入框右侧模型下拉） |
| 循环思考强度 | `Ctrl+T`（输入框右侧思考标签） |
| 中止当前运行 | `Escape` |
| 切换应用 | `Ctrl+1` ~ `Ctrl+9`（按活动栏顺序：1=对话、2=项目、3=任务、4=笔记、5=翻译、6=自动化、7=金融、8=证件照、9=图片工具；顺序随启用插件变化） |

## 命令面板

`Ctrl+Shift+P` 打开命令面板，输入关键词过滤后回车执行。常用命令：

| 命令 | 作用 |
| --- | --- |
| 新建会话 | 在当前工作区开启一个新对话 |
| 切换工作区 | 打开工作区切换器，原地切换并保留当前应用 |
| 压缩上下文 | 压缩当前会话上下文以节省 Token |
| 展开/收起全部工具 | 批量展开或收起工具卡片 |

## 斜杠命令

在输入框输入 `/` 可查看并选择命令；常用斜杠命令：

| 命令 | 作用 |
| --- | --- |
| `/new` | 开始一个新对话 |
| `/settings` | 打开设置 |
| `/help` | 查看输入框快捷键 |
| `/files` | 打开文件浏览器 |
| `/memory` | 从当前对话提取记忆（欢迎页也有「沉淀记忆」入口） |
| `/mode` | 循环切换工作模式（问一问/做一做/想一想） |

## 工作区

| 操作 | 位置 |
| --- | --- |
| 打开文件夹作为工作区 | 点击工作区栏的工作区名称 |
| 切换工作区 | 工作区栏"切换工作区"按钮，或命令面板"切换工作区" |
| 会话/项目更多操作 | 行内 ⋮ 按钮（键盘 Tab 可聚焦，Enter/Space 激活） |

## 笔记

| 操作 | 快捷键 |
| --- | --- |
| 保存当前笔记 | `Ctrl+S` |
| 新建笔记 | `Ctrl+N` |
| 编辑/预览切换 | `Ctrl+E` |
| 下载 Markdown | `Ctrl+Shift+D` |
| 复制 Markdown | `Ctrl+Shift+C` |
| 加粗 | `Ctrl+B` |
| 斜体 | `Ctrl+I` |
| 代码块 | `Ctrl+Shift+K` |
| 创建副本 | `Ctrl+D` |
| 带入对话 | `Ctrl+Enter`（选中文字或整篇笔记） |
| 打开回收站 | `Ctrl+Shift+T` |

## Agent 控制

工作过程中可以发送新的引导消息。需要在当前任务完成后再处理的内容，请使用后续队列。
