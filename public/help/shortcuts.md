# 快捷键

## 消息编辑

| 操作 | 快捷键 |
| --- | --- |
| 发送或追加引导 | `Enter` |
| 排队后续消息 | `Alt+Enter` |
| 输入换行 | `Shift+Enter` |
| 发送普通斜杠文本 | 以 `//` 开头 |

## 界面

| 操作 | 快捷键 |
| --- | --- |
| 关闭 Help 或设置 | `Escape` |
| 打开命令面板 | `Ctrl+Shift+P`（或输入框旁的命令按钮） |
| 搜索会话 | `Ctrl+K`（或在会话栏搜索框输入） |
| 聚焦输入框 | `/` |
| 中止当前运行 | `Escape` |

## 笔记

| 操作 | 快捷键 |
| --- | --- |
| 保存当前笔记 | `Ctrl+S` |
| 新建笔记 | `Ctrl+N` |
| 打开回收站 | `Ctrl+Shift+T` |

## Agent 控制

工作过程中可以发送新的引导消息。需要在当前任务完成后再处理的内容，请使用后续队列。
