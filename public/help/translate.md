# 翻译

翻译应用使用当前场景中由你选择的模型，在多种语言之间翻译文本；结果可复制或下载。

## 使用步骤

1. 在「源语言」选择自动检测或指定语言。
2. 输入要翻译的文本。
3. 在「目标语言」选择目标语言（可点 ⇄ 交换源/目标）。
4. 在「模型服务」选择当前场景已配置的渠道与模型，再点「翻译」。结果标注所用渠道和模型，可复制或下载。

## 说明

- 在「设置 → 配置 → 模型渠道」添加服务地址、选择 OpenAI Chat Completions 协议并填写模型 ID。
- 默认发送渠道 API 密钥；无需鉴权的本地服务可关闭「使用 Bearer 令牌发送 API 密钥」。此时翻译不会读取或发送密钥。
- 列表来自当前场景实际保存的自定义渠道。仅支持 Chat Completions 协议；自定义请求头、OAuth、内置目录中未保存为渠道的模型及其他协议暂不列入。
- 配置改变后点击「刷新模型」重新选择；没有选择或配置不可用时不自动切换服务。
- 文字仅在点击翻译或按 Ctrl/Cmd+Enter 后发送到所选地址。回环地址直连；远程地址沿用系统代理。选用本地服务并不代表模型已经下载或服务已经启动。
- 文本过长或服务不可用时，错误信息会说明原因并允许重试。
