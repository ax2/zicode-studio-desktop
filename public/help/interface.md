# 界面与导航

ZiCode 使用一致的三栏工作台，让对话、笔记、项目、设置和帮助在同一个窗口里完成，不需要在弹窗之间来回切换。

## 三个界面区域

| 区域 | 用途 | 典型内容 |
|---|---|---|
| 导航 | 切换应用 | 对话、笔记、项目、任务、设置、帮助 |
| 功能区 | 操作当前应用 | 会话列表、笔记目录、设置分类、帮助目录 |
| 主视图 | 阅读或编辑内容 | 对话、编辑器、配置表单、文档正文 |

> 功能区会随当前应用变化；导航始终保持稳定，因此不会重复显示 Logo、设置或帮助入口。

## 文件管理

主视图标题区保留文件管理按钮。它用于浏览当前工作区、打开文件和查看 Agent 生成的内容。完整本地路径和 “Open in…” 下拉不会占用标题栏。

## 工作区

顶部功能区（左侧栏）常驻"工作区栏"，显示当前工作区名称与完整路径：

- 点击工作区名称打开系统文件夹选择器，把选中的目录作为新工作区打开；
- 点击右侧"切换工作区"按钮列出全部已注册工作区（名称 + 路径，当前项
  高亮），选择后**当前窗口原地切换**并停留在当前应用（对话、笔记、
  设置等），不会跳回对话；
- 应用首次启动会自动注册一个全局公共工作区（`~/.zicode`），切换器中
  置顶显示；
- 每个工作区的会话、笔记、任务、自动化、金融研究与产物分别保存在
  `<工作区>/.zicode/{sessions,notes,tasks,automation,finance,artifacts}/`
  下，切换工作区即切换对应数据。

## 在应用间切换

1. 从最左侧导航选择应用。
2. 在功能区选择具体会话、笔记、项目或设置分类。
3. 在主视图继续工作；再次返回时会尽量保留当前选择。

## 窄屏布局

在较窄窗口中，次要页内目录会隐藏，正文保持可读宽度。帮助的完整文档树仍位于功能区，可通过关键词快速筛选。
