# 快速开始

ZiCode Studio Desktop 是本地优先的开发者个人平台，围绕项目连接代码开发、AI 协作、知识记录、任务自动化和成果交付。每个会话绑定一个场景、工作区和独立运行实例。

## 认识工作区

- 左侧顶部是工作区栏：显示当前工作区（项目）。点击右侧的切换按钮可以
  打开/新建工作区，或把任意文件夹作为工作区打开。
- 「全局共享工作区」（`~/.zicode`）始终存在；删除项目会先把应用数据移入
  回收站，30 天内可恢复，项目文件本身不会被删除。

## 创建会话

1. 在左侧选择工作区。
2. 在“设置 → 常规 → 新会话场景”选择下一次会话使用的场景。
3. 点击左侧顶部的“新建会话”。

> 场景选择只影响新会话，不会改变当前正在运行的会话。

## 开始一个项目

1. 将已有项目文件夹作为工作区打开，进入「项目」应用。
2. 在「开发环境」查看当前目录的项目声明、工具版本和环境要求；多目录项目先选择要工作的子项目目录。
3. 在「项目命令」刷新命令列表，查看命令内容和启动目录，再主动运行需要的命令。发现命令和检查环境不会自动安装依赖或执行项目脚本。
4. 查看运行状态、退出码和保留的输出；需要交互式 Shell 时使用「项目终端」。离开页面不停止命令或终端，退出桌面 Host 会结束受管理进程。

在桌面端运行和停止项目命令、使用终端。手机和远程视图可用于查看支持的项目内容；它们不开放这些本机控制入口。详见[项目、任务与自动化](projects-tasks.md)。

## 发送消息

- `Enter`：发送消息；Agent 工作时用于追加引导。
- `Alt+Enter`：将消息加入后续队列。
- 输入 `//`：发送以 `/` 开头的普通文本。
- 输入 `/`：打开命令与技能菜单；输入 `//` 则发送普通文本。

## 配置模型

打开“设置 → Configuration”。页面顶部会显示当前正在编辑的场景。API Key、模型渠道和 `models.json` 都只属于这个场景。显式添加所选服务商或本地兼容服务，再主动刷新目录或测试连接；配置为空时不会自动选择服务商。

## 写第一篇笔记

1. 打开左侧「笔记」应用，点击「新建笔记本」并命名。
2. 在笔记本里点「新建笔记」，输入内容；编辑会自动保存（有未保存更改 /
  保存中 / 已保存会实时提示）。
3. 选中一段文字，用工具栏把它「代入对话」，直接在对话里继续加工。

把开发决策和排查结论写入笔记，使用引用链接关联资料。项目的知识关联与运行分析可准备聊天草稿；草稿保留原有输入，检查后由你发送。报告和其他成果可在[产物库](artifacts.md)继续查看与导出。

## 创建第一个任务

1. 打开「任务」应用，点「新建任务」。
2. 填写标题与说明，核对「目标项目」、审批要求和费用限制。
3. 选择手动、每隔 N 分钟或每天定时；也可先保存草稿，草稿不会自动执行。启用的定时模板到期后生成任务实例，需要审批的实例先等待你批准。
4. 在任务列表查看运行、失败和完成状态。定时模板可主动「立即运行」；重试或取消前先核对当前任务状态。

## 用自动化模板开始

打开「自动化」应用，新建面板里有「每日技术简报」「周报汇总」等模板，
点选即填好指令与计划；核对目标项目、审批和预算后保存并启用。到期实例和运行历史可在任务与自动化页面查看。

保持桌面应用运行时，由 Host 处理到期任务。若需要关闭窗口后继续处理，在自动化页主动「启动后台进程」并确认显示运行状态；需要下次登录系统后启动时，再启用「登录系统后启动后台自动化」。关闭窗口不代表后台进程已经启动；进程存在也不表示某次任务已成功，仍应核对任务结果。

## 从会话模板开始

新会话欢迎页有「从模板开始」（写技术博客、翻译、整理笔记、审查代码、
头脑风暴、分析数据等），点击即把起始提示词预填进输入框，补充细节后发送；
设置 → 一般 → 会话模板 可添加自定义模板并导出/导入，详见
[会话模板](templates.md)。

## 在手机上继续

桌面右上角「在手机上打开」生成二维码，手机扫码即可配对并打开当前会话；
手机浏览器同样能查看笔记、任务和产物。

## 数据安全

- 删除项目进回收站（保留 30 天，可一键恢复或清空）。
- 设置 → 通用 →「工作区数据备份」可随时创建快照（最多保留 7 份），
  恢复前会自动先备份当前状态。

下一步可阅读[场景与隔离](scenes.md)和[模型与 API Key](models.md)。
