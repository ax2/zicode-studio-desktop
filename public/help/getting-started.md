# 快速开始

ZiCode Studio Desktop 是一个本地多场景 Agent 工作台。每个会话绑定一个场景、工作区和独立运行实例。

## 认识工作区

- 左侧顶部是工作区栏：显示当前工作区（项目）。点击右侧的切换按钮可以
  打开/新建工作区，或把任意文件夹作为工作区打开。
- 「全局共享工作区」（`~/.zicode`）始终存在；删除项目会先把应用数据移入
  回收站，30 天内可恢复，项目文件本身不会被删除。

## 创建会话

1. 在左侧选择工作区。
2. 在“设置 → 常规 → 新会话场景”选择下一次会话使用的场景。
3. 点击左侧顶部的“新建会话”。

> 场景选择只影响新会话，不会改变当前正在运行的会话。

## 发送消息

- `Enter`：发送消息；Agent 工作时用于追加引导。
- `Alt+Enter`：将消息加入后续队列。
- 输入 `//`：发送以 `/` 开头的普通文本。
- 输入 `/`：打开命令与技能菜单；输入 `//` 则发送普通文本。

## 配置模型

打开“设置 → Configuration”。页面顶部会显示当前正在编辑的场景。API Key、模型渠道和 `models.json` 都只属于这个场景。

## 写第一篇笔记

1. 打开左侧「笔记」应用，点击「新建笔记本」并命名。
2. 在笔记本里点「新建笔记」，输入内容；编辑会自动保存（有未保存更改 /
  保存中 / 已保存会实时提示）。
3. 选中一段文字，用工具栏把它「代入对话」，直接在对话里继续加工。

## 创建第一个任务

1. 打开「任务」应用，点「新建任务」。
2. 填写标题与说明；「目标项目」默认就是当前工作区，可直接运行。
3. 选择触发方式：手动、每隔 N 分钟，或每天定时；保存后任务进入列表，
   定时任务可随时「立即运行」。

## 用自动化模板开始

打开「自动化」应用，新建面板里有「每日技术简报」「周报汇总」等模板，
点选即自动填好指令与计划；保存后到点自动运行，结果与历史汇入任务中心。

## 在手机上继续

桌面右上角「在手机上打开」生成二维码，手机扫码即可配对并打开当前会话；
手机浏览器同样能查看笔记、任务和产物。

## 数据安全

- 删除项目进回收站（保留 30 天，可一键恢复或清空）。
- 设置 → 通用 →「工作区数据备份」可随时创建快照（最多保留 7 份），
  恢复前会自动先备份当前状态。
