# 模型与 API Key

模型渠道与凭据按场景隔离，请先确认 **设置 → 配置** 顶部显示的是目标场景。

## 配置自己的模型渠道

在“自定义模型渠道”中添加提供商标识、协议、Base URL 和模型 ID。支持 OpenAI、Anthropic 和 Google 兼容协议；本地免密服务可关闭 Bearer 鉴权。
可选的“显示名称”只用于当前场景的渠道行和模型列表；渠道 ID 仍是稳定标识，修改名称不会改变已有模型引用。名称最多 100 个可读字符，清空可恢复默认名称。
“模型详情 JSON”按模型 ID 填写可选元数据，例如 `{"my-model":{"name":"本地模型","contextWindow":128000,"maxTokens":8192,"cost":{"input":0,"output":0}}}`。价格单位为每百万 Token 的美元；未填写的已有字段会保留，删除旧元数据仍需使用高级 `models.json` 编辑器。保存前请核对提供商的实际价格。
渠道行的“复制渠道”会预填地址、协议、鉴权方式和模型 ID，并保留这些模型的配置元数据。请填写新的渠道 ID 后保存；密钥不会随副本复制，需要单独输入。若源渠道在编辑期间发生变化，刷新后重新复制。已有 ID 不会被副本覆盖。
点击“测试连接”会主动检查该渠道。已有模型时应用会发送一次简短的模型请求，可能产生服务商费用，并更新该模型的健康状态；尚无模型的 OpenAI 兼容渠道和 QVeris 渠道只读取模型目录，不保存目录结果。测试期间修改渠道配置会使结果失效。
关闭 Bearer 鉴权后，渠道配置不再保留 API Key 引用，表单也不接受新密钥；已存在的系统凭据不会因此自动删除，可在 API Key 列表中单独移除。
渠道行可直接点击「禁用渠道」或「启用渠道」；操作只修改当前场景的 `enabled` 状态，不删除模型、地址或系统凭据。渠道版本变化时会拒绝旧操作，刷新后再决定。禁用渠道在列表标为“已禁用”，从模型选择中隐藏，并停止该行的连接测试与目录发现；Pi 桥接会请求取消当前所选禁用渠道的活动。高级 `models.json` 仍可编辑 `enabled`。已经发出的网络请求无法撤回，第三方扩展调用需单独检查。

新场景不会自动创建 QVeris 渠道。读取配置、保存渠道或保存 Key 均不会自动请求模型目录；已有渠道仍保留，可编辑或删除。

OpenAI Chat Completions 或 Responses 兼容渠道可以先保存空模型列表，再在渠道行点击“发现模型”。应用只从当前渠道的 Base URL 请求 `/models`，读取模型 ID 后打开编辑表单供检查；此时不会写回配置。确认列表后点击“保存渠道”，已有模型的手填参数会保留。免鉴权本地服务可直接发现；需要鉴权的渠道必须先配置 Key。目录可能包含非聊天模型，保存前请检查 ID。

发现请求有超时、大小和条目上限；请求期间渠道发生变化时需刷新并重试。Anthropic 与 Google 兼容渠道仍需手动填写模型 ID。

## 设置 API Key

在 Authentication 列表中找到提供商，点击“Set key”或“Update”。密钥由桌面 Host 保存到操作系统凭据库，场景配置仅保留非敏感引用，不写入 `models.json`、日志或文档。

## 额度不足

聊天提示“模型服务额度不足”时，请检查当前选中渠道的余额或额度；提示本身不代表某个特定服务商已扣费。也可切换成本更低的模型，或新建会话减少上下文。

## 可选的 QVeris 模型目录

需要此适配器时，显式添加 Provider ID 为 `qveris` 的渠道，填写自己使用的网关 Base URL（以 `/v1` 结尾），并设置 Key。该渠道允许暂不填写模型 ID。

随后点击渠道行的“刷新模型”，才会向所配置网关请求模型目录。返回的聊天模型会同步到当前场景；嵌入模型不会进入聊天下拉框。同步保留模型的上下文窗口、视觉输入、推理能力和每百万 Token 价格。
网关拒绝请求时界面只显示 HTTP 状态，不回显服务端错误正文；请检查渠道地址、密钥和服务账户状态后重试。
模型健康检查同样只显示状态或固定错误类别；404 响应仅在明确返回 `model_not_found` 时自动隐藏该模型，不显示上游错误详情。

如果同步期间渠道被修改或删除，本次结果不会写回，请刷新配置后重试。删除渠道后，后续读取或同步不会将其重新创建。

删除渠道也会移除关联凭据；依赖同一提供商凭据的功能可能需要重新配置。修改 Provider ID 后，应检查已有会话的模型引用并重新设置凭据。

## 场景隔离

在 Finance 中配置的 Key 不会自动出现在 Programming。金融服务适配与模型渠道是不同用途，保存金融凭据不会自动创建聊天模型渠道。

## 高级文件

高级编辑器可编辑当前场景的代理配置和 `models.json`。修改后刷新相关模型列表以查看最新配置。
