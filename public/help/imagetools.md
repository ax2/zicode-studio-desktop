# 图片工具

图片工具用于单张图片的缩放、格式/质量转换、旋转、翻转，以及把多张图片拼接成网格。

## 使用步骤

1. 选择或拖入一张/多张图片（JPG / PNG / WEBP）。
2. 在「选项」中设置：
   - 缩放：等比缩放（含边/裁满/拉伸）并设置目标宽高；
   - 格式与质量：转换输出格式，必要时调整压缩质量；
   - 旋转 / 翻转：按角度或水平/垂直翻转；
   - 拼接网格：多张图片时设置列数、间距与排列方向。
3. 点「处理」，在结果区预览。
4. 下载结果或在新标签页打开。

## 输出

处理后的图片会显示新的尺寸、格式与体积（如 192×192 · PNG · 20.3 KB），方便核对是否符合预期。
