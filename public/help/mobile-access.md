# 在手机上使用 ZiCode

ZiCode 的手机端是桌面主机的安全遥控界面：Pi、项目文件和工具执行仍留在电脑上，手机负责对话、查看笔记和管理工作流。当前 ZiCode 不会把 Pi 安装到手机，也不使用手机文件系统执行对话中的工具。

Pi 上游另行支持在 Android 的 [Termux](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/termux.md)
中本机运行命令行版本，但这与 ZiCode 手机界面是两套独立运行方式：Termux 中的 Pi
不会自动接入 ZiCode 的场景、会话、凭据库或插件。iPhone/iPad 目前没有对应的 Pi
本机运行方式。ZiCode 当前推荐的 Android 与 iOS 使用方式仍是连接受信任的桌面 Host。

## 第一次连接

1. 在电脑打开 **设置 → 远程访问**，启用“安全移动访问”，然后重启 ZiCode。
2. 确认手机和电脑位于同一个可信局域网。
3. 在目标对话点击“在手机上打开”，切换到“首次设置”，用手机扫描证书设置二维码。
4. 在安装页选择 Android 或 iPhone/iPad，并严格核对 CA 指纹。
5. 下载并信任证书。回到二维码弹窗，切换到“打开当前对话”。
6. 扫描新生成的会话二维码。链接五分钟内有效且只能使用一次；过期后点击刷新。

> “手机信任设置”使用独立 HTTP 端口，只提供公开 CA 与安装说明；对话、文件和配对令牌不会从该端口提供。

## Android 证书安装

不同厂商的菜单名称略有差异。通常可以在系统设置中搜索“安装证书”“CA 证书”或“凭据”，然后选择下载的 `ZiCode-Studio-Mobile-CA.pem`。系统显示安全警告是正常的，但只有在指纹与电脑完全一致时才能继续。

## iPhone 与 iPad 证书安装

下载后先从“设置”顶部的“已下载描述文件”完成安装，再进入 **设置 → 通用 → 关于本机 → 证书信任设置**，为 ZiCode Studio Mobile CA 开启完全信任。

## 安装到主屏幕

- Android：浏览器提供安装能力时，ZiCode 会显示“安装”卡片。
- iPhone/iPad：在 Safari 中轻点“分享”，选择“添加到主屏幕”。
- 主屏幕和安装确认中统一显示 **ZiCode Studio**，不会把手机入口标成 Desktop。iPhone/iPad
  使用明确的主屏幕 PNG 图标；Android 将现有品牌图标作为普通图标处理，避免系统套用圆形、
  水滴等遮罩时裁掉“Zi”字样。
- 浏览器与已安装应用支持时，地址栏或系统状态栏颜色会随“明亮白色、纯黑深色、暖砂浅色”
  等当前主题同步变化，减少切换主题后的突兀色块。
- 选择“暂不”或 iPhone/iPad 上的“知道了”只会暂停提示七天，不会永久关闭；之后仍未安装时，
  ZiCode 可以再次提供引导。浏览器菜单中的安装或“添加到主屏幕”始终可以手动使用。
- 安装后的入口仍需要电脑在线，并与电脑处于可访问的网络中。
- 从主屏幕冷启动时会恢复这台手机最近打开的会话路径；在应用内切换会话、使用系统返回，
  或临时会话获得正式 ID 后会立即更新。设置和其他应用页面不会覆盖最近会话，只保存经过
  格式校验的路径，不保存查询参数、片段或二维码中的配对令牌。
- 已安装的 ZiCode 回到前台时会按小时节流检查新版离线与分享支持，不会强制刷新正在阅读
  或编辑的对话；新版本在下次正常打开或刷新时生效。

手机系统可能缓存已安装应用的名称和图标。如果升级后仍看到旧的 “ZiCode Studio Desktop”
或被裁切的图标，请先正常打开一次应用等待更新；仍未变化时，从主屏幕移除旧安装并重新添加。
移除主屏幕入口通常不等同于清除站点数据，但执行系统清理前仍应保留重要草稿。

## 切换应用

底部导航固定显示“对话、项目、笔记、文件、更多”，每个入口都提供至少 56px 高的触控
区域。它们是应用导航按钮，不是选项卡；屏幕阅读器会通过“当前页面”指出正在使用的应用。
任务、自动化、金融、产物、命令、插件管理、设置和帮助位于“更多”面板中。

选择次级应用后，“更多”的辅助名称会包含当前页面，例如“更多：设置”。关闭面板不会
触发一次额外的浏览器返回，因此不会刚进入设置又弹回对话。此后使用 Android/iOS 系统
返回手势会正常回到前一个应用。横屏时“更多”面板可以内部滚动，底栏和面板仍避开左右
安全区；系统开启“减少动态效果”时，当前入口的自动定位改为即时完成。

## 在手机上编辑笔记

打开笔记后，编辑/预览和笔记操作分成两个清晰的控制组。手机上每组使用两列布局，带入
对话、添加附件、保存和删除不会挤成超出屏幕的一行；所有按钮至少 40px 高。很窄的屏幕或
粗指针横屏也使用同一布局，标题、标签和 Markdown 编辑区保持在页面宽度内。

“编辑”和“预览”会向屏幕阅读器报告当前选中状态。修改标题、标签或正文后“保存”才会
启用；保存完成后重新禁用，避免重复提交。使用外接键盘时可直接聚焦两个视图按钮并用
Enter 或空格切换，页面不会因为操作区换行产生横向滚动。

## 内置应用的表单与按钮

项目、任务、自动化、金融、产物、插件管理和设置在手机上共用触控安全基线：普通按钮和
复选框标签至少 40px 高，单行输入框和下拉框至少 40px 高。表单文字使用至少 16px 字号，
避免 iPhone/iPad Safari 在聚焦较小文字时自动放大整个页面；标题等原本更大的文字不会被
缩小。桌面端仍保留紧凑控件密度。

Automation 的名称、目标项目、任务说明、计划、费用和重试次数都在输入框上方保留可见
标签；开始输入后不会只剩一个失去上下文的数值。标签同时与控件建立原生关联，轻点文字可
聚焦对应字段，屏幕阅读器也会使用同一名称。窄屏会移除一层重复页面留白，为字段多保留
32px 左右的有效宽度。

创建自动化时填写名称和任务说明，选择计划、费用与重试上限，再轻点“创建自动化”。提交
成功后表单会清空，新规则立即出现在下方；若创建失败，应用会保留当前内容并显示错误提示。

## 从 Android 系统分享到 ZiCode

把 ZiCode 安装到 Android 主屏幕后，可以在网页、浏览器选中文本或其他支持分享的应用中
打开系统分享面板并选择 **ZiCode**。分享的标题、正文和网页地址会添加到当前对话的输入框；
已有草稿会保留，你可以继续编辑、删除或补充内容，ZiCode **不会自动发送**。

也可以从相册、截图工具或其他应用分享 PNG、JPEG、GIF、WebP 图片。最多接收四张，单张
不超过 8 MB、合计不超过 12 MB；图片进入现有预览和压缩流程，最长边会限制到 2048px，
仍需由你确认发送。某张图片类型不支持或超过限制时，ZiCode 会保留能够读取的文字和图片，
并提示“部分分享图片无法添加”。

为避免分享内容出现在浏览器历史、服务器日志或长期缓存中，Android 通过一次 POST 把内容
交给 ZiCode，随后只跳转到这台手机最近打开且经过格式校验的会话路径。文字只暂存在当前
标签页的会话存储；图片进入带随机标识和时间戳的一次性本地收件箱。应用读取时会先删除
原记录再生成预览；超过十分钟、格式损坏或读取超时的内容会被丢弃并显示友好提示。

系统是否显示 ZiCode 取决于 Android 版本、浏览器和 PWA 安装状态。iPhone/iPad 目前可能
不会把网页应用列为系统分享目标，但仍可以在 ZiCode 内使用“分享回答”把内容发送到其他应用。

## 网络切换与恢复

手机断网、锁屏或切换 Wi-Fi 后，顶部会显示离线或重连状态。网络恢复后 ZiCode 会自动重建 WebSocket 并恢复当前会话订阅，不需要刷新页面。若设备已在电脑端被撤销，则不会继续重连，需要重新生成配对链接。

如果重连持续约八秒，顶部提示会说明连接耗时过长并显示“重试”。先确认电脑端仍在运行、远程访问已经启用且两台设备网络可达，再点击按钮立即重新建立连接；无需退出主屏幕应用或重新扫描仍有效的设备凭据。

从锁屏或其他应用回到 ZiCode 时，应用会主动替换可能已经失效的后台连接；若多个系统恢复事件连续到达，只保留一条正在建立的连接。

如果直接打开应用时电脑不可达，会显示独立离线页面。页面会区分“手机仍离线”和“手机已联网但桌面端不可达”，每五秒只检查一次本机 ZiCode Host；发现桌面端恢复后会自动回到原会话路径，也可以点击“立即重试”。该检查不会联系模型服务。

## 软键盘与输入区

在 Android 或 iPhone/iPad 上聚焦消息输入框时，ZiCode 会跟随浏览器的实际可见区域，
把 Composer 保持在软键盘上沿，并暂时收起底部应用导航。iOS 因地址栏或输入焦点平移
页面时，顶部按钮、Composer 和消息滚动安全区会继续随可见区域更新，不需要手动滚动
页面寻找输入框。

关闭键盘后，底部导航和常规安全区会自动恢复。若第三方键盘、浏览器缩放或分屏模式下
仍出现遮挡，请先切回标准缩放并重新聚焦输入框；这些系统组合仍需要在具体 Android/iOS
设备上做发布前验收。

长对话中，如果你原本停在最后一条消息附近，键盘开合、附件预览或 Composer 高度变化
后会继续保持在底部，不需要反复向下滚动。如果你已经上滚阅读历史，ZiCode 会保留当前
阅读位置，不会因为键盘或流式回答突然跳回最新消息。此时若收到新回答，对话右侧会出现
“最新消息 ↓”按钮；点击或用键盘激活即可回到末尾，回到底部后按钮会自动隐藏。
手机上的按钮提供至少 40px 高的触控区域，并避开输入区与右侧安全区。屏幕阅读器会用
礼貌级别播报新回答和返回方式；很长的距离会即时回到末尾，短距离才使用平滑滚动。若系统
开启“减少动态效果”，对话圆点和“最新消息”按钮的所有跳转都会改为即时完成。
通过键盘或屏幕阅读器激活“最新消息”后，焦点会转移到最新回答，不会遗留在已经隐藏的
按钮上。最新回答只在聚焦期间临时进入焦点顺序，离开后自动恢复；手动滚动到底部不会
抢走当前焦点。

为了避免很长的会话在手机上切换时一次性创建数百个消息和工具节点，ZiCode 会先显示
最近一段对话，并在顶部提供“加载更早消息”。每次加载都会保持你当前正在阅读的内容
位置；全部加载后，焦点会落到“已加载全部更早消息”状态，不会因按钮消失而丢失。
使用会话搜索时会自动展开完整历史，因此较早内容仍可搜索，不需要先手动逐批加载。

历史消息中的附件图片和 Markdown 图片只会在接近可见区域时开始加载，并使用异步解码，
减少长对话初次打开时的网络、主线程和内存压力。当前正在编辑的图片预览以及已经打开的
大图查看器仍会立即显示。外部 Markdown 图片请求不会携带 ZiCode 页面来源信息；但图片
接近可见区域后仍会连接图片所在的外部主机，因此这项优化不代表图片已经离线保存。

## 阅读宽表格和代码

回答中的宽表格和长代码只在各自内容区内横向滚动，不会把整个页面撑宽。手机上可以直接
左右滑动；使用外接键盘时，先聚焦带有“可横向滚动的表格”名称的表格区域，再用左右方向键
移动。表格和代码区会隔离横向滚动链，避免滑到边缘时意外拖动整个应用。

代码块右上角的“复制”在手机上提供至少 40px 的触控区域。复制成功会显示“已复制”并通过
状态区域播报；浏览器拒绝剪贴板权限时会显示“复制失败”，同时播报检查剪贴板权限的建议，
不会产生无响应或未处理错误。失败反馈保持五秒后恢复为“复制”，可以调整站点权限后重试。

## 查看工具执行

Pi 运行命令、读取文件或修改内容时，工具卡片标题在手机上是至少 40px 高的展开按钮。轻点
可以查看参数和输出，再次轻点收起；使用外接键盘时也可以聚焦后按 Enter 或空格。按钮向
屏幕阅读器提供“工具名 + 展开/收起动作”，不会把很长的文件路径或命令全部塞进按钮名称。
长路径会在紧凑标题中省略，完整值仍保留在展开参数中。

执行失败的工具会自动展开错误详情，不需要猜测红色状态后还要手动打开。工具输出和差异区
在手机上最多占可见高度的 38%，可以内部滚动。复制输出按钮始终可见并提供 40px 触控区域；
成功会显示绿色“工具输出已复制”，权限拒绝会显示五秒红色建议。待处理、运行中、完成和
错误状态以及所有辅助名称都会随当前语言更新。

## 断线时保存待发送内容

远程连接断开时，发送按钮的辅助说明会变为“保存草稿，等待重连”。点击后不会请求模型，
也不会在后台静默重试；ZiCode 会先保存当前加密文字和图片草稿，再写入一个按会话隔离、
同样加密的待发送标记。若本地存储失败，内容仍留在输入区，并显示可操作错误。

连接恢复后，Composer 上方会显示确认条。选择“立即发送”才会真正提交；选择“保留为草稿”
只清除待发送标记，内容继续保留。标记 24 小时后自动过期，草稿本身仍按七天规则保留，
因此很久以后重新打开应用也不会意外自动发送旧内容。切换会话时，各会话的确认状态互不影响。

## 未发送草稿恢复

远程手机客户端按 Workspace 和会话保存未发送的文字及已处理图片。输入停止约 250ms 后，草稿
使用设备本地生成的 AES-GCM 256 位不可导出密钥加密，再写入 IndexedDB；刷新页面、系统
回收 PWA 后重新打开同一会话时，ZiCode 会恢复文字和图片预览、聚焦输入框并显示“已恢复此设备上的
未发送草稿”。恢复不会覆盖你在读取完成前已经输入的新文字。

每个草稿最多 32,768 个字符，七天后自动删除。切换会话不会串稿；临时新会话获得正式
会话 ID 时会迁移现有草稿。请求成功提交后删除草稿，请求失败则继续保留。图片恢复最多
四张、单张解码后 8 MB、合计 12 MB，并只保留最近三个含图片的会话；文字密文与附件密文
分开保存，因此正常打字不会反复加密大图。超过限制的图片仍可在当前页面发送，但应用会
提示它们无法用于重启恢复，需要重新选择。

草稿只保存在这台手机的当前 ZiCode 站点中，不同步到电脑、云端或其他设备。加密用于减少
设备存储被直接读取时的文字或图片明文暴露，不等同于端到端加密；能够在当前 ZiCode Origin 执行的
代码仍可请求浏览器解密。清除站点数据会同时删除草稿和设备密钥，无法恢复。

在手机打开 **设置 → 常规 → 移动端 → 保护本地草稿**，可以主动请求浏览器把当前 ZiCode
站点设为持久存储。获得保护后，浏览器不会仅因存储空间紧张而自动回收这些加密草稿；操作
不会上传草稿，也不会改变七天过期和容量限制。设置页会显示浏览器返回的保护状态，并在可用时
显示当前用量与额度。浏览器拒绝或不支持时，草稿仍保持加密，但可能在存储压力下被清理。

持久存储不是永久备份：手动清除站点数据、重置浏览器或卸载并删除站点数据，仍会删除草稿和
设备密钥。ZiCode 只会在你点击“保护草稿”后请求权限，不会在后台自动弹出权限请求。

## Pi 任务进度

Pi 使用任务清单时，输入区上方会显示紧凑的“任务”进度条和已完成数量。手机上轻点进度条
即可展开最多五项当前任务，再次轻点即可收起；任务较多时会显示剩余数量。很长的任务名称
最多显示两行，展开内容限制在可滚动区域内，不会把输入框推出屏幕。

进度条提供至少 40px 高的触控区域，并向屏幕阅读器说明当前完成比例以及展开或收起动作。
收起时任务详情会同时退出操作与无障碍浏览范围；中英文切换后标题、状态、剩余数量和辅助
名称都会立即更新。桌面端仍可悬停预览，也可以点击固定展开状态。

## 任务完成提醒

在手机打开 **设置 → 常规 → 移动端 → 任务完成提醒**，由你主动授予浏览器通知权限。
启用后，ZiCode 只在已经跟踪的 Pi 任务完成且页面仍处于后台时发送系统提醒；如果已经
回到 ZiCode，则不会重复打扰。提醒只显示“Pi 任务已完成”，不会把提示词、模型回答、
文件名或工作区内容放到锁屏通知中。点击提醒会优先聚焦已打开的 ZiCode，应用未打开时
才恢复最近的安全会话入口。

如果开关显示浏览器已阻止通知，请在该站点的系统/浏览器设置中重新允许。在 iPhone 或
iPad 上，通常需要先把 ZiCode 添加到主屏幕，再从主屏幕应用启用提醒。

## 返回手势

在 Android 浏览器或主屏幕应用中使用系统返回键时，ZiCode 会按界面层级返回：先关闭“更多”面板等浮层，再关闭当前应用的功能区抽屉，然后回到上一个应用或会话。返回不会因为只关闭一层界面就退出 ZiCode；跨工作区的历史会重新加载目标工作区，避免地址与内容错位。

照片选择面板也遵循同一规则：返回会先关闭“拍照/从相册选择”面板，并把焦点还给输入区
的“添加图片”，不会直接离开当前对话。选择大图后请等“正在处理图片”消失并出现预览，
发送按钮会在照片准备完成后自动恢复。

## 直连（P2P）与中继

新版手机端会自动尝试与桌面建立 WebRTC 直连（P2P）：同一局域网或可以打洞的
网络下，对话数据直接在两台设备间传输，不经过服务器中继；打洞失败时自动回退
到中继通道，不需要任何手动切换。中继仍负责配对信令与兜底，服务器始终看不到
桌面端执行的会话内容。如果服务器部署了 STUN/TURN（coturn），把部署脚本输出
的 `relayIceServers` 填入桌面端 `remote-access/config.json`，手机即可获得
公网打洞候选。

## 安全建议

- 只在自己控制或信任的局域网启用远程访问。
- 不要安装指纹不匹配的证书。
- 不再使用的手机应在 **设置 → 远程访问 → 已配对设备** 中撤销。
- 一次性二维码可以配对设备，不要转发或截图分享。
- 只有电脑本机可以生成新的配对二维码；已配对手机不能继续为其他设备签发凭据。
