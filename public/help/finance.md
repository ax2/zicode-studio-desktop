# 金融工作台

Finance 场景提供本地研究卡、手工来源市场快照、确定性回测、筛选和模拟账户；这些功能不要求外部数据密钥。内置示例使用虚构的 DEMO 标的和演示数值，不代表实时市场数据。

金融工作台使用统一三栏界面：左侧导航切换应用，功能区选择数据、分析或账户页面，主视图显示当前页面。它不再打开独立浮层。

## 可选的 QVeris 数据连接

需要外部金融能力时，可配置同一场景内的 QVeris Key：

- 模型目录通过 Model Gateway 获取；
- 金融能力通过 QVeris Capability API 获取；
- 两者使用不同端点，但凭据保持场景隔离。

## 可选外部数据调用流程

1. Discover 查找当前可用能力。
2. Inspect 获取参数 Schema、成功率和计费规则。
3. 确认预估费用。
4. Call 执行请求。
5. 保存执行 ID、来源和数据时间，并按需核对 Usage。

外部服务拒绝请求时，工作台只显示 HTTP 状态，不展示服务端错误正文；可检查 Key、余额和请求参数后再试。

成功保存的市场快照、回测和选股结果会自动进入产物库。归档失败不会隐藏已经得到的分析结果。
保存快照时填写真实来源、数据时间和币种；QVeris 的工具、搜索及执行 ID 仅在实际取得时填写。

## 风险边界

金融工作台不会连接真实券商，也不会提交真实交易。回测必须说明数据来源、日期、费用、滑点和复权方式。
