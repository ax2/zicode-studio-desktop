# 项目、任务与自动化

项目负责聚合目标，任务负责记录执行状态，自动化负责按规则触发重复工作。三者配合可以把一次聊天升级为可持续的工作流。

> 当前默认状态：**任务**与**自动化**已启用可直接使用；**项目**插件默认
> 禁用，需先在「管理插件」中启用后才会出现在「更多」菜单。本文描述的
> 项目规则在启用后适用。

## 什么时候创建项目

当工作包含多个会话、多个阶段或多个交付物时创建项目。项目可集中展示关联会话、任务进度、产物和最近活动。

## 跨项目内容搜索

在“更多 → 项目 → 项目搜索”中输入关键词，可以同时检索当前项目的对话、笔记、文件和产物。
搜索框上方的“项目搜索”标签会在输入后继续显示；手机端结果按文件、对话等类型纵向排列，
标题和路径不会被窄屏三列布局挤压。搜索范围始终跟随当前项目，不会混入其他工作区的内容。

## 任务状态

| 状态 | 含义 | 可用操作 |
|---|---|---|
| 定时 | 按计划重复运行的模板，等待下次触发 | 编辑、暂停定时、删除 |
| 待运行 | 已创建或已批准，等待派发 | 批准并运行、取消 |
| 运行中 | Agent 正在执行 | 暂停、取消 |
| 已暂停 | 保留现场但不继续 | 恢复、取消 |
| 需要输入 | 代理执行中提问，等你回答 | 直接回复、重试 |
| 已失败 | 执行遇到错误 | 查看原因、一键重试并运行 |
| 已完成 | 结果已产出 | 查看产物、再次运行 |

暂停、恢复、取消和重试会作用于真实后台任务，不只是改变界面标签。
定时模板本身不会执行；到期时任务应用会生成一条新的“待运行”实例。

## 回答代理的问题

代理执行过程中需要你确认时，任务会进入「需要输入」状态，并在任务卡片上
直接给出回复框。输入回答后任务自动继续，无需重开会话或重新派发。
「重试」按钮在需要输入的任务上是次级操作，避免误把“重新派发”当成
默认路径。

## 一键重试并运行

失败或阻塞且绑定了目标项目的任务，卡片上直接提供「重试并运行」主按钮：
一次点击完成重试计数、清空失败原因并重新派发给项目代理，不用先回到
“待运行”再点“批准”。达到自动重试上限时仍会先弹确认框。

手机上的任务中心将运行中、需要输入、失败和已完成摘要排列为 2×2；任务操作使用等宽按钮，
历史记录标题具有完整触控区域。项目名、时间或其他长值会自然换行，不会以省略号隐藏关键信息。

## 在任务中心创建与管理任务

任务中心不只是接收后台工作的收件箱，也可以直接创建和管理任务，不需要先经过
对话或收件箱：

- 「新建任务」：填写标题、说明、目标项目，选择触发方式——手动、每隔 N 分钟
  或每天 HH:MM；可选择「执行模式」——自动运行（完全访问，到期直接执行）
  或每次运行前确认（默认权限，先停在任务中心等你批准）——并设置最大重试
  次数。
- 手动任务：创建后出现在任务列表；按审批设置自动运行或等你在任务中心点
  「批准并运行」。
- 定时任务：创建后作为「定时」模板卡片，显示计划（如“每天 09:00”）和下次
  运行时间；到期由任务应用自动生成新任务实例并执行（按审批设置决定是否自动
  运行）。支持编辑（标题/说明/目标项目/触发方式/时间）、暂停定时、删除。
- 编辑任务：一次性任务与定时任务卡片都有「编辑」入口，保存后立即生效，定时
  任务会自动重算下次运行时间。
- 按空间分组：列表顶部「按空间分组」开关把任务按目标项目（工作空间）分组
  展示，组头显示项目路径与任务数；默认空间单独成组。
- 置顶：任意任务卡片都有「置顶」，置顶任务始终排在列表最前，方便固定重要
  事项。
- 继续处理：有绑定子会话的任务显示「继续处理」主按钮，点击直接进入该任务的
  对话接着工作。
- 再次运行：已完成/已取消的一次性任务可「再次运行」，以相同设置创建新任务
  并立即派发；自动化来源任务用「再次运行」重跑对应工作流。
- 运行时长：运行中任务的状态旁显示「已运行 N 分钟」，随时了解后台任务进度。
- 归档：已完成/已取消任务可「归档」——从常规视图隐藏但保留；左侧筛选新增
  「已归档」查看，归档任务可「恢复」回列表。
- 「定时任务」筛选：左侧导航只显示定时模板，方便统一管理。

## 自动化规则

自动化适合周期性整理、固定提示词和重复研究。创建前明确：

1. 触发条件；
2. 使用的场景和模型策略；
3. 预期产物及保存位置；
4. 失败后的通知与重试方式。

在“更多 → 自动化”中填写名称、目标项目和任务说明，选择手动、每小时或每日计划，并设置
单次费用、最大重试次数与「执行模式」。新建表单顶部还有「从模板开始」：内置每日
技术简报、周报汇总、每日学习计划、代码巡检、新闻摘要等常用模板，点击即预填名称、
提示词与计划，可在此基础上修改或一键「使用自定义」清空。点击“创建自动化”后，
新规则会立即出现在列表中；
手机端表单使用防止系统自动缩放的 16px 输入字号和至少 40px 的触控区域。每个字段都有
持续可见标签，输入内容后仍能辨认字段含义；轻点标签也可聚焦相应控件。
已有工作流卡片可「复制」为同配置的新工作流（标题加“副本”后缀、历史清空、
下次运行时间重算），适合基于现有规则派生变体。

### 自动执行范围

- 选择「自动运行（完全访问）」的工作流：到期后自动把任务派发到目标项目，
  无需在任务中心手动点“批准”。
- 选择「每次运行前确认（默认权限）」的工作流：到期后任务停在“需要批准”
  状态，在任务中心手动批准后才开始执行。
- 调度器在应用打开期间持续运行，不依赖你停留在自动化页面；应用完全关闭
  后不会执行（无人值守后台运行器属于后续版本规划）。
- 派发到目标项目的任务在代理执行结束后会自动标记为已完成并弹出通知
  （含结果摘要）；失败也会通知，并可从任务中心重试。

> 自动化不会绕过场景隔离、插件权限或模型预算限制。
