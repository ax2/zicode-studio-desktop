# 会话模板

新会话的欢迎页提供「从模板开始」：点击任意模板会把对应的起始提示词预填
到输入框（不会自动发送），你可以先补充细节再确认发送，避免每次从空白
开始组织常用请求。

## 内置模板

- ✍️ 写技术博客
- 🌐 翻译文本
- 📝 整理成笔记
- 🔍 审查代码
- 💡 头脑风暴
- 📊 分析数据

## 自定义模板

打开 设置 → 一般 → 会话模板，可以添加、编辑或删除自己的模板：

- **名称**：模板的显示名
- **Emoji 图标（可选）**：默认 📝
- **模板提示词**：点击模板后预填进输入框的起始内容

自定义模板会和内置模板一起显示在欢迎页；名称与提示词为必填。支持
**导出模板 / 导入模板**（JSON 文件），便于备份或在电脑与手机之间迁移——
导入按 id 去重，已存在的模板自动跳过，不会产生重复项。

> 提示：模板只是起点，发送前可自由修改。Pi 以当前工作区为工作目录，
> 在提示词里写相对路径（如 `src/app.ts`）即可直接引用文件；也可以把
> 右侧文件面板里的文件直接拖进输入框插入路径。
