# 网页监控

网页监控应用通过内容哈希检测公开网页何时发生变化，适合盯住不提供
RSS 的页面：价格页、公告页、文档更新页等。

## 使用步骤

1. 点击「添加监控」，填写名称与要监控的网页地址。
2. 页面会立即抓取一次，记录当前内容哈希作为基线。
3. 需要时点击「全部检查」（或单个检查）重新抓取并对比。
4. 页面内容发生变化时，该监控项会显示「已变化」；再次检查确认后，
   新的内容哈希会成为新的基线。

## 说明

- 监控的是公开可访问的网页；需要登录或验证码的页面无法抓取；
- 检查是手动触发（应用打开时），不依赖后台常驻服务；
- 变化的判断基于内容哈希，页面中时间戳、计数器等动态区域可能导致
  频繁提示变化，可据此判断是否适合用哈希监控。
