# 故障排查

遇到问题时先确认当前场景、任务状态和错误卡片。ZiCode 会尽量给出可执行的下一步，而不是只显示技术异常。

## QVeris 模型没有出现

1. 打开“设置 → Configuration”，确认正在编辑正确场景。
2. 检查 QVeris Model Gateway 地址和 API Key 状态。
3. 保存后重新获取模型列表。
4. 若网关不可达，检查内网连接和服务状态。

## 请求失败或会话没有反应

- 查看消息下方的友好错误卡片；可直接重试原请求。
- 打开模型设置，确认所选模型仍在网关列表中。
- 查看任务应用，确认任务是运行、暂停、失败还是已取消。
- 不确定时新建会话验证，可区分会话状态问题与全局配置问题。

## 插件无法运行

- 确认插件已启用且所需权限已授权。
- 已签名插件必须提供 WASI 模块；开发者本地包才可使用 JavaScript Worker。
- 检查插件包大小、签名和运行超时错误。

## 笔记站点构建失败

打开笔记应用的发布日志，确认 Astro 项目文件完整且网络可访问依赖源。发布只在本机明确确认后执行，并要求最终生成 `dist/index.html`。

## 仍然无法解决

记录场景名称、操作步骤、错误时间和非敏感日志。请勿截取或粘贴完整 API Key、Cookie、令牌和账号凭据。
