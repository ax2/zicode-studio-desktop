# 文字识别（OCR）

文字识别应用使用系统 OCR 引擎，从截图和图片中提取文字；结果可复制、
下载或发送到笔记。

## 使用步骤

1. 点击「选择图片」或直接把截图/图片拖入应用。
2. 如需识别中文、英文之外的语言，可先选择识别语言。
3. 点击「识别」，提取的文字显示在结果区。
4. 复制文字、下载结果、发送到笔记库，或「添加到对话」直接在对话里继续
   讨论提取的内容。

## 说明

- 识别完全在本机完成，图片不会上传到云端；
- 图片清晰、文字为正立时准确率最高；模糊或倾斜的文字建议先调整图片再识别；
- 支持常见的截图与图片格式（JPG / PNG / WEBP 等）。
