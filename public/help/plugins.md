# 插件安装与信任

ZiCode 应用插件与 Pi 扩展是两套机制。应用插件可以提供左侧导航、功能区、主界面、命令
和对话可调用的能力；Pi 扩展只随 Pi Runtime 加载。

## 管理插件

在左侧导航打开“管理插件”。插件的启用状态和权限按当前场景分别保存。

- **安装本地插件**：选择开发目录。此模式只适合你完全信任的本地代码。
- **安装签名插件包**：选择 `.zicode-plugin`。程序先验证全部文件哈希与发布者签名。
- **启用/禁用**：只影响当前场景。
- **回滚**：签名插件更新后可切换到保留的旧版本。
- **撤销发布者信任**：立即移除该发布者插件的活动注册，并拒绝其后续安装。

## 首次信任

签名有效不代表发布者自动可信。首次安装某个发布者时，请核对发布者名称、64 位密钥
指纹和权限清单。只有确认后，该公钥才会写入本机信任库。不要仅凭包内显示的名称判断
来源。

完全信任的本地 Developer 插件可以在 Worker 中注册 Capability 和 Command。命令面板、
插件界面和 Chat 都经 Host Broker 调用；每次调用在无 DOM、网络、文件和环境变量 API 的
独立限时进程中执行。

签名插件的界面运行在隔离 iframe 中。公开第三方后台 Worker 尚未开放；签名不能替代
WASI 或操作系统级沙箱。
