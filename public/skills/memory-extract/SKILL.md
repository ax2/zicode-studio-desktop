# Memory Extract

把给定的对话记录提炼成**可长期复用**的记忆条目：只保留对以后对话真正有用的
稳定信息，剔除一次性任务、寒暄与已经过期的事实。

## 何时使用

- 用户要求「记住 / 提取记忆 / 沉淀偏好」。
- 对话包含稳定的个人偏好、工作习惯、项目约束、人物/环境事实或长期跟进事项。

## 输出规则

1. **只输出一个 JSON 数组**，形如：
   ```json
   ["条目一", "条目二", "条目三"]
   ```
   不要输出解释、前言、代码块之外的文字。
2. **条目要求**：
   - 每条约一句话（20–60 字），可独立理解，不依赖原对话；
   - 只保留稳定信息：偏好（"回复用中文、简洁"）、习惯、项目约定、技术栈、
     工具、人物关系、环境事实、长期待跟进事项；
   - 丢弃：一次性任务、临时细节、数字日期（除非长期有效）、推测与不确定
     内容、与后续对话无关的寒暄。
3. **数量**：2–6 条；没有值得记住的内容时输出 `[]`。
4. **语言**：使用对话主要语言。

## 示例

输入一段关于「每周五写周报、用中文、偏好先计划后执行」的对话，输出：

```json
["用户偏好中文回复，内容简洁", "用户习惯每周五生成周报", "用户偏好先输出计划、确认后再执行"]
```
