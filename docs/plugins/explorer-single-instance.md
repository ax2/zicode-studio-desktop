# Explorer 启动交接与单实例边界

状态：2026-10-13，尚未实现。当前文件、文件夹与盘符右键命令各启动一个新的 Studio 进程；连续打开多个对象可能产生多个 Host、Pi 与托盘图标。此前同一进程内工具窗口复用不能证明跨进程去重。

## 接收条件

1. 第二次启动的文件/目录路径与动作必须由首进程重新验证；不接受来自回调的原始路径作为插件授权，不把绝对路径放入页面 URL 或工具输入。文件读取、目录枚举与写入仍分别由用户确认。
2. `--open-file` 进入原文件父项目的工具会话，保持零自动 Pi；文件意图必须按目标窗口保存，不能依赖次进程内的 `OnceLock`。`--open-folder` 保持当前项目会话语义；盘符根目录保持默认工具工作区语义。不得因为首进程已有 AI 窗口而重用错误的运行模式。
3. 首进程 Host 尚未就绪时应排队并有明确终态；失败应提示用户，不静默丢失 Explorer 意图。并发启动同一项目复用窗口，不重复创建 Host/托盘；不同项目保留各自窗口和会话。
4. 显式 `--isolated-profile` 的验收实例可并存，不向普通配置的首进程交接。正式安装、debug 和 release 的隔离及升级时行为要单独验证，不能跨不同 EXE 或版本错误路由。
5. Windows、macOS、Linux 分别验证启动、激活、退出和崩溃恢复。Windows Explorer 实体右键需覆盖中文/空格/特殊字符文件、文件夹、目录背景与盘符；记录进程树、托盘图标数及截图。

Tauri 官方提供跨桌面平台的 [single-instance 插件](https://v2.tauri.app/plugin/single-instance/)，回调可收到第二次启动的参数和工作目录，且需要优先注册。2026-10-13 本机 `rustc 1.88.0`；当前官方文档声明新版插件至少 Rust 1.90，而 [2.4.0 包清单](https://docs.rs/crate/tauri-plugin-single-instance/2.4.0/source/Cargo.toml)声明 1.77.2。接入前应固定兼容版本并检验现有 Tauri/Cargo.lock 和三个桌面系统；不能仅以添加锁或回调收到参数宣称已完成意图交接。
