# 手动工具调用排查记录

更新：2026-10-11。适用工具中心通用手动调用；不是资源调用日志或正式插件协议。

## 行为

- 请求报告超时、计算额度耗尽、内存访问错误、栈额度或其他执行错误时，展示对应固定提示。连接超时与执行超时分开。
- 错误响应不能证明调用结束；继续沿用[终态证明规则](manual-call-terminal-proof.md)，由用户显式查询 Host 状态后决定后续操作。不会自动解锁、重放、保存或提高 Worker 预算。
- 详情底部折叠“调用排查信息”，记录本次调用标识、Host 标识、插件/能力/版本/运行时，以及最多24条带时间的固定事件和白名单状态码。未知错误统一为 unclassified_error。
- 不采集输入、输出、原始错误消息、文件路径或凭据；不写磁盘。关闭工具清除记录，下次主动执行替换记录。详情渲染失败的恢复界面仍可查看记录。

## 验证证据

18个前端文件99项通过，类型检查及 lint/design 通过；141个已有 warning、9个 info 和既有终端 inline-style warning 保留。

实际 Windows Tauri WebView2 → Host → 生产 JavaScript Worker：Studio 自有合成插件执行循环，约5秒后实际返回 worker_timeout。界面锁定，白名单轨迹记录请求错误；显式查询取得 executionFinished=true/outcome=worker_timeout 后才释放。随后用户主动执行新调用成功，轨迹替换；共3次 invoke，无自动重放或写入。

超时等待期间，冻结且未修改的 DevTools 文本插件 Base64 编码实际 WASI 执行成功；安装包13文件250054B经外部接收摘要核对。它验证故障隔离及一个基本操作，不是整个工具的完整验收。

1440×900浅色与390×844暗色 WebView截图已检查，无新增横向溢出；没有页面异常，1条HTTP500控制台信息对应刻意触发的实际超时。Browser插件不可用，沿用现有Node Playwright连接本轮专属Tauri CDP；未操作OS安全设置或原生对话框。

证据：技术博客档案 iterations/tool-call-diagnostics-2026-10-11，包含原生请求/响应、三个轨迹、截图、运行包摘要、失败记录和进程终态。

## 边界

- 合成成功结果显示 result_profile_unsupported，不具备结果保存资格，本轮没有验证保存/接力。
- 详情渲染失败后的排查入口由单元回归覆盖，未在原生运行中制造渲染故障。
- 前一阶段诊断工具HTTP500根因仍未知；本轮不能反推为相同超时。
- 未覆盖刷新持久化、其他操作系统或真实DevTools全目录算法。154项完整工具验收仍为0。
- 沿用debug EXE和唯一target，无Rust改动/编译、版本号变更或新Release；正式v0.4.2安装包不含本轮开发改动。
