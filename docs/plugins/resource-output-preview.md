# 插件资源输出的受控预览

2026-10-10；内部 `resource.wasi.output.draft1` 候选。Studio 通用父级能力，不代表 DevTools 图片算法或完整工具目录验收。

## 用户流程

在 Studio 可信控件选择文件和接收工具，点击确认共享；独立插件执行完成后显示输出卡片。用户点击预览时才读取结果。卡片说明结果尚未保存。左侧导航不增加输出或工具图标，工具仍从统一工具中心搜索、分类、收藏和最近使用进入。

可信父级和隔离 View 仅收到白名单描述符，包含资源 ID、摘要、MIME、长度、来源关联和过期时间；不传凭据或路径。未知 profile、错误关联、重复 ID、非法长度、超过四项/32MiB 的结果均拒绝转发。旧 JSON 结果路径保持兼容。

## 预览限制

| 类型 | 限制与展示 |
| --- | --- |
| text/plain | 最多128KiB，严格 UTF-8，纯文本，不解析 HTML |
| application/octet-stream | 最多8MiB，全量摘要校验，只显示前256字节十六进制 |
| application/x-zicode-archive-* | 最多8MiB，全量摘要校验，只显示前256字节十六进制；不解压内容 |
| PNG / JPEG / WebP | 编码最多8MiB，单边4096、总像素4Mi；先检查头和结构预算，再浏览器解码为新静态 PNG |
| SVG / HTML / 动画 / 其他格式 | 不支持；不能由声明 MIME 绕过图像检查 |

归档的受控保存和下载扩展名见[归档输出类型 draft1](archive-output-types-draft1.md)。

读取分块最多32KiB，逐块核对偏移/长度/结束标记，并验证完整SHA-256。原始图片不直接交给图片标签；浏览器解码后绘制到新 canvas，显示其 PNG Blob。结构检查不是完整媒体安全证明；浏览器解码器仍是依赖。峰值内存、其他OS/WebView媒体兼容性尚未测量。

关闭预览释放 Blob URL 和可见内容；重新执行、取消共享、切换会话或卸载 View 清理旧状态。关闭不撤销仍有效的 Host 结果，用户可重新预览。关闭阻断后续分块及迟到展示，已有一个 HTTP 分块可能完成。

显示时每5秒读取一个字节复核 Host 授权。源资源撤销、过期或权限变更导致后续读取失败时清空显示并提示；这不是即时撤回已复制像素的保证。Host 的同 owner 派生资源链、权限与生命周期规则继续适用。

## 验证与边界

前端37项定向测试通过，含元数据白名单/来源拒绝、摘要/范围/UTF-8、头部尺寸预算、按需读取、URL释放、迟到结果和授权复核失败。`bun run check` 通过，既有警告保留。实际环境证据持续写入[阶段档案](C:/Users/ax2/Documents/技术博客/zicode-studio-desktop/iterations/resource-output-preview-2026-10-10/work-log.md)。

实际浏览器辅助按环境显式启用，在真实 HTTP Host 测试中安装 Studio 自有复制插件，复用生产 Worker EXE，加载生产父级模块。它不修改冻结提供方包；不等于独立原生 GUI、Pi 自主调用或 DevTools 工具算法验收。

跨工具资源传递必须定义新的用户确认授权；保存必须另行准备并确认写入。本模块不授权跨 owner 读取或写盘。纯资源而无非空 JSON 结果、实际提供方资源包、完整源 scope、持久审计/幂等和其他OS仍待推进。

实现拆分为输出引用、读取、图片和预览模块；大型 `plugin-view-host.js` 只接线生命周期，保留其既有其他工作。

后续进展：Host 已有[跨工具两步授权候选](resource-transfer-candidate.md)及真实 Worker 间输出共享证据；本预览界面尚未增加接收工具搜索/确认/交付入口，不能把 Host 接口通过记为用户交互通过。
