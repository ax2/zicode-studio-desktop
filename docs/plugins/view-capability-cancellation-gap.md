# 插件 View 普通能力调用取消：接收侧状态

2026-10-18 View 源加载的签名校验和 HTML 读取已移出全局插件注册表锁，完成后复核启用状态、安装快照及目录修订。真实 HTTP 故障隔离用例通过，慢盘并发、签名实包、原生窗口与跨平台仍待验收；见[阶段记录](../iterations/2026-10-18-view-source-read-isolation.md)。

2026-10-18。Studio 可信父页现为 `zicode.capabilities.invoke(capabilityId, input, { signal })` 复用现有 `manual.tool.call.v1`，提供方无需引用 Studio 代码或修改独立程序。此实现仍未完成正式 DevTools 工具验收。

## 已实现

- 当前 Host 的 View 源响应携带 `catalogRevision`；View 实例保存加载时的修订。每次能力调用以此修订读取能力详情，核对插件版本和能力 ID，再由 Host `prepare-call` 发放单次句柄。插件安装、启用状态或权限变化会使旧修订失效，旧帧不会换取新修订绕过校验。旧 Host 不携带修订时，可信父页按已有目录接口取修订并检查版本。
- `prepare-call` 的详情校验按插件/能力 ID 查声明，不要求它出现在当前目录搜索页。真实 Host 专项验证：搜索结果 0 项，按同一修订取到声明能力，成功准备句柄，取消返回 `cancel_requested`，状态仍为非终态；随后禁用插件使旧修订准备失败，但不阻止对既有句柄再次请求取消。普通工具中心不支持的复杂表单不妨碍 Host 校验有效输入。
- 调用前或准备期间取消，不启动 Worker；运行中取消请求交给 Host。用户取消、View 卸载、目标切换和前端超时均尝试取消。取消 ACK 不是执行终态，迟到成功仍交付真实结果；传输超时标记结果未知，并请求 Host 停止。
- 旧 Host、没有工作区目标或不支持该运行时仍沿用旧调用路径；工作区 ID 已给出但 Host 不认识时直接报错。显式传入 `AbortSignal` 时，无法提供 Host 取消则拒绝执行，不假称可取消。插件 iframe 只传请求 ID 和取消意图，看不到 Host 令牌、调用句柄或目录修订。

## 待验收与限制

- 新 View 源修订字段及取消流程已通过代码与合成 Host/前端专项；复用本项目 Debug EXE 的真实 Host/Worker 专项也验证了运行中取消、终态、进程回收及管道关闭。尚未用正式提供方包和新版原生 Tauri 窗口完成“发现→加载→执行→取消→结果”链路；Host/Worker 证据不能自动代替原生 View 交互验收。
- 旧 Host 的 View 源缺修订时，可信父页只能在调用时查当前修订；同版本重装发生在旧帧首次调用前，仍缺加载时安装代次证明。更新 Host 的 `catalogRevision` 绑定解决该路径，但跨版本旧 Host 不具备同等保证。
- 可信父页从单次句柄发放后跟踪调用，并在传输响应丢失时展示状态查询/再次请求停止。同一 Studio 页面会话内，View 卸载、重建与目标切换后，同一 View/场景/运行目标的调用记录仍留在父页，重新打开时显示；旧 View 的迟到响应会更新新面板，但不会把业务结果误交付给它。状态未证实结束时，同一 View 的同一能力禁止再次执行；原响应尚在路上时，即使查询到 `finished` 也要等原响应。响应已丢失时，只有 `finished` 或同一 Host 实例的有效对账证明能解除锁定。完成后的执行结果无法从状态接口取回，界面明确要求核对实际效果，绝不自动重试。关闭/重启 Studio 后这份父页内存状态不持久，跨重启对账与结果恢复仍待协议扩展；不能将本项视为持久恢复。
- 页面卸载/刷新前，父页对仍锁定的 View 普通能力调用设置 `beforeunload` 提示；原响应交付或有效终态解除锁后不再提示。当前 Windows 工作区窗口普通关闭会隐藏到托盘并保留 WebView；托盘“退出 ZiCode Studio”由原生 `app.exit` 触发 Host 清理，不保证触发页面 `beforeunload`。因此本提示不构成托盘退出确认或跨进程恢复证据。
- `manual.tool.call.v1` 只覆盖已登记工作区中的外部 Worker/WASI 能力；内建同步能力、模型生成、HTTP GET 和资源工具各有自己的生命周期合同。旧路径的取消语义保持不可保证。

完整 ZiDevTools 接受仍为 0/154。用户选择暂不启用的隔离 JSON 对象插件与 `pi.tools.register` 保持原状态。状态面板的原生窗口截图与真实点击仍待验。
