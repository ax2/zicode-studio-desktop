# 从工具结果打开已保存产物

2026-10-11，日常开发版本0.4.2；尚未进入正式发布安装包。

## 实现

通用文本结果保存控制器在用户预览并确认保存后，显示“查看已保存产物”。
点击才切换到产物中心并读取这次保存返回的精确产物ID；保存成功本身不跳转。
导航不执行工具、不重复保存、不向模型发送内容。已有预览、取消及幂等保存协议不变。
手动工具和隔离插件View的可信父界面共用该控制器。

事件只携带有界产物ID和来源场景/工作区。控制器销毁、切换工作区、产生新结果后，
旧按钮失效。主界面在页面切换完成后再次核对工作区与激活状态；被拒绝的页面切换
不继续读取详情。历史不带作用域的产物入口仍限于当前工作区，并复核切换期间的目标。

真实验收发现产物中心首次挂载时的目录读取会使详情读取失效。
列表与详情现使用独立请求序号，共同维护加载状态；目录刷新不覆盖新选择，
筛选改变显式撤销旧详情，工作区改变和销毁使两路迟到响应失效。

## 已验证

- 25文件160项前端专项通过，覆盖产物中心、工具中心、保存/传递控制器、View Host及导航守卫；
  类型检查、React构建与lint/design检查通过，既有warnings保留。
- Windows实际Tauri WebView2、真实Host/WASI、独立测试配置：Base64执行一次，
  两次预览（第一次取消），确认保存一次，点击打开精确产物一次。
  保存前后未自动导航；错误工作区事件零详情读取。实际内容及来源元数据一致。
- 最终页面/控制台错误与警告0；1440×900浅色、390×844暗色截图已查看。
  窄屏正文纵向滚动可达，代码内容在自身区域横向滚动，页面无横向溢出。
- 收到的文本插件13文件、250054字节与外部收据SHA-256一致；该核对为字节完整性，
  不冒称新增签名验收。首轮详情超时失败记录与截图保留。
