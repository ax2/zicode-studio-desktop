# 文件摘要资源执行草案

`resource.wasi.file-digest.v1`，版本 `1.0.0-preview.1`，当前为本机实现候选，必须先完成实际最大输入、并发和取消验证，不能把草案当作已交付承诺。

该能力使用经逐次确认的 `resource.wasi.input.draft2` 文件快照和 `resource.wasi.output.draft1`，不暴露路径或写权限。一次1–4项，总共最多32 MiB，允许空文件。每项按输入顺序返回 SHA-256、SHA-512、字节数以及可选的预期摘要比较。Host 在接纳成功结果前将返回的 SHA-256 与授权快照的内容版本、文件数、顺序和字节数逐项核对；不允许派生资源或附加字段。错误消息由Host归一化。

执行策略候选为256 MiB guest内存、80亿 fuel、30秒，受现有重资源池约束（全局最多两项、每插件最多一项），沿用宿主授权失效和显式取消的终止逻辑。该预算必须使用真实 Worker 对32 MiB单文件、四文件合计32 MiB、并发、取消、权限撤销和边界拒绝验证，失败则保留证据并重新评估，不能只凭声明标记可用。

该快照方案不提供物理文件实时进度，最多4项，不等同独立版的64文件、后台进度、文件身份变化检测或报告/文件引用接力。未知大小或需要更大文件时应先定义独立的流式文件授权接口，不放宽通用权限或悄悄执行独立程序。
