# 接力接收工具的收藏和最近使用

2026-10-11；Studio 开发版0.4.2，正式发布安装包不包含本轮改动。

## 行为与内部接口

“发送到工具”提供全部、收藏、最近使用。收藏与最近沿用当前场景和项目的工具中心记录，只展示能够接收当前文本结果的字段；浏览不执行工具。切换列表保留搜索词并回到第一页，预览中的更换接收工具保留当前列表和页码。

桌面 Host `/v2/plugin-results/targets` 增加可选 `view`（`all`默认、`favorites`、`recent`）及 `accessRevision`。工具身份与工具中心共用 `manual.tool` 摘要。Host 对全部兼容字段先筛选与排序，再以20条分页；单工具多个兼容字段分别占一条。响应包含 `accessRevision`，全部列表为null。后续页必须提交目录 `revision`；个性化列表还须提交 `accessRevision`，包括0。

目录修订绑定来源证明、插件目录/权限、工作区、查询、列表类型和工具访问修订。变化拒绝旧页，界面提示用户重新搜索，不自动重试。个性化列表只读取已登记工作区的记录，元数据失败显式报错，不退回不准确的本地筛选。旧的全部列表请求格式保持；旧Host不支持新增列表时显式失败。

此扩展属于Studio内部桌面接口，没有改动提供方插件协议或冻结包。执行仍须选择字段、预览并明确确认；保存/写入沿用单独确认。
