# 工具详情界面异常隔离（2026-10-10）

## 已实现

工具目录中每个打开的工具独立包裹React异常边界。一个详情的渲染或React生命周期错误只卸载该详情的内容，其他工具的输入、结果及目录状态保留。错误卡片使用通用中英文提示，不显示原始异常或业务输入；可返回目录。异常后清除该工具的本地busy标记，允许明确关闭；这不是Host取消成功证明。

故障卡片不提供自动重试，不随切换工具、目录或翻译重新挂载。用户明确关闭并重新打开才重新加载；按场景/工作区/工具身份隔离生命周期。组件卸载沿用原有手工调用cancel和资源控制器销毁语义，无法确认后台停止时提示“可能仍在执行或已经完成”，不自动重放可能有写入影响的操作。

共享React入口vendor.ts显式导出Component，避免源码测试使用完整React而实际import map缺导出。vendor.test.ts防止该导出回归。
