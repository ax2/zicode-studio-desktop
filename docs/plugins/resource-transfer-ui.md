# 资源输出转交界面（内部候选）

Studio 可信父级界面在每项资源输出旁提供“发送到工具”。左侧导航保持统一工具入口；接收端使用已有工具目录，不为每项能力增加图标。

## 交互与边界

1. `GET /v2/plugin-tool-directory?resourceOnly=true` 仅返回当前场景已启用、声明并获准 `resource.read`、选择 `resource.wasi.input.draft2` 的 WASI 工具。每页最多40条；名称、别名和描述沿用目录搜索。目录只读元数据，不加载模块、不启动 Worker。默认目录请求保持兼容。
2. 选中接收端才按目录修订读取声明并挂载已有通用参数表单。支持平面字符串、整数、数值、布尔、枚举及现有约束；保留 false/0，未编辑的可选字段省略。不支持的嵌套/复杂 schema 明确提示，不静默丢约束。
3. 检查共享范围展示目标插件、工具、版本、MIME和字节数。准备不授予目标读取权；取消不确认。确认仅交付当前会话中此项输出的目标专属引用，不代表同意执行或保存。票据60秒失效由Host复核。
4. 用户检查参数后单独点击运行。使用现有真实资源 Worker 调用、独立取消请求、严格输出规范化和可信预览。错误采用固定提示，区分超时、取消、授权变化；不透传任意服务端消息、不自动重试。
5. 关闭/换工具/换输入/换会话销毁表单、预览并取消正在执行的调用。延迟确认返回后撤销新引用；执行中的引用等响应结束后回收。结果可见时每5秒复核授权；来源链失效清除结果，不等于立即收回已经复制给Worker的字节。

Host准备、确认、执行仍各自核对真实模块和权限。目录可见性只是筛选，不是授权凭据。传递不写盘、不开放任意路径、不启动独立DevTools应用，不向不可信iframe开放转授权接口。
