# 资源输出发布边界

2026-10-10，内部资源输出候选实现修正；不改变公开profile支持列表、请求字段或Worker ABI。不代表正式resource.v1或DevTools图片工具接受。

## 两阶段发布

Worker成功退出、管道回收、完整原始帧验证以及结果输出契约校验后，将输出ID/摘要/描述符和内存记录准备在独立Pending对象中。这一准备过程不持有资源库锁，不插入库、不返回ID。单次仍最多4项/32MiB，最多两个在途资源计算；不新增磁盘缓存或排队。

准备完成后重新校验当前运行会话/凭据/插件/权限/模块证明。随后锁定资源库，复核源资源及祖先链仍已确认且未撤销/过期、当前32条/128MiB共享配额，最后检查取消标志，再整组插入。摘要和大字节副本处理均已完成，锁内不重新摘要整个输出。任一拒绝均丢弃Pending，不能留下部分资源或其ID。准备期间其他请求新增资源占用配额会在最终发布时反映，不能依靠早期容量检查。

发布前取消时，Worker可能已退出，cancel-view仍返回requested/executionFinished=false，因为父级调用尚未结束；父级丢弃未发布结果、退出后再次查询才为finished。已发布后到达的取消不保证撤回已复制字节；可通过原资源撤销链阻断后续读取。最终取消检查是发布提交点的一部分，不能据此声称覆盖所有指令级竞态、外部文件原子历史或用户写盘恢复。

## 真实环境验证范围

增强原真实HTTP专项，在测试构建内的output_prepared观察点暂停：生产EXE的Worker已回收/管道已结束，2MiB完整输出完成准备，但库记录数尚未增加。测试同时检查资源库可获得锁。分别触发：

| 情况 | 预期 |
| --- | --- |
| cancel-view | worker_cancelled，零输出登记，调用结束后释放槽位 |
| 源资源revoke | resource_unavailable，零输出登记 |
| 目标resource.read撤权 | permission_denied，零输出登记 |
| 目标插件禁用 | resource_plugin_unavailable，零输出登记 |
| 运行时凭据世代变化 | resource_authorization_changed，零输出登记 |
| 准备后用其他请求填满记录数配额 | resource_budget_exceeded，整组拒绝 |
| 无关插件权限变化 | 原输出成功登记，不误伤本次结果 |

每项独立启动一个Worker，检查发布前已回收和管道结束、最终槽位释放/父级调用finished；失败不返回resources、不增加记录。每项使用新的自有输入授权并清理自身资源，后续无关变更场景成功也证明调用恢复。观察点仅在Rust测试构建启用，生产Host不含暂停开关或测试授权绕过。

完整测试终态与当前EXE摘要见技术博客iterations/output-publication-2026-10-10；普通19项资源测试与显式ignored真实环境专项分开计数。原2MiB读回/链式执行/输出schema/失败丢弃及旧JSON生命周期回归仍保留在同一专项。以上是发布前确定性注入，既不是DevTools真实算法运行时中断，也不是原生GUI/Pi用户交互或所有OS接受。

## 仍待

可信预览/媒体检查、跨owner用户确认的工具传递、确认保存与冲突处理、资源结果幂等和持久审计、实际DevTools包、原生GUI和其他OS。真实运行中凭据失效/超时、发布最后指令窗口的取消、真实进程清理失败注入、128MiB字节配额在HTTP层竞争和低端峰值仍待进一步验证。测试恢复旧凭据是夹具复原，不是产品可恢复旧授权的承诺。源模块摘要仍不是外部文件系统历史的原子证明。
