# 通用工具表单展示约定

Studio通用工作台按已支持的平面标量schema生成输入；展示层改进不扩展schema验证能力、权限、输入输出或执行协议。提供方继续独立维护算法和完整应用。

## 字段顺序与说明

- 必填字段先显示，同组保持manifest中properties声明顺序；required数组的顺序不改变字段顺序。
- title作为字段标签；缺失时用原字段key。description以纯文本显示，并通过aria-describedby关联输入。不要在其中放凭据、HTML或可执行代码。
- Studio展示必填/可选提示。未编辑的可选字符串仍省略，明确编辑为空字符串仍提交空字符串；数值、布尔和枚举沿用各自准备规则。default只是注解，不自动注入输入。
- 有效、单行且不超过80个字符的标量default可显示“填入声明的默认值”按钮；点击只修改对应输入框，不执行工具。无效、超限、结构化或含控制字符的default不提供快捷填入。用户未点击时仍省略可选值；Host继续验证实际提交值。见[2026-10-17阶段记录](../iterations/2026-10-17-declared-plugin-defaults.md)。
- 显示排序不改变稳定能力ID、输入key、权限或工具版本；输入验证仍拒绝不支持的结构与约束。
- title/description应使用用户能理解的业务说明。诊断包目前secondary标签缺少语义、description主要为英文技术预算；请在后续独立版本注明比较对象/补充报告用途。不得修改已冻结候选，也不在Host按工具ID推断业务。

## 输入与执行结果导航

有成功或业务错误结果后，输入区出现“查看最近执行结果”，结果区提供“返回输入”。显式点击才滚动并移动焦点；完成执行不会自动滚动或抢焦点。跳转不执行工具、不保存数据、不产生历史记录。

新的执行先清除旧结果；取消、Host失败和未确定执行沿用既有调用状态规则，不显示旧成功结果。业务错误可定位并返回修改，输入保留。保存/发送仍沿用预览和显式确认。

跳转目标保留顶部留白，避免窄窗口悬浮控件覆盖入口。其他OS、屏幕阅读器和深色主题的本改动仍需分别验收，不能由Windows浅色截图推断通过。
