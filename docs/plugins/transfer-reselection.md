# 工具接力预览中的修改与重选

2026-10-11，Studio日常开发版0.4.2，未新增正式Release。

## 实现

- 发送预览增加“更换接收工具”，返回来源结果的同一查询、页码和目录修订，
  搜索框恢复焦点。返回后仍需选择字段、预览并明确确认；返回不执行工具。
- 多字段接收表单显示所选工具和映射字段；预览可“修改接收工具输入”，保留该次
  显式填写的草稿。修改后重新申请预览，不沿用旧确认。更换工具不隐式传递补充草稿。
- 确认执行期间禁用重选和修改；业务失败可改选，历史预览、表单与目录按钮失效。
  主结果、工作区作用域、双端权限与幂等协议沿用现有Host，不修改冻结提供方包。
- 真实View验收发现默认浏览器离开确认返回取消而未出现可操作提示。
  Studio插件离开确认现复用应用内对话框，默认“否”；取消/Escape保留输入。
  有其他Pi/用户对话框时不覆盖它，保守取消本次离开。明确“是”才继续导航。
