# 多工具切换与窄屏布局

工具目录集中搜索、来源/分类筛选、收藏与最近使用；只有打开工具才加载详情。
左侧保留一个工具入口，不按插件能力增加图标。打开的工具最多八个，切换不会重新执行或丢弃输入与结果。

已打开工具栏使用单行横向滚动，完整工具名保留在按钮的可访问名称及 title 中，窄屏长名仅在视觉上截断。
选中工具或调整窗口宽度时，只调整切换栏自身的横向位置，不移动整个表单、不抢焦点。
目录按钮回到切换栏起点；原有关闭确认及未确认执行的关闭保护保持。
键盘可使用 Tab 移动与 Enter 激活原生按钮。资源输入控件的边距计入容器布局，不再因满宽控件加外边距而出现横向滚动条。
