# 模块快照与证明的有界读取

2026-10-10。适用于Studio内部WASI结果证明、保存/接力来源复核、资源计算模块捕获和授权监视。不更改公开输入输出协议、权限、resource草案或应用版本策略。

## 行为

1. 打开文件后，从该句柄检查普通文件及长度，拒绝空或超过2MiB的模块。
2. 根据句柄长度分配固定缓冲区，容量为预期长度+1，最大2MiB+1。读取期间不能随文件增长扩容；多读一个字节足以拒绝超限/增长。
3. 实际读取长度必须等于预期长度；再次检查该句柄的长度，拒绝观察到的长度变化、短读和IO失败。固定码向调用者返回，不附带路径或原始异常。
4. 已捕获并借用的模块字节也检查非空和2MiB限制，随后才计算证明摘要；不会为了校验复制整份借用快照。

结果证明维持result_source_integrity；资源捕获维持resource_module_unavailable。资源Worker运行时若当前模块超限，授权监视取消原调用，清理进程和管道，并阻止旧结果交付；恢复模块后必须通过当前授权和新调用验证。

打开后路径被替换，不会让同一次读取切换到新路径目标；后续独立读取取得新的句柄。此行为不等于文件系统原子快照，也不宣称解决打开前路径替换、同长度并发覆写或所有网络文件系统竞态。已有包/路径完整性检查、模块摘要证明和交付前复核继续保留。

## 验证范围

专项覆盖1字节与恰好2MiB、空/超限/短读/增长、持续供数读取器的读取上限，以及实际临时文件在长度检查后增长和打开后路径替换。实际结果证明检查磁盘与借用快照一致、拒绝空/超限借用字节。保存确认/幂等/接力和资源授权回归保持。

真实HTTP Host与Studio自有WASI环境专项增加module_oversize场景，与原六项失效一起验证主动取消、同PID回收/管道结束、无旧结果和恢复执行。专项终态与更新EXE摘要以技术博客iterations/bounded-module-proof-2026-10-10为准；不能将忽略项当成通过。

仍待：其他OS/网络文件系统、同长度并发写入与打开前路径替换的额外保证、低端性能/峰值内存、按插件作用域证明修订、真实图片/文件工具及完整资源结果流。154项完整工具接受计数不因底层读取改进改变。
