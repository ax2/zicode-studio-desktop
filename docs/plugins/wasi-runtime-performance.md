## 配置与不变量

`src-tauri/Cargo.toml` 的dev profile仅将 `cranelift-codegen` 与 `regalloc2` 两个运行时编译热点依赖设为 `opt-level=2`。test继承同配置；应用保留debug=1与incremental，release配置保持原值。首次重建依赖及相关产物，此后固定配置、复用根target，不按阶段切换参数或新建缓存。

没有改变Worker五秒预算、fuel、guest内存上限、输入输出大小、权限校验或子进程隔离；没有新增磁盘模块缓存、反序列化机器码或提供方依赖。每次执行仍在独立Worker中冷编译模块，因此多工具频繁执行的成本尚未彻底解决。
