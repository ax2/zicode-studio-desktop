# 产品化路线图 M0–M6

> 本页保留早期 Agent 工作台路线图的历史记录。当前持续目标与待验收项见
> [开发者个人平台推进计划](developer-platform.md)，本页的“已完成”不代表整体平台目标完成。

更新时间：2026-08-01

产品定位：本地优先、可审计、能把对话转化为持续项目成果的 Agent 工作台。

## 阶段与验收

| 阶段 | 目标 | 当前状态 | 关键验收 |
| --- | --- | --- | --- |
| M0 | 稳定与透明 | 已完成 | 统一失败/重试；后台状态可见；模型费用可比较；会话预算硬拦截；中英文完整 |
| M1 | 项目工作区 | 已完成 | 项目说明、默认场景与预算；会话、笔记、文件、产物聚合；项目活动与搜索 |
| M2 | 全局任务中心 | 已完成 | 全局状态、失败恢复、会话跳转、取消、权限与预算、通知 |
| M3 | 知识闭环 | 已完成 | 研究卡片、引用、反链、相似笔记、冲突视图、上下文包 |
| M4 | 金融产品化 | 已完成 | 研究模板、观察列表、事件、证据/失效条件、来源报告、组合风险 |
| M5 | 自动化 | 已完成 | 配方、调度、成本上限、审批、重试、运行历史 |
| M6 | 发布/同步/生态 | 已完成（仓库受门禁） | Astro 发布、增量同步、Credential Broker、Worker 控制、WASI、仓库门禁 |

依赖顺序：M0 → M1 → M2 → M3；M4 使用稳定底座；M5 依赖任务中心、预算和审批；M6 最后开放同步与第三方生态。

## 成功指标

- 首个有效任务少于 5 分钟。
- 长操作在 15 秒内进入成功、可见进度或可恢复失败。
- 模型错误的一键恢复率高于 70%。
- 30% 的有效会话转化为笔记或产物。
- 查找旧结果少于 20 秒。
- 超预算请求拦截率 100%。
- 崩溃恢复率高于 95%。

## 非目标

- 当前阶段不接入真实券商或自动实盘交易。
- 没有端到端加密与冲突协议前不开放云同步。
- 没有 WASI 或等价 OS 隔离前不开放公共插件市场。
- 不继续增加互相孤立的内置插件或更多导航层级。
