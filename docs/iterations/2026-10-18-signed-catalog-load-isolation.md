# 2026-10-18 签名插件按需加载隔离

## 发现与修改

Pi 按需加载目录详情时，原实现持有全局插件注册表锁并逐文件校验签名安装目录。磁盘读取较慢或包损坏时，这段同步工作可能让其他插件请求等待同一把锁。

Studio 现在在锁内取得工具详情、版本和签名包身份快照，释放锁后用阻塞任务校验签名文件；校验完成后重新鉴权，并复核目录修订、工具身份与安装快照。校验期间若插件被替换或运行时身份变化，请求拒绝旧详情。未签名开发插件沿原有目录协议加载，不增加提供方协议字段。既有注册表签名验证复用同一快照校验逻辑。
