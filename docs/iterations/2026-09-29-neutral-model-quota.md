# 2026-09-29 通用模型额度提示

## 目标与发现

- 聊天错误解析对额度不足采用通用匹配，但标题与建议固定提及 QVeris。用户使用其他渠道时会得到错误的服务商提示。
- 原摘要把所有这类错误都表述为“预扣费”失败；其他兼容渠道未必采用预扣费机制。

## 修改与决定

- 额度不足标题、摘要和建议改为当前选中模型服务的中立措辞，不推断特定服务商收费结果。
- 保留已有 QVeris 错误识别，同时识别常见的 `insufficient_quota`、`insufficient balance` 和 `insufficient credit`；只在错误文本实际包含余额和预扣数值时展示指标。
- 中英文帮助说明按当前渠道核对余额或额度。专用 QVeris 适配器及金融工作台不受影响。

## 验证与遗留

- 本轮运行 TypeScript、静态规则、翻译覆盖和 React 构建检查；未运行测试或真实上游请求。不同服务商错误格式仍需在实际连接中积累证据。
- 仅更新本地工作树，未发布。
