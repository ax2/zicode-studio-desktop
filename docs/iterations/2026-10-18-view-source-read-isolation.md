# 2026-10-18 插件 View 源读取隔离

## 发现与修改

Studio 的 `/v2/plugin-views/source` 原先在持有全局插件注册表锁期间核验签名安装包，并读取 View HTML 文件。文件读取变慢或失败会延长其他插件请求等待注册表的时间。

接收端现先在锁内确认场景启用状态、View 声明和安装身份，取得轻量快照；锁外的阻塞任务负责签名校验、路径检查和 HTML 读取。返回前再次核对启用状态、安装身份与手动工具目录修订；期间变化则拒绝旧 View。原注册表直读包装方法只保留在测试编译中，提供方 View 协议不变。

## 验证与边界

`bun run check:rust:static` 通过，整仓 fmt 仍有既有 advisory；新增的 View 快照文件单独格式检查通过。真实 HTTP View 源定向测试 1/1：禁用拒绝、启用读取、其他场景拒绝、文件损坏返回 422 后插件列表仍返回 200。注册表 View 文档测试 1/1 通过。
