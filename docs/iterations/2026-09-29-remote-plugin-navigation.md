## 目标与发现

- 已配对远程端不能读取外部插件视图，也不能执行其 Worker 命令，但插件 Shell 仍把开发者和签名插件列在活动栏、移动菜单、数字快捷键和命令面板。
- `?app=<pluginId>` 深链与程序化激活仍可进入这些远程不可用页面。

## 修改与决定

- Shell 根据原生桌面身份统一判断插件可用性：远程端保留内置插件，隐藏外部插件的活动与命令入口；桌面端保持全部已启用入口。
- 远程外部插件的深链回退聊天并显示桌面端说明；直接激活与历史导航也回退聊天。插件管理页仍显示只读清单。
- 本轮未新增或运行测试。
