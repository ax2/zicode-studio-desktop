# 工具目录直达后的最近使用记录（2026-10-18）

## 目标与发现

工具中心从目录打开外部插件工具时，旧流程在调用 `openTool` 之前就写入项目最近使用。此时插件 View 可能尚未加载、拒绝该能力定位，或 5 秒内没有回执。因此“最近使用”可能包含实际没有打开的工具。

## 修改

- `PluginViewHost.openTool` 接受可选成功回调。只有当前主 View、请求 ID、插件版本和资源目标匹配，且回执状态为 `opened` 时才调用一次；失败、超时、重复或旧工作区回执均不调用。
- 工具目录的 `recentRecord` 移至该成功回调，并在记录前再核对工作区与插件版本。未更改插件运行权限、执行能力或提供方代码。
- 用户已选择暂不启用 JSON 对象插件，未改变其启用状态及 `pi.tools.register`。

## 同日续验：Studio 外壳记录时机

新增外壳集成断言：从工具中心两次进入应用，第一轮在确认前切换工作区，旧回执不写 `recentRecord`；第二轮当前工作区确认后只写入该工作区，且未执行工具。首次测试失败由夹具等待到上一轮 `openTool` 调用导致，改成等待调用次数增加后 37/37 通过。这补上了此前只有 View Host 回执单元测试、未覆盖外壳历史写入的证据缺口；仍非原生 View 实体操作。
