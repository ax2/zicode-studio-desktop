# v0.7.9 · HTML 实体文件转义与还原

工具中心的「HTML 转义」和「HTML 还原」可分别导入 8 KiB 以内的 UTF-8 文件，选择器优先显示 `.html`、`.htm` 和 `.txt`。保留正文换行和字节内容，UTF-8 BOM 作为编码标记读取。取消或读取失败时保留草稿，导入可撤销。

手动执行后，选择「下载转义后的文本」或「下载还原后的文本」获得同次完整 TXT。两种模式保留冻结工具对 `&amp;`、`&lt;`、`&gt;`、`&quot;` 和 `&#39;` 的实体转换规则。转换结果在文本区域显示并以纯文本写出。

每个方向独立使用 8 KiB 输入约束，扩展后的完整文本可能超过另一个方向的文件上限。

## Windows 验证

- 使用冻结 Transforms 0.1.1 候选 01 和生产 Windows Worker。804 文件、隔离 Windows Host 和本机 Pi 工具通道对 23 个固定样例及十个权限阶段的验证见[同包验收](2026-11-25-line-tool-files.md)。
- 正常工具中心 1180px 英文浅色和 420px 中文深色共运行生产 Worker 14 次，12 次成功、2 次预期超限拒绝。普通文章标记的五种实体可从实际下载的 TXT 逐字节还原。未知字符引用按既有语义保留，空结果可下载。实际结果区域无文章 DOM，未观察到外部请求。
- 两种入口各实测完整 8192 字节输入。编码扩展结果完整下载 40,945 字节，SHA256 `f2160b9f9d7556383bf8a6cf3da37e4ec788e6e947069fb6efe571d1f7f69fd5`。十二份 TXT 逐字节等于同次 Worker 文本。覆盖取消、撤销、无效 UTF-8、修改和失败后旧下载失效，源文件的 BOM、CRLF 与尾部空白经回读保留。
- 单独用原生产 Worker 实测 8192 个 ASCII 双引号，膨胀后的结果因 48 KiB 输出上限被明确拒绝，业务码为 `INPUT_TOO_LARGE`，无可下载正文。
- 66 项前端、4 项矩阵通过，8 项既有跳过。TypeScript 与词条检查通过。工具中心资源 SHA256 `034ab5237e3b75dc8ba14832455415fb07db574a51bb39e3f38067acba6e16c8`。
