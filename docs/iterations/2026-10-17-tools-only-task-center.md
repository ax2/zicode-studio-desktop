# 工具专用会话任务中心隔离（2026-10-17）

## 目标与发现

上一轮 Windows Debug 截图显示：插件任务概览正常，但工具专用会话仍读取 AI / Super Agent 任务，整页出现 `TOOL_SESSION_AI_UNAVAILABLE`。工具专用启动本来不运行 Pi；任务中心应遵守 Host 提供的 `runtimeMode`。

## 修改

- 任务目标和任务中心 store 纳入 `runtimeMode`。工具模式不读取 AI 项目或任务，也不启动 AI 任务轮询与调度。
- 工具模式只显示插件任务导航和只读插件任务概览，说明切到 AI 会话后可管理 AI 任务；从工具模式切回 AI 模式时恢复相应读取与轮询。
- 补充中文文案和模式切换测试。没有扩展插件任务提交、执行、取消或结果写入权限。

## 验证

- 任务中心相关前端测试 56/56 通过；`bun run typecheck`、`bun run check`、中文词条覆盖检查通过，缺失词条 0。
- `bun run build:local` 成功，复用现有 `target/debug` 和 Pi 1.3.0 等运行资源；没有发布新版本、生成 Release 或 ZIP。
- 使用隔离 profile 和 `--tools-only` 启动当前 Debug EXE，实际 Windows 窗口截图检查到“任务中心”标题、工具会话说明和插件任务空状态；未出现 AI 任务错误。截图只证明空状态渲染，不证明真实插件任务可执行。测试进程已按命令行和 EXE 路径核对后关闭。
