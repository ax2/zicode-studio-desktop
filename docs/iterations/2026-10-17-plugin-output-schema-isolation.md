# 插件输出声明与 Worker 输入边界（2026-10-17）

## 目标与发现

Studio 面向独立插件提供方校验 `output.schema.v1`。前一阶段收紧输入声明后，
输出声明仍递归调用输入声明检查，导致输出协议本来支持的 `oneOf` 被误判为
不支持。现有结果协议测试复现了两个失败。另一个易误导之处是通用 Capability
入口检查 16 MiB，却报告“256 KiB”；真正独立 Worker 请求仍为 256 KiB。

## 修改

- 输出声明由自己的白名单和递归规则校验，不再套用输入关键字白名单；保留
  `oneOf` 结果校验。
- 明确拒绝重复 `required`、重复联合 `type`、空 `enum` 和错误注解类型。
- 通用 Capability 超限提示改为 16 MiB；协议文档区分它与完整 Worker 请求
  的 256 KiB 上限。没有提高 Worker 请求预算，大文件仍须使用受控资源协议。
