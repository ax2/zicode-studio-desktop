# Stage：插件声明默认值的显式填入

日期：2026-10-17。只修改 Studio 通用工具表单，不修改 ZiDevTools 提供方或冻结插件包。

## 发现与修改

ZiDevTools 图片缩放 0.1.1 声明 `webp`、`1600`、`82` 三个标量默认值。原生通用表单仍留空，用户每次需手动输入。schema 的 `default` 是注解，不能在未编辑时自动注入提交参数。

现在对类型、枚举、长度及数值边界均有效，且单行不超过80个字符的标量默认值提供“填入声明的默认值”按钮。点击只填入该字段；未点击时可选字段继续省略，不触发插件调用。无效值、长字符串、控制字符和结构化默认值不显示按钮。目录工具和资源工具共用这一呈现。Host提交验证与权限边界保持不变。
