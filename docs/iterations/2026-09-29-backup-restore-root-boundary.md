# 2026-09-29 备份恢复目录边界

状态：实现与静态检查完成；实机验收待补。

## 发现

创建备份要求工作区 `.zicode` 是普通目录，但恢复入口在同一路径下直接创建 `.restore-<id>` 暂存目录。若 `.zicode` 被替换为符号链接或 Windows 目录链接，恢复可能沿链接写入工作区外。

## 修改

恢复在创建暂存目录前检查 `.zicode` 为普通目录。不存在、非目录或链接时返回错误，不创建暂存目录，也不开始恢复前快照和目录交换。普通目录判断在 Windows 上同时拒绝带重解析点属性的 junction；创建备份、快照列表、备份来源、目标目录与复制树也沿用这一判断，不把链接内容当作普通文件或目录。

## 验证与遗留

`cargo check --locked --all-targets`、`cargo clippy --locked --all-targets -- -D warnings`、目标文件 Rustfmt 与目标差异空白检查通过。本轮未运行测试或真实桌面恢复。检查到使用之间仍存在路径替换竞态；并发写入、打开的 Windows 句柄和跨平台文件系统行为需要实机验收。
