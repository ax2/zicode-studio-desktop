# 项目总览最近命令运行（2026-09-28）

## 目标与发现

项目总览已有 Git 状态、提交历史和知识成果，但开发者要到命令页才能看到最近的运行结果。Host 已按注册工作区返回运行历史，含运行状态与历史存储状态；同一响应也供命令页使用。

## 修改

- 总览只读展示最多三条最近运行，含任务名、状态、开始时间和命令目录；通过入口可进入项目命令页查看完整记录。
- 读取响应沿用命令页的工作区归属与字段校验，项目切换或刷新时忽略旧请求结果。提供手动刷新，不在总览重复命令页的持续轮询。
- 显示前端接收快照的时间。运行中与停止中的状态仅代表该次读取；持久化历史不可用与仅内存历史均明确提示，读取失败不显示为空历史。
- 不在总览展示命令文本、标准输出或标准错误，避免在浏览项目时暴露敏感运行内容。

## 验证与限制

TypeScript 类型检查、i18n 覆盖检查、Biome 检查、React/CSS 打包与严格 MkDocs 构建通过。总览为只读快照；命令页仍承担持续状态轮询与操作。本轮未运行测试；跨平台实机视觉和运行验收尚未完成。
