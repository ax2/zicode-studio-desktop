# v0.7.9 · Spring 配置文件对比

在工具中心打开「Spring 配置对比」，可以分别导入基准配置和对比配置。每侧接受最多 8 KiB 的 UTF-8 JSON、YAML 或 YML，两侧可用不同格式。导入去掉开头 BOM，保留原换行和原件。错误或取消时保留对应草稿，撤销只恢复最近一次文件导入。点击「执行工具」后才比较。

成功后可下载本次完整 JSON 报告，也可通过现有的预览和确认保存到 Studio。改动任一输入或再次执行失败时，旧报告没有下载入口。比较和敏感值遮盖继续由冻结 Diagnostics 0.1.4 执行。

## Windows 验证

- 基线是真实 Studio 工具中心、已安装的 Diagnostics 0.1.4 和同一 Host/Worker。手动输入混合格式可得到报告，当时两侧均无文件入口。基线回执 SHA-256 为 fb738fac5f5f11914acfb22c5a516e29dcf022cd61583de28a223aa91c1a3492。
- 最终构件在 1180 px 英文和 420 px 中文分别实测，导入动作在两个配置编辑框上方。两组覆盖 BOM、CRLF、8192 字节导入、8193 字节拒绝、格式错误、无效 UTF-8、空文档、取消、撤销、手动执行、脱敏和旧下载失效。合成源文件逐字节保持。
- 两个窗口发出的 JSON 下载内容均为 1329 字节，与生产 Worker 返回逐字节一致，SHA-256 为 0225780f98ed53871beddfdd6eccc44693f60ba754abf7d12750fd9712de1b00。另通过真实 Host 的预览、确认和保存回执。下载证明读取了真实 WebView 发出的字节。第一次尝试用调试协议指定 Windows 下载目录未观察到落盘，原生文件对话框和安装版下载仍由 [#28](https://github.com/ax2/zicode-studio-desktop/issues/28) 跟踪。
