# 项目工作列表分批展开（2026-10-01）

## 目标与发现

项目工作页此前对任务和自动化各固定显示前 20 项。用户需要跳到全局中心才能找剩余条目，离开了当前项目上下文；全局中心还包含其他项目的工作。

## 修改与决策

- 两类列表分别以 20 项为一批展开已加载的当前项目条目，原有任务和自动化跳转保持不变。底部全局中心入口继续提供完整管理。
- 工作视图按项目作用域重新建立组件，切换项目时展开数量回到 20，不沿用上一项目的浏览状态。刷新同一项目时保留本次展开数量，列表缩短后自然只显示现存条目。
- 中英文帮助与按钮词条同步。失败读取仍显示最后一次成功的项目数据及警告；本轮不改变 Host 的数据读取范围。

## 验证与遗留

`bun run typecheck`、`bun run check`、中文词条覆盖、`bun run build:react` 和修改文件的 `git diff --check` 均通过；仓库检查仍有既有非阻断警告。本轮不新增或运行测试。桌面窄屏、键盘操作及跨平台真实项目列表仍待界面验收。
