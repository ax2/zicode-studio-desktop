日期：2026-10-17。仅修改 Studio，保留其他未提交工作；不修改 ZiDevTools 或 ZiFile 提供方。

## 目标与实现

普通文本结果的“发送到工具”目录增加工具来源、工具分类筛选，与已有搜索、收藏、最近使用和分页并用。Host 在分页前计算兼容字段映射并应用筛选；返回来源、分类计数及每项分类 ID。查询修订号包含两个筛选条件，防止切换条件后复用旧页。旧请求不带筛选参数时保持原语义。这里的计数单位是兼容输入字段映射，不是插件包数或独立工具数。

本轮沿用既有 `target/debug`，不改 0.4.2 版本，不生成 Release 或 ZIP。隔离配置已有 Text 0.1.0 与 Trace 0.1.0 无签名开发候选；安装副本对冻结源逐文件比对 Text 13/13、Trace 346/346，差异 0。只读检查提供方候选目录仍未发现正式 `.zicode-plugin` 签名包。
