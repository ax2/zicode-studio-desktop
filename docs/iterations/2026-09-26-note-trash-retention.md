# 2026-09-26 回收站保留时间

状态：实现与静态检查完成，运行验收待补。本轮不新增或运行测试。

## 目标与发现

- 删除使用 rename，旧正文 mtime 被误当作删除时间，可能导致刚删除就自动过期。
- 独立记录删除时间和删除事件标识；历史条目没有删除时间证据时，从首次识别开始保留，不推断历史。
- 导入明确携带明确时间标记的新备份保留原日期；旧备份或未知时间条目从导入开始保留。导入生成新事件标识。
- 保持正文版本不变；无元数据迁移只在持有现有 Vault 锁的操作中执行。

## 工作日志

- 已检查单篇删除、整本删除、恢复、清理、备份、导入和前端条件写路径。
- 新增 trash_metadata.rs，以 .trash/<id>.trash.json 保存 schemaVersion、deletedAt、deletionTimeKnown、trashToken。单篇及整本删除写入记录后再移动正文，拒绝覆盖已存在的同 ID 回收站文件。
- 列表、导出和条件写共享元数据读取。缺失元数据安全初始化；损坏、过大或符号链接元数据返回错误，该条目不会按正文日期自动清理。未知删除日期在 UI 显示“保留期开始于”。

- 恢复或永久删除正文后尽力移除时间记录；残留记录在下次删除时覆盖，不因清理记录失败把已成功恢复报告为失败。
- 大文件 notes_vault/host_server/notesLogic 仅字段、接线和删除旧时间辅助方法；核心逻辑独立。中英文帮助、平台说明和导航同步。

- 没有运行测试、真实文件操作验收、视觉或跨平台验证，也没有发布。此次为实现与静态检查，不能代表运行验收通过。
