# 模型渠道启用与禁用入口（2026-09-30）

## 目标与发现

当前 Rust 模型工具和内置 Pi 桥接已经识别 `enabled: false`，设置页也显示禁用状态，但用户只能在高级 JSON 中改变它。普通渠道保存会保留现有 `enabled` 字段，适合新增独立状态操作。

## 修改与决策

- 配置扩展新增 `set_provider_channel_enabled`：要求显式布尔值和渠道修订号，在模型文件锁内核对版本，仅修改该渠道 `enabled`，不动模型、地址或凭据。
- 写入后刷新 Pi 模型目录并执行凭据封存；即使刷新失败，已提交的状态仍明确返回，普通设置页提示运行时结果未确认。配置桥接在成功禁用当前所选渠道后请求取消活动。
- 设置页渠道行新增启用/禁用按钮，操作固定点击时的场景和版本；进行中禁止重复点击及同页其他渠道操作。失败后重新读取状态，避免把已提交但刷新异常的写入误判为没有发生。
- 中英文帮助说明凭据继续保留、旧修订号冲突以及已经发出的请求无法撤回。
