# 帮助页请求顺序与失败恢复

日期：2026-10-02。状态：实现与定向验证完成，实际 WebView 视觉验收待补。

## 发现与修改

原帮助存储不校验异步请求归属。连续切页时旧正文能覆盖当前页面；切换语言时旧目录能恢复旧语言状态，正文路径又取自可变的全局目录语言。导航按钮与文章链接的 Promise 拒绝也缺少处理。

现为页面读取记录请求序号、语言与语言切换代次，只有当前读取可提交正文或错误。目录读取提交前核对语言代次，正文路径取自请求开始时的语言。切页立即记录目标并清空旧正文，语言切换期间保留目标页面 ID。

当前失败写入存储并向调用者保留拒绝结果，界面内部调用消费该拒绝，不再由外围回调写入可能迟到的错误。正文改为独立的 DOM 容器，避免 Markdown 装饰操作与 React 管理的加载/错误节点混用；清空正文时同时清空页内目录。

## 验证

帮助存储、组件与双语资源共 3 个文件、16 条用例通过。新增覆盖旧请求迟到成功与失败、语言切换期间旧目录迟到、当前失败与重试，以及页面失败后旧正文/目录清除和恢复。

前端类型检查、代码与设计检查、React 构建退出 0。既有 124 项警告、7 项提示与终端生成文件样式 advisory 保留。检查通过不证明真实 WebView 排版、网络失败表现或三平台安装行为；这些仍待实机验收。本轮未运行 Rust 构建。
