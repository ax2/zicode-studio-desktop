# 2026-09-29 模型渠道显示名称

状态：源码实现与静态检查完成；真实桌面与跨平台行为待验收。

## 目标与发现

- [需求基线](../requirements.md)要求每个渠道保存稳定 ID 与显示名称。此前设置表单只编辑 ID，渠道列表显示 ID，模型列表直接采用 Pi 注册表名称。
- 渠道 ID 同时用于模型引用和凭据引用，显示名称不能通过修改 ID 实现。

## 修改与决定

- 新增可选的显示名称输入，支持编辑和复制。渠道行展示名称并保留 ID；模型列表优先读取同场景配置的显示名称，旧配置回退到原有注册表名称。
- 扩展保存名称时限制为 100 个可读字符；清空会移除配置字段。未带名称参数的旧调用保留原有值。名称写在场景 `models.json` 中，不写凭据。
- 使用现有渠道保存流程、配置会话与场景切换隔离，不引入新的网络请求。

- `bun run typecheck`、`bun run build:extensions`、`bun run build:react`、`bun run bundle-css`、`bun run check`、翻译覆盖检查和按 CRLF 规则执行的差异空白检查通过。全仓检查仍报告 119 条已有警告、7 条提示及 1 条设计警告。
