# 项目命令置顶工作日志（2026-09-28）

## 目标与发现

项目命令已按来源分组并支持临时筛选，但混合仓库重新打开后仍需反复查找常用命令。此前工作日志明确将可保存的排序或收藏设置列为缺口。

## 本轮修改

- 新增按工作区 ID 与当前子项目目录隔离的本机命令置顶存储，只保存 Host 任务 ID 或旧 Host 的稳定任务键；不存命令输出、环境变量或凭据。
- 列表提供逐项置顶与「只看置顶命令」。含置顶项的来源组优先，组内置顶项优先；当前清单暂缺的任务 ID 保留，重新发现后恢复显示。
- 保存限制为每目录 32 项、最近 64 个目录范围，读取有大小与结构校验；本机存储不可用或写入失败时显示提示。跨窗口 `storage` 更新会刷新当前列表。
- 保留临时搜索、Host 任务 ID、目录指纹和原运行入口；更新中英文帮助。

## 偏差与风险

- 置顶保存在当前设备的应用 Web 存储，不跨设备同步；清空站点数据会删除选择。旧 Host 没有任务 ID 时使用来源、工具和名称生成稳定键。
- 本轮没有实际桌面、窄屏、键盘或读屏验收；没有修改 Rust Host，因此保留已释放的 Cargo 调试缓存。

## 验证与发布

`bun run typecheck`、`bun run check`、i18n 覆盖检查、`bun run build:react` 与严格文档构建均通过。全局 lint 和设计检查仍报告仓库其他位置的既有提示；构建后恢复原本干净的无关前端产物，只保留项目命令相关的生成包及既有改动。Cargo `target` 保持约 3.7 MB。未新增或运行测试，也未发布安装包。
