# 2026-10-01 版本配置目录发现

状态：实现及静态检查完成；真实三平台验收待补。

## 目标与发现

- 环境页能读取选中子项目的 `.tool-versions` 和 mise 配置，但目录发现只把语言构建清单视为子项目。只有版本配置的子目录无法从环境页目录选择器进入。
- 同一个目录选择器还供项目终端、存储视图和固定任务页使用；发现目录不等于允许执行一个新任务。
- 核对现有模型渠道要求与代码后，QVeris 为可选专用路径，基础项目目录发现无需连接该渠道。

## 修改与决策

- 目录发现除语言清单外还识别 `.tool-versions` 和受支持的 mise 固定配置路径，使版本配置目录可选。
- mise 文件名复用环境解析器的同一清单，防止目录发现和报告读取范围漂移。
- 工作区成员的语言清单判定和固定命令生成维持原有规则；仅有版本配置的目录可以看环境、打开终端，不会凭配置文件新增可执行的固定任务。
