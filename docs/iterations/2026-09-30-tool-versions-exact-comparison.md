# 2026-09-30 `.tool-versions` 固定版本比较

状态：实现及前端静态检查完成；跨平台实机验收待补。

## 目标与发现

- 环境页已展示 `.tool-versions` 的多个工具声明，但此前每项均标为无法比较。
- 环境报告已有实际探测的 Node、Bun、npm、pnpm、Yarn、Python、Rust 与 Go 版本；单一完整数字版本可以与这些结果做精确比较。

## 修改与决策

- 对单一 `主版本.次版本.补丁版本` 声明，按工具名映射到已探测的可执行工具并做精确版本比较；Rust 和 Go 复用现有工具版本解析规则。
- 缺失工具、探测失败和无法解析的输出分别保留原有状态。多个回退版本、`latest`、`system`、`path:`、`ref:` 等动态声明继续标为无法判断，不推断版本管理器选择。
- Python 条目比较环境页当前选中的解释器；去掉只适用于项目清单比较的“宿主 Python”提示。比较结果旁明确说明它只代表本次探测，不证明 asdf/mise 自身的解析过程。
