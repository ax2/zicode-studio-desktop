# v0.7.9 · Unicode 文件检查与规范化

「Unicode 码点」「NFC 规范化」「NFKC 规范化」均可导入 8 KiB 内 UTF-8 文件。输入保留 BOM、原换行及字节顺序，码点偏移以原文件起点为基准。选择文件只更新草稿，可撤销，取消或读取失败保留草稿。

执行后可手动下载本次完整码点 JSON，或分别下载 NFC、NFKC 的完整 TXT。NFC 合并规范等价的序列，NFKC 还转换全角字母和带圈数字等兼容字符。空文件的正常结果也可下载。原件完整保留。

码点输出仍受 48 KiB 输出约束。实际报告超过此范围时，显示 Worker 错误，保留输入草稿。
