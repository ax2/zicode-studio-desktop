# 2026-09-29 模型渠道复制

状态：源码实现与静态检查完成；尚无真实渠道或跨平台桌面验证。

## 目标与发现

- 需求要求渠道支持复制。设置页此前只有添加、编辑、目录发现与删除；直接用编辑表单会把源渠道当作修改目标。
- 保存新渠道时，若用户输入已有 ID，扩展原先会覆盖现有配置。系统凭据先于扩展保存，冲突时还可能提前改写目标密钥。

## 修改与决定

- 渠道行增加“复制渠道”。表单预填地址、协议、鉴权方式和模型 ID，清空目标 ID、密钥及原渠道 ID；不读取或展示源密钥。
- 渠道列表返回源配置修订号。保存副本时，扩展检查源渠道仍存在且未变更，保留同 ID 模型的元数据，并拒绝覆盖已有目标 ID。副本只继承标准字段和模型元数据，不继承源渠道的其他高级 JSON 字段或凭据。
- 新建渠道和重命名渠道在扩展确认成功后写入新 ID 的系统凭据，避免目标 ID 冲突时先覆盖其凭据。系统凭据后续失败会显示部分完成提示。
- 帮助文档同步说明复制行为。未改变已有渠道的编辑、目录发现与删除入口。
