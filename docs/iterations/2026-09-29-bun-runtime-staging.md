# 2026-09-29 内嵌 Bun 更新暂存

## 目标与发现

- 内嵌 Bun 若需更新，原脚本先删除整个资源目录，再复制宿主 Bun 或解压已校验归档；复制、写入或权限设置中断后会失去上一个可运行版本。
- 大文件盘点显示本机内嵌 Bun 约 98 MB；它与 C 盘的宿主 Bun 不在同一卷，无法通过硬链接节省本项目空间。

## 修改与决定

- 两种安装来源都先写入资源目录旁的临时目录，确认目标为非空普通文件并写入版本标记，再把旧目录移至临时备份名并提交新目录。
- 复用检查也要求目标为非空普通文件；仅有匹配版本标记但可执行文件为空时会重新安装。
- 提交失败会尝试恢复旧目录；若恢复也失败，错误保留旧目录实际路径供人工处理。新目录提交成功后清理旧目录；清理失败仅告警并保留具体路径，不把新安装误报为失败。
- 同卷目录切换只缩短不完整状态的窗口，不能宣称跨进程或断电事务；断电后遗留的暂存或旧目录仍需核对。
- 接续 PortableGit 更新时，目录切换提取为两种资源共用的同步函数；Bun 的可执行文件与版本标记校验仍在其入口中完成。
