# 2026-09-29 模型渠道编辑版本核对

## 目标与发现

- 设置页加载渠道列表时已收到 Pi 配置层计算的 `revision`，保存接口也支持 `expectedRevision` 对比；普通编辑器打开时却把这个字段清空。另一窗口或进程修改渠道后，旧表单可能覆盖较新的配置。
- 复制渠道已有独立的源版本核对；本轮保持其新 ID 流程。

## 修改

- 打开已有渠道编辑器时保存列表中的版本，提交时传给现有的配置接口。旧运行时没有返回版本时，编辑器在更新凭据或配置前提示刷新或更新运行时，不再执行无版本写入。
- 保存时若检测到版本冲突，配置接口拒绝本次写入；编辑器保留用户草稿和错误提示，便于刷新后人工比较。新建与复制渠道继续使用原有入口。
- 此项保护设置页的普通编辑流程。高级 JSON 编辑、其他直接调用配置接口的客户端及跨进程文件写入事务尚不受它覆盖。

## 验证与遗留

- `bun run check`、`bun run typecheck`、`bun run build:react` 与改动文件空白检查通过。Biome 仍报告 119 个既有 warning 和 7 个 info；设计检查报告 1 个现有警告。本轮未运行测试或真实双窗口编辑。
- 完整渠道禁用仍需约束 Pi 聊天、扩展命令、排队请求和运行中的调用，未向用户暴露不完整开关。
