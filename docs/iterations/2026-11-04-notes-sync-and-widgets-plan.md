# 笔记云同步与 Windows 小组件方案

2026-11-04。本文是用户要求的方案设计，尚未连接云账号、上传笔记或交付系统小组件安装包。

## 推荐同步方案

在 Studio 内置 WebDAV 同步，首个适配坚果云，并保留 NAS/其他兼容服务入口。默认填好服务地址，用户只需配置账号和单独生成的应用密码；后续在应用内看到“已同步、等待网络、有冲突、需要重新登录”等清楚状态，提供立即同步和暂停。应用密码放入系统凭据库，避免用网盘登录密码。

坚果云官方提供第三方应用密码和 WebDAV 接入方法，同时规定请求频率和单次目录枚举上限。因此实现必须使用索引与批量队列，并处理限流，不能每篇笔记频繁扫描云端目录。[坚果云官方接入说明](https://help.jianguoyun.com/?p=2064)

- 本地是完整工作副本，断网可读写；同步只处理已保存的笔记、笔记本元数据和附件。SQLite索引、本地恢复草稿、模型凭据及工具历史不直接上传。
- 笔记使用稳定ID，附件按内容哈希寻址，笔记正文与元数据形成有版本的对象。云端使用索引记录对象版本；上传对象成功后再提交索引，避免附件或正文只传了一半。
- 通过条件请求检查远端版本；首次适配必须实测服务端的ETag/条件写行为。远端版本变化时重新合并，不以最后上传者覆盖双方。
- 两台设备同时编辑同一篇时保留两个版本，明确标出冲突来源，由用户合并。笔记本排序属于可同步元数据，展开/折叠属于设备上的阅读状态。
- 删除采用可恢复的删除记录；离线设备回来时先识别删除记录，避免旧笔记自动复活。提供云端历史版本和本地独立备份；“同步成功”不等于已经完成备份策略。
- 推荐默认端到端加密：本机生成同步密钥，云端仅保存加密对象和索引；首次设置保存恢复码，第二台设备通过扫码或恢复码接入。云服务应用密码与解密密钥分开保存。使用成熟加密库，不自行设计算法。
- 文字保存后合并排队，附件独立传输并可恢复；失败有退避和明确状态。索引读取代替全量目录枚举，以适应服务端请求和文件列表限制。

正式启用前的验收：两个真实设备/资料库的新增、修改、移动、重命名、附件、删除恢复；同时编辑冲突；上传中断和重启；限流、凭据失效；换设备恢复密钥；本地文件与云端可恢复内容逐项核对。当前阶段不把本地模拟服务测试当成真实云端验收。

## Windows 小组件构思

可以使用打包的 Win32 应用提供 Windows 小组件，通过 Windows App SDK 的 Provider 和系统小组件宿主连接；需要包清单注册及对应分发形式。[微软 Provider 文档](https://learn.microsoft.com/en-us/windows/apps/develop/widgets/widget-providers)

建议第一个做“Studio 速记”：

| 大小 | 内容与操作 |
| --- | --- |
| 小 | 一个“新建笔记”入口 |
| 中 | “新建笔记”加最近两篇笔记，三处可点击入口 |
| 大 | 在最近/置顶笔记中增加可选一项，保持一屏可见 |

点击卡片直接打开对应笔记或新建编辑器，继续使用固定资料库。默认隐藏正文，可开启隐私模式隐藏标题。不读取剪贴板、不触发模型调用。详细编辑放回 Studio，避免把小组件变成缩小的完整应用；这也符合微软的小组件导航建议。[微软交互设计指南](https://learn.microsoft.com/en-us/windows/apps/design/widgets/widgets-interaction-design)

系统资源监测可以作为第二个独立的“系统状态”小组件，显示CPU、内存和磁盘概览，点击进入本轮新增的系统信息页。温度只显示可用传感器读数，更新频率按宿主能力安排。当前便携程序继续使用；系统小组件的包注册、宿主版本与分发验收单独推进。

## Pi 换 DSH 的判断

若指 DeepSeek Harness，聊天最小接入属于中等工作量，完整替换属于中等偏大；现有笔记、工具、托盘和大部分界面可以复用。当前Pi连接通过stdio RPC，扩展还依赖Pi SDK，因此必须适配会话、模型、流式事件、工具调用和权限确认，并迁移Pi扩展。

DSH官方架构提供SDK profile及JSON-RPC入口，但项目仍明确标为开发者预览，存在不兼容变更。建议先在内部形成运行时适配层，让DSH完成完整聊天与工具流程后再考虑切默认。本轮只评估，不替换Pi。[官方架构](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md)、[项目状态](https://github.com/deepseek-ai/deepseek-harness)
