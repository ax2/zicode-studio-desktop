# 2026-09-30 禁用模型渠道的可见状态

## 发现

- 高级 `models.json` 支持 `enabled: false`，模型目录和多条请求路径已按此标记处理，但普通渠道列表响应没有返回启用状态。用户看不到渠道为何不出现在模型选择中，仍可点击只会被后端拒绝的连接检查和目录发现。

## 修改

- `list_provider_channels` 返回规范化的 `enabled` 值；未声明该字段的既有渠道按启用处理。
- 设置页渠道行显示“已禁用”状态和高级 JSON 中重新启用的提示，禁用连接检查与目录发现按钮；编辑、复制和删除保留。中英文帮助文档说明该状态与恢复步骤。

## 验证与遗留

- `bun run typecheck`、`bun run check`、`bun run build:extensions` 和 `bun run build:react` 通过；运行时设置页 bundle 已同步。首次代码检查发现新加的 “Disabled” 翻译与原词典条目重复，移除后检查通过。未运行测试或桌面实机查看。
- 普通表单暂不提供启用/禁用开关。Pi 取消时序、已经发出的请求以及第三方扩展调用仍未完成全链路验收。
