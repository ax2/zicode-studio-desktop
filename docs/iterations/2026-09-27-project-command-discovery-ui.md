# 项目命令发现界面工作日志

## 目标与发现

项目命令已覆盖 JavaScript、Rust、Go、Python、CMake、Java 和 .NET。原界面将所有任务平铺并逐项重复来源说明，混合仓库或多个 .NET 目标时难以快速找到所需命令。

## 修改与决策

- 按 Host 返回的来源文件分组，每组显示命令数量和一次性来源说明。保留每项命令文本、Python 解释器、不可运行原因与显式运行按钮。
- 增加本地搜索框，匹配命令名、命令文本、来源文件及管理工具；显示匹配数与任务总数。无结果时明确提示。
- 搜索仅过滤界面，不改变 Host 任务 ID、目录指纹、运行状态或历史；工作区和子项目目录切换时重置搜索。
- 将任务列表提取为独立组件，避免持续扩展项目运行器主面板；窄屏路径和长命令可换行。

## 验证

已通过 `bun run typecheck`、`bun run check`（111 条警告、7 条提示，命令退出码 0）、词条覆盖检查（2556 个中文词条，缺失 0）、`bun run build:react`、MkDocs 严格构建和 `git diff --check`。未运行测试或实际点击桌面命令。

## 遗留问题与风险

- 目录清单仍可能因数量或大小上限无法生成；筛选不代替 Host 分页发现。
- 分组顺序沿 Host 任务发现顺序，未增加用户可保存的排序或收藏设置。
- 桌面、窄屏、键盘与读屏操作尚待实机验收。

## 发布结果

本阶段仅更新本地工作区，没有发布或打包。
