# 开发插件选择与安装分离（2026-10-17）

## 目标与发现

原“安装本地插件”在用户选定目录后立即复制并安装。Inspect 等独立提供方包可能包含大量文件，用户需要先看插件身份、工具数量和权限。单纯把目录路径留给安装命令还会让预览与安装之间的目录变化失去约束。

## 修改

Studio 的原生目录选择命令现在只解析并校验清单，计算整个目录的内容摘要，返回 ID、名称、版本、发布者、工具数量和声明权限。Plugin Manager 展示核对卡，用户可取消或明确点击安装。安装命令在复制前检查源目录摘要，在暂存复制后再次检查摘要；不同则拒绝并要求重新选择。选择新目录时先清除旧预览。开发包仍遵循既有无签名插件启用和授权规则；DevTools 源码、候选目录和协议均未修改。

## 验证

- 注册表定向 Rust 1/1：预览不安装，预览后修改同版本清单会拒绝，重新预览后可安装。
- 前端定向 1/1：选择只呈现预览，明确安装才提交路径和摘要。
- Tauri 49 项命令权限检查、`bun run check`、`bun run check:rust:static` 退出 0；前端检查有既有告警。
- 复用单一 `target/debug` 构建，当前 EXE SHA-256 为 `3C550F770536B1EDA4E03E49F8AA719A080B541A84147AB0407C1D461AD91DA8`，大小 125,064,192 字节。隔离原生窗口的插件管理页实际显示 Inspect 0.1.1、`com.zicode.devtools.inspect`、8 项工具和 `pi.tools.register` 权限；1442×931 截图实看布局清楚。未点击安装，隔离进程 PID 55708 已核对命令行后停止。
