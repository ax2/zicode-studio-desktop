# 项目上下文文件完整性（2026-09-28）

## 目标与发现

桌面宿主通过项目目录内 `.zicode/project.json` 保存说明、默认场景和会话预算。这个文件可随项目目录迁移。此前读取失败或 JSON 损坏时返回空配置；界面可能据此保存并覆盖原文件，写入也直接作用于最终路径。

## 修改

- 读取既有配置时检查普通文件、大小、版本及关键字段；损坏或不支持的内容返回稳定错误码，不再当作新项目。
- 写入前拒绝覆盖无法读取的既有配置。新内容先写同目录临时文件，再重命名为最终路径；写入失败时清理临时文件。
- 项目上下文页显示本地化错误并禁用保存，修复文件后可通过项目刷新重读。项目切换时错误状态隔离。

## 验证与限制

TypeScript 类型检查、全局 `bun run check`、受影响文件的 Biome lint、i18n 覆盖、扩展/React 打包及离线严格 MkDocs 构建通过。本轮未运行测试；仍需在 Windows、macOS、Linux 上验证意外中断、并发窗口编辑、权限和符号链接边界。并发编辑目前仍是后写覆盖先写，尚无版本冲突处理。
