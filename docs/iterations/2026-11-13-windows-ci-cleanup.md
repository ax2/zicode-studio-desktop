## 修复边界

- 仅修改测试模块，生产 Host 生命周期、资源预算及产品功能不变。
- 关闭 HTTP 客户端并完成 `stop_and_wait` 后，断言 Host 状态的弱引用已无法升级；如果仍持有数据库的 Host 未释放，直接失败，清理重试不能掩盖它。

- 只有 Windows 错误32允许重试，每次20ms、最多100次。其他错误立即失败，持续占用仍失败并保留剩余文件。首次冲突、恢复成功的次数和最终错误均打印到测试日志。
- 保留所有原有业务断言，不跳过测试、不降低检查级别、不修改用户资料。
