# 2026-09-26 用户自主配置模型渠道

状态：实现与 Windows 自动化验证完成，实际界面及其他平台待验收。

## 发现与计划

- 配置命令每次读取都会补写 QVeris 渠道；空场景也显示强制渠道。
- 设置页会自动同步 QVeris 目录，保存 Key/渠道也触发网络同步；删除该渠道被禁止。
- 改为仅列出实际渠道/运行时目录，读取不修改模型文件；已有配置保留原文，用户显式编辑才更新。
- QVeris 目录适配保留为已配置渠道的显式操作；保存凭据和渠道不自动获取目录，不允许同步重新创建已删除渠道。

## 实现与关键决定

- 新增 `extensions/model-channels.ts`，独立处理模型文档结构校验与渠道密钥引用生成，不添加默认渠道。
- 配置入口移除 `ensureBuiltInModelGateway`，目录集合来自实际配置和 Pi 运行时；不改变 Pi 自身内置模型目录。
- 保存渠道时写入与 Host 环境命名一致的密钥引用；关闭鉴权时不新增引用，已有扩展字段得以保留。读取不承担修补配置的职责。
- 保存 Key、保存渠道、加载设置均取消自动目录同步。用户显式配置 `qveris` 后可手动刷新，支持先保存空模型列表再获取目录。
- 移除 QVeris 渠道的删除和重命名限制；删除或改名清除旧运行时凭据缓存。既有删除语义仍会移除关联凭据，帮助文档说明对其他功能及模型引用的影响。
- 手动刷新展示忙碌状态和可读错误；切换目标场景后不应用旧场景同步结果。
- 网络等待结束后重读配置：同一渠道发生变化则拒绝写回；其他渠道的变更合并保留，避免使用请求前的整份文件覆盖。
- 沿用现有大型配置分发器接线，新增纯配置处理抽出模块；前端沿用设置 store 和现有行组件，未扩展应用根入口。
