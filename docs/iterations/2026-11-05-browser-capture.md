# Bounded browser content capture — 2026-11-05

The trusted Browser interface now provides Read page and a local plain-text preview. It explicitly invokes browser_capture_page with its tab identity and expected URL; no model or Pi request is made. Before opening the modal it awaits native hide; closing requests restoration. The preview uses textarea.value/textContent, never HTML rendering of captured markup.

Rust reads only its owning window's native tab, runs a fixed bundled extraction script and checks the trusted window origin before work and on completion. The native URL must match the requested URL and returned page URL. A unique native document instance plus a navigation counter detects reload/replacement; a window surface revision detects intervening tab/visibility transitions. A closed tab/window or changed source produces an error. Requests time out after ten seconds. There is no arbitrary script, file path or cross-window owner argument. Results include tab, document revision, native-checked URL, title, bounded body/selection, UTC timestamp and an untrusted-web-content marker.

The script visits at most 12000 text nodes, returns at most 48000 UTF-16 body characters, 8192 selection characters and 512 title characters. Visible text is collected while script/style/template/form/editable/hidden regions are skipped. Selections intersecting form/editable regions are excluded. These are tested extraction rules, not a guarantee to redact every secret a website chooses to display. DOM text remains untrusted and cannot confer Agent/native permissions. Links/tables/images, Readability-quality article extraction, iframe contents, and sensitive-content classification remain future scope.
