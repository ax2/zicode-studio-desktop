# v0.7.9 · 文本行整理文件导入与下载

工具中心中的稳定去重、升序、降序、去空行及去首尾空白均可导入 8 KiB 内的 UTF-8 文本文件，可撤销，取消或读取失败时保留草稿。读入时识别 UTF-8 BOM，保留正文的原始换行。用户手动选择「执行工具」后才处理。

执行成功后，点击「下载整理后的文本」获取本次完整 TXT。处理继续采用现有按行和排序规则，输出使用 LF。去空行结果为空时可下载零字节文本。输入修改或执行失败后，旧结果不能继续下载。原文件及其换行完整保留。
