# 2026-09-29 远程工作区范围

状态：Windows 本地编译与静态检查通过；真实远程多项目切换待验收。

## 目标与发现

- 已配对的 LAN 或公共远程设备可调用 `/v2/resolve-workspace`。此前它会根据请求中的任意现存桌面目录分配工作区 ID，并把该目录加入 Host 的工作区登记表。
- 随后的会话恢复和新建接口都以已登记工作区为范围，因此远程设备能扩大本机可访问目录集合。
- 应用启动时已从桌面元数据载入现存工作区；桌面窗口打开新目录时也会显式登记。远程切换项目只需要查找，不需要创建登记。

## 修改与决定

- 远程路径解析先规范化请求路径，再与 Host 当前登记的规范化根目录精确比较；仅返回匹配的工作区 ID。
- 目录不存在或不在登记表中统一返回 `project_not_found`。登记表暂不可用时返回服务不可用，不推断空工作区。
- 移除原来供远程路径接口调用的元数据 ID 分配方法；桌面原生项目打开流程仍负责新工作区登记。
- 本轮未新增或运行测试。
