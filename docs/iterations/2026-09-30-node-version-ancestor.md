# 2026-09-30 Node 祖先版本声明

状态：实现及静态检查完成；真实项目验收待记录。

## 目标与发现

- 环境页已能读取当前目录的 `.nvmrc` 与 `.node-version`，但子项目目录看不到注册工作区内祖先声明的 Node 版本。
- 两种文件在同层且版本不同时，现有本地报告会显示冲突；祖先报告也应保留这一语义与具体来源路径。

## 修改与决策

- 选中目录没有任一 Node 版本文件时，最多向上查找 32 层，遇到注册工作区内最近的一层声明即停止；本地文件优先。
- 同层两种文件均可读取但版本不同时报告冲突；不可读、指向声明目录外或超出读取上限时保留状态，不继续借用更远祖先。
- 祖先文件以相对注册工作区的路径显示。冲突文案根据清单类型判断，避免带目录路径的 Node 文件被误标为 Rust 工具链冲突。
