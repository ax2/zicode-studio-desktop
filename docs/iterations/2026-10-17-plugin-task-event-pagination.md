# 插件任务事件分页（2026-10-17）

## 目标与修改

Studio 内部任务存储已保留最多 256 条事件，但任务中心只读详情之前只返回最近 64 条，更早事件只显示未展示提示。本轮为桌面令牌限定的 `/v2/plugin-task-center/detail` 增加可选 `beforeSequence`，每次按降序查询 65 条、返回最多 64 条并准确标记是否有更早记录。工作区验证、任务引用隔离、输入与授权数据不外泄的边界保持。

React 任务详情在事件列表上方按需加载早期事件，按原始序号合并并显示；切换工作区或关闭详情会使在途回复失效。首次实际截图发现按钮放在 64 条之后不可见，遂移到列表前并去掉有序列表与手写序号的重复编号。事件列表限制在卡片内滚动；复查截图发现序号被滚动容器裁剪后，改用列表内部序号。
