# Deno 自定义任务工作日志（2026-10-01）

## 目标与发现

前一阶段只发现 `deno.json` / `deno.jsonc` 与三个固定命令。Deno 项目实际常把开发、构建等流程写在 `tasks` 中，命令页还无法看到或运行这些声明。

## 修改与决策

- 使用有界读取和 JSONC 解析，允许注释与尾随逗号，拒绝更宽松的 JSON5 语法。无效配置仍按任务清单错误处理，不猜测任务。
- 两种配置文件同目录存在时优先读取 `deno.json` 的任务；两文件内容均参与指纹，使刷新不会使用旧清单。
- 最多列出 100 个自定义任务。字符串任务和含非空 `command` 的对象任务展示正文，运行时交给 `deno task <名称>`；不解析或执行正文。名称超出既有任务运行器安全范围时仍显示，但禁用运行。
- 固定格式检查、lint、test 命令保持独立。所有命令都由用户主动点击启动。

## 验证与遗留

`bun run check:rust:static` 通过（Cargo check 与 Clippy），本轮 Rust 文件的独立格式检查通过；全仓库格式检查仍提示其他文件的既有格式漂移。Cargo 重新解析锁文件时一并补入当前工作树已有清单依赖。检查后执行 `cargo clean`，清理约 3.3 GiB 再生构建缓存。未运行测试或真实 Deno 命令。依赖型但无 `command` 的任务对象暂不列出；跨 Windows、macOS、Linux 的真实 CLI 行为待验收。
