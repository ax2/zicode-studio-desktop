# 2026-09-30 模型渠道地址一致性

状态：实现和静态检查已完成；真实服务验收待办。

## 目标与发现

- 通用 OpenAI 兼容渠道按用户保存的 `baseUrl` 直接请求服务；Rust 的 QVeris 本地代理只服务显式配置的专用兼容渠道。
- 渠道保存校验此前接受包含查询参数或片段的地址，而通用模型目录发现拒绝这类地址。用户可能先保存成功，再在目录发现时遇到不可用配置。

## 修改与决策

- 渠道地址在保存和读取用于连接前统一拒绝查询参数和片段，包含空的 `?` 或 `#` 后缀。
- 保留 HTTP(S) 本地服务、用户明确配置的远端服务和路径前缀；不改变专用 QVeris 代理的目标地址。
