# 2026-09-26 项目 Git 差异查看

状态：功能已实现并完成本机自动验证，视觉与跨平台实机验收待补。
接续已落盘并完成自动验证的项目 Git 状态面板。

## 目标与设计

- 在项目总览直接查看未暂存改动（工作树对暂存区）与已暂存改动（暂存区对 HEAD）。
- 由 Host 解析注册的 workspace ID；仅接受两种固定比较模式，路径固定限制在项目目录。
- 不执行外部 diff/textconv，不加载文件预览脚本；内容以文本渲染。
- 复用 Git 超时、输出上限和 Windows 隐藏进程策略；过大结果保留清楚的截断/失败提示。
- 切换项目、刷新状态或切换比较模式时丢弃旧结果，差异读取不依赖 AI 会话。
- 明确标示未跟踪文件没有 Git diff，子模块内部改动不在检查范围。

## 实现结果

- `git_diff.rs` 独立模块提供项目作用域的 staged/unstaged 比较；新建仓库尚无 HEAD
  时也可查看暂存内容。`--no-ext-diff` / `--no-textconv` 禁止执行仓库配置的程序。
- 复用统一 Git 子进程：每次最多 5 秒、每输出流 2 MiB；显示最多 2000 行和 256 KiB，
  按完整 UTF-8 行截断。超大单行也明确标记截断，不能显示成“没有改动”。
- 前端独立 `GitDiffPanel.tsx`：按需读取、切换比较、点击原按钮重试、关闭预览；过期响应
  不覆盖当前项目/比较。使用原生只读 textarea，支持内容选择、复制和键盘滚动。
- 不自动暂存、提交或推送；未跟踪内容不进入 Git diff。原有子模块限制仍显示在面板中。
- Host 和项目页大文件仅增加协议/组件接线，功能逻辑留在独立模块。上一轮的未提交内容保留。
