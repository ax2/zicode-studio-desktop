# 千工具目录搜索的锁作用域（2026-10-18）

## 目标与发现

Studio 的工具搜索和按需加载会为当前场景生成目录修订。此前搜索请求持有全局插件注册表锁，完成工具排序、搜索索引、版本表和修订哈希；工具越多，其他插件管理和工具操作等待该锁的时间越长。版本表还为每个插件重新线性扫描所有工具。已有真实 HTTP 合成用例覆盖 1,000 个授权工具，可用于本轮回归，但不代表实际 DevTools/ZiFile 包接受。

## 修改和边界

搜索在注册表锁内只取得同一时点的工具、插件和能力内存快照，锁外完成目录排序、索引和修订哈希。版本筛选使用工具插件 ID 集合，消除逐插件扫描全部工具的二次增长；排序缓存键值，保持原有排序规则。加载与调用仍重新检查目录修订、目标权限及签名包完整性，不使用搜索时的快照直接授权。状态若在搜索快照之后变化，搜索结果可能短暂过期，后续加载/调用会拒绝失效修订；这与先前搜索解锁后发生状态变更的边界一致。

未增加持久缓存、磁盘文件、版本号或完整运行目录；用户暂不启用的隔离 JSON 对象插件及权限未改动。无 UI 改动或新增截图。
