# v0.7.9 · 公式计算器

审核并启用 ZiDevTools Expression Calculator 0.1.0 后，从工具中心搜索「公式计算器」。可直接输入 `1/3+1/6`、`comb(52,5)`、`sin(pi/6)` 或 `5 km -> m`。支持精确有理数、近似实数与复数、排列组合、固定 128 位有符号位运算，以及长度、质量、时间、存储和温度换算。角度默认用弧度，也可选择角度制。

单次输入最多 2048 UTF-8 字节、512 个词元、64 层嵌套，函数最多 64 个参数。最多可传入 64 个本次常量，字符串保留精确分数，JSON 数字表示有限近似值。结果包含可复制文本和保留精度的结构化值。计算离线运行，权限列表为空。
