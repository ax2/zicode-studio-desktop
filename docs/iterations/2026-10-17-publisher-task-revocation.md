# 发布者撤销后的插件任务状态（2026-10-17）

## 目标与修改

Studio 已能撤销签名发布者并禁用其插件，但此前内部任务记录不会跟随终止。注册表的成功撤销操作现返回受影响插件 ID，Host 再逐个把其活动任务标为 `revoked`。无关发布者或插件的任务不受这一步影响；任务存储失败会记录有界错误，仍不能宣称强一致性。

## 验证

- 签名注册表专项 1/1：撤销返回预期插件 ID，既有签名包安装/升级/回退与撤销行为通过。
- 使用接收端临时测试密钥签名包的隔离 Host 专项 1/1：成功发布者撤销后，所属插件活动任务置 `revoked`；无关插件任务保持 `running`，正常 Host 关闭时才变 `interrupted`。
- `bun run check:rust:static` 退出 0，Cargo check 与严格 Clippy 通过；rustfmt 仍有既有 advisory。
- 前后只读存储扫描完整、未知项 0：`target` 29,419,166,335 → 29,419,072,127 B；task-scratch 均为 852,978,182 B；E 盘可用 46,179,307,520 → 46,221,336,576 B。未执行清理，卷余量变化不归因于本阶段。

## 遗留

注册表或 Store 在撤销流程中途失败，仍可能留有旧任务元数据；发布前需要一致性恢复策略。批量重载、工作区关闭、View 生命周期处理器、真实提供方任务与跨平台实机验收仍待。测试包不是 Zi DevTools 正式签发包，154 项完整工具接受仍为 0。
