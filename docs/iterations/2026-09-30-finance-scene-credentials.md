# 2026-09-30 金融外部连接凭据边界

状态：实现和静态检查已完成；真实桌面验收待办。

## 目标与发现

- 平台的项目和金融本地研究流程应允许用户不配置特定服务商。QVeris 仅是金融场景中可选的外部数据连接。
- 金融能力客户端此前会直接接受继承的 `QVERIS_API_KEY`，并在没有 `PI_CODING_AGENT_DIR` 时查找当前工作目录的 `auth.json`。这两条隐式路径可能使未配置场景显示为已配置，或向外部服务发送非本场景的凭据。
- 桌面 Host 已按场景从系统凭据库准备 `auth.json`，Pi 启动时会把该文件中的凭据载入运行时；模型配置中的 `$QVERIS_API_KEY` 仍由场景注入机制解析。

## 修改与决策

- 金融能力客户端只接受场景运行时明确设置的密钥，或 `PI_CODING_AGENT_DIR/auth.json` 中该场景的密钥。
- 缺少场景目录时报告未配置，不回退到进程环境变量或当前工作目录。
- 保留模型渠道的场景环境变量机制及金融连接的显式代理地址配置；本轮不改变模型请求路径。
