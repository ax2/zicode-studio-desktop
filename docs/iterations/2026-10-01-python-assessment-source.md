## 目标与发现

- 环境页在 `pyproject.toml` 的 Python 版本要求下写着“只与宿主 Python 比较”。当前 Host 为选中目录探测 Python 时会使用显式环境、项目本地环境、工具目录及宿主回退，并在工具区单独展示来源。

- 只有 PEP 440 要求实际得到满足或不满足结果时，才提示比较对象是此目录检测到的 Python 解释器，并引导用户在工具区核对来源。
