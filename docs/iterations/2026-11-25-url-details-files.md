# v0.7.9 · URL 拆解文件与报告

工具中心的「URL 拆解」可导入 8 KiB 内的 UTF-8 文本，文件中只填一行 URL，首尾可有空白和 UTF-8 BOM。选择文件仅更新草稿，可撤销。点击「执行工具」才在本地解析。

执行成功后选择「下载 JSON」获取本次完整报告，保留协议、主机、端口、路径、片段和按输入顺序排列的查询参数。重复参数与空值均保留，百分号编码按 URL 查询规则解析。URL 中用户名和密码只以存在标记报告。

## Windows 验证

- 使用冻结 Transforms 0.1.1 候选 01 及生产 Windows Worker。804 文件、隔离 Windows Host 和本机 Pi 工具通道对 23 个样例及十个权限阶段的验证见[同包验收](2026-11-25-line-tool-files.md)。
- 正常工具中心在 1180px 英文浅色和 420px 中文深色共执行 8 次，6 次成功、2 次预期拒绝。六份实际下载的 JSON 与该次 Worker 内容逐字节相同，核对了重复查询键的顺序、`%2B` 与 `+` 的区别、百分号编码的中文值、空值和两种用户名密码存在状态。合成地址使用保留域 `.invalid`，验收未观察到外部请求。
- 两种窗口均实测含 BOM 的 8192 字节文件、8193 字节拒绝、空文件、多行、无效 UTF-8、撤销、选择取消、输入改变后旧结果失效和原件回读。含 BOM/CRLF 的合成样本 SHA256 `19e1dbf496464b3b109584a0f888df797a672b38d787decd5d510027dbfc25a0`。
- 64 项定向前端、4 项矩阵通过，8 项既有跳过。TypeScript 与词条覆盖通过。工具中心资源 SHA256 `75d90be8155359e86caf7cae0903b52dee572494741f4444f4776725702f9850`。

实际 Windows 文件选择窗口和安装版桌面下载体验由 [#28](https://github.com/ax2/zicode-studio-desktop/issues/28) 跟踪。
