# Host 定时任务模板调度（2026-10-02）

状态：源码已接入，定向 Rust 与前端测试及最终静态复查通过；三平台 worker 实机行为待验收。

## 目标与实现

此前任务中心页面为 interval/daily 模板创建实例，窗口关闭后没有对应 Host 生成路径。新增 `automation_task_schedule`，与工作流调度同处取得 OS 执行锁后的 Host 生命周期，十五秒扫描已登记工作区的正式任务文件。每轮最多读取 24 个工作区，每工作区最多处理四个到期模板；工作区轮换顺序，保持关闭屏障和文件大小边界。

模板与实例在一次文件修订号校验写入中提交，实例 ID 由模板 ID 和原始到期时间的 SHA-256 构成。实例已存在时只修复模板下一次到期时间。新实例清空旧 dispatch、result 和费用，审批要求决定 autoDispatch；草稿、禁用、未来时间与非法时间跳过。非法日程不会阻止后续有效模板。Host 派发器排除 interval/daily 模板本身，避免旧 autoDispatch 标记执行模板而非实例。

下一次时间复用 Host 工作流的本地时区和夏令时处理；interval 最少五分钟，保留页面允许的长周期，使用有界转换与 checked 日期加法拒绝溢出，消除既有 Host 静默缩短超过七天周期的偏差。休眠后仅补一个到期实例，再从当前时刻计算下一次，不枚举全部错过周期。未初始化或损坏文件不会作为空列表创建或覆盖。

任务页面 `tick()` 改为只读刷新；主动“立即运行”、审批和编辑保留。读取失败现保留 Host 错误码，使既有运行时未就绪退避机制生效。本机任务中心五个文件、59 个用例通过，验证了只读到期观察、草稿不激活、失败读取恢复以及显式操作。
