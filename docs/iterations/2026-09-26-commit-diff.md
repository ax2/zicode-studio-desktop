# 2026-09-26 提交差异预览

状态：2026-09-27 实现与静态检查完成，运行验收待进行。本轮接续提交历史，补齐历史到代码改动的查看流程。

## 目标与设计

- 从历史中的完整提交 ID 显式读取差异；仅接受 SHA-1/SHA-256 十六进制 ID，不接受任意 revision、命令或目录。
- 从原始 commit 对象解析真实父提交。普通提交与第一父提交比较，合并提交明确显示第一父提交规则，真正的根提交与空树比较。
- 浅克隆边界的父对象缺失必须报告失败，不能把它当作根提交显示全量新增。
- 差异限定已注册项目目录，复用 2000 行/256 KiB 显示上限和有界 Git 子进程。只读文本、按需加载，项目切换与刷新丢弃旧回复。

## 工作日志

- commit_diff.rs 校验完整对象 ID，cat-file 读取原始 commit header；父引用最多 1024 个。普通/合并提交用两棵树直接比较，真实根提交用 diff-tree --root 递归显示，避免按浅克隆 revision walk 推断父关系。
- 请求不接受前端目录，只解析注册 workspace ID；禁用外部 diff/textconv、颜色、重命名检测，限制到项目路径。每个 Git 子进程沿用 5 秒及标准输出/错误各 2 MiB 上限，整次读取限 12 秒。
- patch_preview.rs 提取整行 UTF-8 截断，工作树/暂存区差异和提交差异共用 2000 行、256 KiB 上限。原有测试代码未新增或执行，常量仅在已有测试编译配置保留。
- 数据网关新增 workspace_commit_diff 只读请求。前端响应解析校验请求对象 ID、父数量/父 ID、patch 大小和截断标记。
- CommitDiffPanel 独立管理加载/错误/重试和基准说明；历史面板只允许一个条目展开差异，收起条目即卸载，关闭/刷新/切换后丢弃异步旧结果。
- 大型 Host、store、项目入口仅做接线，i18n.js 仅增加词条；核心读取、截断、校验和 UI 在独立模块。中英文帮助、平台说明与导航同步。

- 合并差异不是所有父提交的综合视图，不含分支图、签名验证、逐文件加载、补丁应用或 AI 自动发送。
