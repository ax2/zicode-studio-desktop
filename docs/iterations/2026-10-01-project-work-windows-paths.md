# 项目工作关联：Windows 路径分隔符

日期：2026-10-01。状态：代码已修改，真实桌面验收待补。

## 目标与发现

项目页依赖 `projectPathKey` 对任务、自动化的显式 `targetProject` 与当前项目路径做关联。此前已统一反斜杠、盘符大小写与 Windows verbatim 前缀，但未统一重复路径分隔符。例如 `C:\\work\\app` 与 `C:\work\app` 可指同一目录，却产生不同的关联键，导致关联项在项目页漏显。

## 修改与边界

- Windows 风格路径先统一斜杠，再压缩重复分隔符；UNC 路径保留恰好两个开头斜杠。POSIX 路径仍保持原样，避免更改其平台语义。
- 该键只决定界面上的项目关联；文件访问仍由 Host 的注册工作区与目录校验授权。相对路径和 `.`、`..` 段继续拒绝关联。
- 没有变更已存储的任务或自动化数据，也没有执行目录清理。
