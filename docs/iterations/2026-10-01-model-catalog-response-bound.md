# 模型目录响应边界工作日志（2026-10-01）

## 目标与发现

QVeris 模型目录是用户主动配置、主动刷新的可选渠道。现有请求虽设 2 MB 限制，却先通过 `response.text()` 读取整个响应；大型或恶意响应会在限额判断前占用内存。基础地址允许查询参数与片段，也会让追加的 `/models` 路径产生错误请求。

## 修改与决策

- 正常 Fetch 响应以流读取、按字节累计，超过 2,000,000 字节即取消读取；保留既有错误信息与超时控制。
- 无响应流的注入式 Fetch 实现继续通过 `text()` 兼容，随后按 UTF-8 字节数核对上限；这一回退无法在读取前限制内存，只面向非标准实现。
- 基础地址拒绝 URL 凭据、查询参数和片段。用户仍可显式配置 HTTP 网关，现有私有网络配置不受这一轮约束变化影响。

## 验证与遗留

`bun run typecheck:external-clients`、`bun run check` 与 `bun run build:extensions` 均退出 0；仓库静态检查仍报告既有警告。本轮未运行测试；真实大响应、三平台网络和 QVeris 服务行为仍待验收。
