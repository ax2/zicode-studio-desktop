# Stage：工具目录无历史存储时的托盘视图降级（2026-10-17）

## 目标与发现

大量插件工具统一进入可搜索的工具目录，收藏和最近使用依赖工作区访问记录。
托盘可以向工具中心传入 `toolView=favorites/recent` 或同等事件。
此前当 `accessStore` 缺席时，具体工具目录仍向 Host 请求个性化视图，
但不显示“全部工具”切换按钮；Host 可返回参数错误或空列表，用户会误以为工具消失。
完整应用列表也可能从托盘视图落到空收藏页，虽然“全部应用”按钮仍可用。

## 修改

在 `ManualToolDirectory` 与 `ToolCenterApp` 中将无历史存储时的有效视图固定为
`all`，用于 Host 查询、分页、筛选提示和按钮状态。保留托盘请求状态，
当历史存储重新可用时仍可选择原视图；有存储的收藏/最近使用流程不变。
没有读取其他工作区数据，也没有自动加载或执行工具。

## 验证

- 新增两项组件断言：无存储时收到托盘收藏事件后，Host 请求不携带
  `view/workspaceId` 个性化参数，具体工具和完整应用仍可见。
- 定向 Vitest：工具目录 30 项、工具中心 3 项，共 33/33 通过。
- `bun run typecheck` 与 `bun run check` 通过；静态检查的既有
  144 条 warning、10 条 info、1 条设计提示保留；`git diff --check` 通过。
- 前后只读存储扫描均完整，`target` 29,399,231,464 B / 74,559 文件，
  task-scratch 838,287,896 B / 31,062 文件，均无变化；未构建 Rust 或清理缓存。
