# 资源链路的目标插件授权快照（2026-10-18）

## 发现与修改

资源授权身份、Worker 执行、Host 内置资源处理、目录、跨插件接力、项目文件库与保存路径原先为了检查一个插件而调用 `registry.list(scene)`。完整列表为每个签名插件读取元数据和保留版本目录；资源 Worker 的运行中授权复核还会周期性重复这项工作。

注册表新增仅从内存安装清单和当前场景状态生成的 `PluginExecutionSnapshot`，包含目标 manifest、来源、启用状态和已声明权限的授予状态。上述资源路径改为按 ID 查询目标插件；未知或禁用插件仍按原分支拒绝，`resource.read`、`resource.directory.read`、`storage.plugin` 等权限检查不变。目标包模块和资源内容的完整性复核没有移除。UI 完整列表的签名发布者及历史版本字段不变。

这使 Studio 接收数十种文件、目录及数据工具时，单个资源调用不再受无关签名插件目录读取影响；它尚不是正式 `resource.v1` 发布，也没有扩大现有输入大小、Worker 时限或输出类型范围。
