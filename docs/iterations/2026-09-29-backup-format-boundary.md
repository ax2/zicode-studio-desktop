# 2026-09-29 备份格式边界

状态：实现与静态检查完成；实机验收待补。

## 发现

新增的 `contentSha256` 字段可选，以兼容旧快照。但新快照的元数据若丢失该字段，恢复会把它当作无摘要的旧快照，绕过新格式的内容校验。

## 修改

- 新快照写入 `formatVersion: 2`；旧元数据没有版本字段时按版本 1 读取，保持旧快照可用。
- 恢复拒绝未知版本、版本 2 缺失摘要，以及格式不正确的摘要；这些检查先于暂存复制与当前数据替换。
- 设置页区分旧快照、存有摘要的新快照、缺摘要的新快照和未知格式。异常快照禁用恢复，保留删除操作。

## 验证与限制

`cargo check --locked --all-targets`、`cargo clippy --locked --all-targets -- -D warnings`、目标文件 Rustfmt、`bun run typecheck`、`bun run check`、翻译覆盖与目标差异空白检查通过；全局 Biome/设计检查仍有仓库其他位置的既有提示。本轮未运行测试或真实恢复。版本号和摘要同处可编辑的本地元数据，不能抵御有意同时篡改两者；该边界用于发现意外缺失和阻止不受支持格式的恢复。
