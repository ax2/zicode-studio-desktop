# 项目命令输出完整性（2026-09-29）

## 目标与发现

- 核对项目命令运行器在 Windows、macOS、Linux 上结束任务时的输出记录。
- 子进程退出后，stdout/stderr 读取任务各最多再等 1 秒；超时会终止读取任务。此前这条路径没有更新 `truncated`，界面可能把最后一段未读取的输出当作完整记录。

## 修改与决策

- 输出读取只在收到 EOF 时报告完整；缺失管道、读取错误、读取任务异常或超时均报告不完整。两个输出读取任务中只要有一个不完整，就将运行记录的 `truncated` 置为 true。
- 保留现有的 64 KiB 每流上限、等待时间和任务终止语义；`truncated` 现同时表示达到上限或读取未完成。
- 项目运行详情中的提示同步改为“输出可能不完整”，涵盖容量截断和读取未完成两种情况。
- 将标记写入完成记录，后续历史摘要的状态与退出码仍按原逻辑保存。
