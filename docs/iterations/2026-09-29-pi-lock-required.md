# 2026-09-29 Pi 目标与摘要锁定

## 目标与发现

- 当前 Pi 锁文件包含 Windows、macOS、Linux 六个目标的 SHA-256，但下载脚本仍允许目标摘要缺失时跳过校验并安装。
- `PI_TARGET_PLATFORM` 原先可传入任意字符串，并用于生成缓存文件名及下载资产名；构建目标应限制为实际支持的六种平台与架构。

## 修改与决定

- 构建所选目标必须在固定目标集合内，锁定版本必须是安全的短标识，目标 SHA-256 必须是 64 位十六进制值；不满足时在复用、下载或改写资源目录前停止。
- 缓存与新下载归档均无条件进行 SHA-256 比对，不再存在只告警跳过摘要的路径。接受锁文件中大小写形式的十六进制摘要，写入资源标记前统一为小写。
- 本轮不改变六个已锁定摘要或更新脚本的发布者摘要来源。

## 验证与遗留

- `node --check scripts/fetch-pi-binary.js`、`bun run check` 与目标差异空白检查通过；未运行测试、下载或三平台构建。
- 目标合法性与摘要格式的静态检查不能证明远端资产可下载或本机解包可用；仍需各平台实际验收。
- 仅更新本地工作树，未发布。
