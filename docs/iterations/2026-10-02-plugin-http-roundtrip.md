# 打包插件桥接 HTTP 往返

日期：2026-10-02。状态：Windows 真实 Pi 与本机临时服务往返通过；Rust Host 接口仍待集成验收。

## 实现与验证方式

扩展 smoke 启动绑定 127.0.0.1、随机端口的临时 HTTP 服务，为真实 Pi 子进程提供检查专用的插件上下文。实际 plugin-broker ESM 仍作为扩展加载；临时观察扩展另从同一 ESM 的 setupPluginBroker 捕获工具定义，调用其实际 execute 方法，无模型推理。

服务核对请求路径、POST 方法、检查专用身份头、runtime/session/call/tool 标识与输入参数，返回确定的结果。观察扩展同时核对 details 与文本结果。另实际请求一次被拒绝的 call ID 和一次缺少 result 的成功状态响应，确认打包桥接分别抛出对应错误。

每次检查要求成功、拒绝、不完整结果各一次；结束时停止服务，正常退出 Pi 并删除临时目录。无外部网络与真实账户调用，档案不保存身份头具体值。

## 当前证据

- Inbox 与金融两个隔离场景分别完成真实 Pi 内的打包桥接 HTTP 往返与两种失败响应验证，进程正常退出。
- 插件源码规则与环境隔离共 2 个文件、4 条用例通过。
- 代码/设计检查退出 0，既有 advisory 保留。发布步骤沿用两种场景的既有 smoke 入口，因此后续发布也会执行本轮往返检查。

## 限制

本机服务模拟了 Host 响应，不是 Rust Host。此证据验证打包后的 JavaScript 桥接请求与错误处理，不证明 Rust Host 的鉴权、插件执行、权限撤销或实际插件数据变更。Inbox 真实收发、模型工具调度、WebView 与其他平台安装运行仍待完成。未运行远端流水线、未发布、未新增 Rust 构建缓存。
