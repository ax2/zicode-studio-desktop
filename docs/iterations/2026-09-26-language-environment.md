## 设计与实现边界

- `language_requirements.rs` 解析 Rust/Go 声明，`language-requirements.ts` 独立比较观察到的版本；项目面板保留原有加载、刷新和切换项目时丢弃迟到响应的机制。
- Rust 读取 `package.rust-version`，同文件中显式 `workspace = true` 继承可解析；不读取注册项目外的父目录。虚拟工作区默认值不会当作所有成员的已生效要求。
- 工具链完整数字版本按精确匹配；stable/beta/nightly、日期/目标平台别名和部分版本不推断实际编译器。两个工具链文件同时存在时保守标为冲突。
- `go.mod` 只提取顶层 go/toolchain 指令，忽略注释、依赖块中的内容；不是完整 Go 模块语法或依赖验证器。重复/缺少参数的版本指令拒绝解析。
- Go 1.21 起的语言版本（例如 1.23）排序在 beta、rc、1.23.0 之前；此前不带补丁号的版本代表首个正式发行。推荐工具链与最低版本采用不同文案。
- 文件内容限 256 KiB，单条声明限 200 字符；截断、格式错误、越界路径均不能被判为匹配。报告只返回版本要求，不返回依赖、组件或私有路径配置内容。
- 宿主默认 rustc/Go 检查与项目命令实际工具链选择是不同证据；本轮不设置 rustup override、不下载工具链，也不强制运行器满足这些要求。
