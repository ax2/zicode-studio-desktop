# 工作区关闭时的插件状态收敛（2026-10-17）

## 目标与发现

窗口销毁原先只停止工作区的 Pi/工具会话；删除工作区原先只移动 `.zicode` 数据并注销工作区。插件活动任务、待确认授权、归档游标与结果保存句柄未同步收敛，可能在关闭后继续显示为可操作或占用资源。

## 修改

- Studio Host 新增按工作区关闭入口；窗口销毁和删除工作区均调用。删除前先停止插件工作，避免在移动工作区数据后才处理运行时。
- 按工作区撤销插件 Broker token、手动工具调用、模型/HTTP 授权与操作、结果保存/传递句柄；按对应 runtime ID 撤销资源记录、待导入和待保存授权、归档游标、插件调用及资源 Worker admission，并请求停止该工作区运行时。其他工作区状态保持。
- 运行时确认停止后，插件任务 Store 将该工作区的 `queued`、`running`、`awaiting_confirmation` 记录一次性写为 `interrupted`，保留事件与终态历史；重复关闭不增加事件。
- 未修改插件协议、DevTools 工程或应用版本。

## 验证

- Store 定向 1/1：关闭一个工作区只中断其运行/待确认任务，另一个工作区的运行任务保留，重复关闭幂等。
- 隔离 Host 定向 1/1：两个工具会话与任务并存，关闭其中一个后其运行时、token、游标和任务停止/失效；另一工作区继续运行。成功夹具位于 `.cache/task-scratch`，含 owner 标记，结束后核对无遗留目录。
- 模型与 HTTP 授权定向 2/2：目标工作区操作取消，其他工作区操作保留。
- `bun run check:rust:static` 退出 0，Cargo check 与严格 Clippy 通过；rustfmt 仍为 advisory。
- 前后只读空间扫描完整、未知项 0：`target` 29,419,982,761 → 29,420,220,329 B；task-scratch 均为 852,978,182 B；E 盘可用 43,137,077,248 → 42,289,246,208 B。本轮未清理文件，卷空间变化不能归因于本阶段。
