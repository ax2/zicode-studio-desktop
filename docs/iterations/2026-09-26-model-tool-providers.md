# 2026-09-26 翻译与摘要的模型渠道选择

状态：实现与 Windows 自动化验证完成，实际界面及其他平台待验收。

## 发现与目标

- 翻译和文章摘要当前写死 QVeris 地址、默认模型及凭据选择，与「已配置模型」文案和个人平台定位不符。
- 读取当前场景实际保存的模型渠道，用户显式选择兼容模型后调用；不自动回退到特定服务。
- 支持 OpenAI chat completions 兼容渠道，包括显式关闭鉴权的本地服务；凭据仅从当前场景和选定渠道读取。
- 本轮不改动其他 AI 功能、金融适配器或用户已有模型配置。其他服务绑定继续跟进，不能据此声称整个平台已完成独立化。
- 网络请求应在阻塞线程执行，限制响应大小、超时和跳转，错误不回显凭据或服务响应正文。

## 实现与关键决定

- 新增 `model_tools.rs`，从当前场景 `models.json` 列出已保存的 OpenAI Chat Completions 渠道；前端不能传入任意 URL 或密钥，只能传渠道及模型标识，Host 每次重新解析配置。
- 共用模型选择组件用于翻译和采集摘要；列表加载不发送正文，不自动选择首项；刷新清空当前选择，场景变更拒绝旧场景选择并丢弃迟到的列表/结果。
- 翻译结果记录渠道与模型；兼容工具 `translate.text` 也要求显式 provider/model。旧客户端未提交选择时会得到配置提示，不保留固定网关兜底。
- 凭据直接按当前场景和选定渠道的凭据账户读取；关闭鉴权时完全跳过系统凭据读取和 Authorization 头。模型列表不返回密钥或凭据前缀。
- 设置渠道编辑器增加 Bearer 鉴权开关，保存和再次编辑保留 `authHeader=false`，默认仍开启鉴权。关闭不会删除用户已有密钥。
- 翻译和摘要 HTTP 处理移至 `host_server/model_tools_http.rs`，配置读取、凭据和阻塞网络执行放到阻塞线程，减少 Host 主文件职责。
- 配置及响应各限制为 4 MiB，翻译 60 秒、摘要 90 秒超时；禁用 HTTP 重定向，拒绝含 URL 凭据、query/fragment 的模型地址。响应错误只返回稳定代码和状态码，不回显服务响应正文或请求头。
- 真实本地 HTTP 测试首次返回 503，定位为系统代理接管回环请求。已让 localhost、回环 IPv4/IPv6 直连，远程服务继续沿用系统代理。
- 摘要发送前补齐 Notes 的 `network.fetch` 权限检查；本地存储授权本身不能授权发送正文。
- 首次统一检查发现重复翻译键、React effect/列表 key 静态规则问题，以及已有任务复制定时器在测试卸载后触发。已去重翻译键、使用稳定模型键并说明刷新依赖，在任务测试 teardown 正式卸载 React 树以执行定时器清理。
- 后续全套 Rust 测试发现 Windows 的 accept 连接可能继承 listener 非阻塞状态，夹具偶发 `WouldBlock`；已显式设置接收连接为阻塞模式，保留读取超时后重新验证。

## 验证与边界

- 真实临时模型配置验证场景隔离、必须显式选择、不回退 QVeris、模型目录不含配置密钥。
- 真实回环 HTTP 服务覆盖翻译、摘要、免鉴权请求、选定凭据、禁用重定向、响应大小和 JSON 校验；测试凭据均为无效夹具，未读取用户凭据或调用付费服务。
- 真实 Host HTTP 用例覆盖 Notes 网络权限拒绝、缺少模型选择拒绝、停用翻译插件后模型目录拒绝。
- 组件与网关覆盖模型选择、目标场景参数、空目录刷新、迟到请求丢弃、未选择或跨场景时禁止提交正文、设置页免鉴权保存。
- 当前仅覆盖显式保存的自定义 Chat Completions 渠道；其他协议、OAuth、自定义请求头和仅存在于内置目录的模型不在支持范围。配置中的明文 apiKey 不作为此入口的凭据来源。
- 本地模型服务需要用户另行安装并启动；本轮不包含模型下载、运行时安装或断网实机验收。无模型时仍可使用独立的本地笔记编辑等能力。
- 浏览器通道仍返回 `nodeRepl.fetch request failed`；按 frontend-testing-debugging 技能保留实际 WebView/布局/截图验收，不擅自改用另一浏览器通道。
- 其他默认渠道注入、金融数据适配与成本追踪仍需后续推进；Windows 证据不能替代 macOS/Linux 验收。
- 此入口与 Pi 聊天、模型健康检查及统一预算仍是不同调用链，不能推断本地聊天模型接入或成本审计已一并完成。
