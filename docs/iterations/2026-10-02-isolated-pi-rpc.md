# 内嵌 Pi 的隔离通信验证

日期：2026-10-02。状态：Windows 真实内嵌 Pi 检查通过，跨平台发布流程已接入但未远端执行。

## 发现与修改

现有 RPC smoke 使用临时工作目录，但仍继承用户配置路径、技能、扩展与环境。旧契约包含技能命令来源，因此受个人机器配置影响。

现使用临时 HOME/USERPROFILE/PI_CODING_AGENT_DIR，仅继承进程启动所需的系统环境，关闭自动扩展、技能、提示模板与主题发现。明确创建并加载一份检查扩展和技能，无模型推理、无服务凭据、无实际项目脚本执行。先核对真实二进制 `--version` 与锁定版本一致，再进行 RPC 检查。

先注册响应等待器再写入请求，避免快速响应遗漏；持续消费 stderr 但不保留内容。关闭 stdin 后等待正常退出，超过五秒则终止并标为失败，成功消息只在退出码为零且清理完成后输出。临时文件自动删除。

Release 四个平台构建行均在内嵌资源准备后运行该检查，失败阻止后续打包。无需更新或放宽既有 0.84.2 契约文件。

## 验证

Windows 内嵌 Pi 0.84.2 的 `get_state`、`get_commands`、`set_steering_mode`、`set_follow_up_mode`、检查扩展 prompt 与 abort 六项实际命令通过，并正常退出。发现命令来源为明确加载的 extension/skill，事件包含 extension_ui_request。

最初完全关闭技能时，检查按预期报告 commandSources 缺少 skill；随后加入明确的临时技能，原契约通过。退出检查初版被 lint 的 finally 控制流规则拒绝，改为清理完成后检查退出结果，最终代码/设计检查退出 0，既有 advisory 保留。

## 范围

这证明本机内嵌 Pi 的基础 RPC 协议，不证明 Rust Host/WebView 桥接、真实模型请求、会话磁盘恢复、后台任务或安装成功。其他平台仍待真实发布运行。未触发远端工作流或发布，未新增 Rust 构建缓存。
