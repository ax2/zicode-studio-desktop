# 项目命令运行摘要导出（2026-09-28）

## 目标与发现

项目任务与自动化定义保存在工作区 `.zicode/` 目录，随项目文件迁移；项目命令运行摘要保存在设备应用数据目录的 `project-run-history.sqlite3`。后者不会仅因复制项目目录而出现在另一设备。已保存的旧运行记录只有元数据，没有命令正文或输出。

## 修改

- 命令页在成功读取当前项目运行列表后提供主动下载 JSON 的入口；读取失败、操作进行中或无记录时禁用。最多导出当前列表前 40 条记录，若列表更多则写入省略数量；文件上限 2 MiB。
- 导出格式包含项目名、导出时间、快照接收时间、历史保存状态和运行 ID、名称、子目录、工具类别、状态、起止时间、退出码、清单指纹及历史标记。只提取这些字段，不导出工作区内部 ID、命令正文、调用参数、解释器路径、stdout 或 stderr。
- 界面与中英文帮助提示文件为明文，任务名和目录仍可能包含私有信息；下载只供留存与审阅，不导入新设备的运行历史，也不证明快照是实时状态。

## 验证与限制

TypeScript 类型检查、定向 Biome、i18n 覆盖（缺失 0）、React 构建、`bun run check`、严格 MkDocs 构建及差异空白检查通过。全局检查仍有既有警告。本轮未新增或运行测试；桌面下载行为、各系统文件保存和跨设备使用仍待验收。
