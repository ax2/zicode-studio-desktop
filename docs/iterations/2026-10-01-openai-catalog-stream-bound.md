# 通用模型目录流式读取边界（2026-10-01）

## 目标与发现

用户可自行配置兼容 OpenAI 的模型渠道并主动同步目录。目录读取已有 2 MB 上限，但无 `Response.body` 时会先调用 `text()`，在计算字节数之前把整段响应载入内存；只提供 `text()` 的注入响应可绕开实际内存边界。

## 修改与决策

- 通用渠道目录要求可流式读取的响应。没有响应流时直接报告无效 JSON；真实空响应本来也无法构成有效目录。
- 保留响应头的提前拒绝与流中逐块累计上限。渠道 URL、凭据、目录条目数量和模型 ID 的既有校验不变。
- 这一改动仅针对通用渠道；其他渠道的响应读取仍需分别核对，不能据此宣称所有联网入口均有同等边界。

## 验证与遗留

`bun run typecheck:platform-core`、`bun run check`、`bun run build:extensions` 和目标文件 Biome 格式检查均退出 0。仓库检查仍显示既有警告。未运行测试；真实兼容服务的大目录、异常流和三平台网络行为仍待验收。
