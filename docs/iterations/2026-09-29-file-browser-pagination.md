# 2026-09-29 项目文件侧栏分页

状态：实现与静态检查完成；真实界面验收待补。

## 目标与发现

上一轮为防止 Host 无界读取，超过 4096 条目的目录只能报错。开发者项目常有大型目录，侧栏应能继续浏览，而不是要求用户退出应用。

## 修改与决策

- 文件读取移入 `host_data/files.rs`；旧 `list_files` 客户端保留原有完整响应和 4096 扫描条目边界。新客户端显式请求分页，每页 200 项，单次扫描上限 100000 条。
- 两种目录扫描都在线程池中运行，不占用异步 Host 协议处理线程；每次扫描仍受条目上限约束。
- 按目录优先、名称忽略大小写及原名补充排序。Host 对有序路径清单计算摘要；后续页提交偏移和摘要，目录增删、重命名或类型变化时拒绝旧页并要求刷新。
- 前端追加分页结果，加载失败保留已读条目并显示错误；切换目录时用请求序号忽略旧回复。旧 Host 未返回分页字段时仍能显示其完整列表。
- 同步中英文提示和帮助。分页仍会在每页扫描目录，避免跨请求保留文件系统句柄或全局快照。

## 验证与遗留

`cargo check --locked --all-targets`、`cargo clippy --locked --all-targets -- -D warnings`、目标 Rust 文件格式、`bun run typecheck`、`bun run check`、翻译覆盖、React 构建与目标差异空白检查通过。Biome/设计检查仍有仓库其他位置的既有提示。本轮未运行测试或真实界面。文件大小或内容变化不改变清单摘要；超过 100000 个扫描条目仍会报错。目录在单次扫描过程中并发变化仍可能造成不一致，三平台文件系统行为和大目录性能待验收。数据网关默认 15 秒超时，慢速网络磁盘上的大目录可能需刷新重试。
