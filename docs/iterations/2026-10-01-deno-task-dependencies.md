# Deno 任务依赖预览工作日志（2026-10-01）

## 目标与资料

前一阶段只列出字符串任务及带非空 `command` 的对象任务。Deno 官方 [Task 文档](https://docs.deno.com/runtime/reference/cli/task/)说明任务可只有 `dependencies` 而无命令；运行对象任务时，其直接依赖并行执行，也可递归触发其他任务。原列表只展示命令正文，会漏掉这些执行范围。

## 修改与决策

- 解析非空字符串数组形式的直接依赖，并在任务预览中以 JSON 字符串数组显示完整名称；带命令的对象同时显示依赖和命令。
- 仅有依赖的对象任务也进入命令目录，经用户点击后仍由 `deno task <名称>` 执行。其他格式异常的对象不猜测；任务数量上限、名称安全范围、配置读取边界和目录指纹保持原规则。
- 预览只显示直接依赖，不静态推断依赖图、循环或 Deno 的缓存选择。运行前可查看相应任务声明。

## 验证与遗留

`bun run check:rust:static` 通过（Cargo check 与 Clippy），本轮 Rust 文件的独立格式检查通过；全仓库格式检查仍提示其他文件的既有格式漂移。检查后执行 `cargo clean`，清理约 3.3 GiB 再生构建缓存。本轮未运行测试或真实 Deno 任务。Windows、macOS、Linux 的真实依赖任务运行及界面验收待补。
