# v0.7.9 · 非线性方程求根

在插件管理中审核并启用 ZiDevTools Root Solver 0.1.0 候选后，从工具中心搜索「非线性方程求根」。输入单变量 `x` 的公式和区间上下界。例如用 `x^2-2` 和区间 `[1, 2]` 求正平方根。可选弧度或角度，也可提供精确分数和有限近似小数作为常量。

二分法从端点命中或异号区间开始，返回候选点、该点的有符号残差和迭代次数。报告中的「区间已收敛」表示计算命中零值、达到宽度容差或达到浮点分辨率。可用残差判断候选点。最多 200 次迭代，公式最多 2048 UTF-8 字节、512 词元及 64 层嵌套。复杂公式与大区间的组合可能需要简化公式、收窄区间或放宽容差。工具离线运行，权限列表为空。
