# Go 工作区普通引号模块目录（2026-09-29）

## 目标与发现

- `go.work` 模块发现原先只接受未加引号的 `./` 相对路径；含空格的模块目录需要引号，因而不会进入目录列表或固定 Go 命令。
- 模块路径最终通过工作区相对目录解析器，并要求目标存在有效 `go.mod`。命令执行通过固定参数数组传递 `go -C` 路径。

## 修改与决策

- 接受无转义的普通双引号字面路径，例如 `use "./my module"`，单行与 `use (...)` 块使用同一解析入口。
- 引号内仅额外允许普通空格；保留 `./` 前缀、长度、目录段、工作区范围、链接拒绝及模块数量边界。
- 含反斜杠转义、嵌套引号或更复杂 Go workfile 语法仍标记为不完整，不尝试猜测转义结果。
