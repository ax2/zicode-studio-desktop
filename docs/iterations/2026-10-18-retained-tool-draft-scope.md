## 发现

旧文档把“离开整个工具中心的草稿保护”笼统列为未完成。
当前 `retained-tool-center.js` 在相同 scene/workspace 下移走并重新挂回同一个
React 容器；`plugin-shell.js` 导航到其他应用时不销毁该实例。
现有外壳用例实际输入文字，切到 Notes 再从工具入口返回，确认文字仍在、
详情仅加载一次且没有执行工具。切换 scene/workspace 会销毁原实例，
此路径尚无未保存草稿的确认或恢复承诺。
