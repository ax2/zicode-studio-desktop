# Stage：提供方工具目录版本漂移核对

日期：2026-10-17。目标是持续追踪 Zi DevTools 全部工具范围，而不把其正在修改的工作树当成 Studio 的版本化插件交付。只修改 Studio 的只读核对脚本与档案，不修改提供方源码、冻结夹具或接入矩阵。

## 修改

新增 `scripts/compare-provider-catalog.mjs`。显式接收一份 `tools.json` 路径，与 Studio `devtools-all-tools-matrix.json` 的 `sourceToolId`、独立工具版本、源状态比较；拒绝重复 ID、缺失版本及未知状态，输出来源和矩阵文件 SHA-256、双方计数、新增/消失 ID、版本/状态差异及当前状态计数。`--fail-on-drift` 在有效但存在差异时退出 1，输入无效退出 2。脚本不读固定的兄弟仓库路径，不安装、执行或自动改写插件/矩阵。

续补可选 `--baseline <冻结 tools.json>`：对候选与明确指定的冻结目录再比较版本/状态、`scope` 文本及发现元数据，并分别报告差异。`scope` 必须是非空字符串；发现元数据如存在必须是对象。对象键按规范顺序计算 SHA-256，避免 JSON 属性顺序产生假阳性；报告只存变更 ID 和两侧摘要，不将尚未核准的提供方描述复制进 Studio 接入矩阵。严格模式同时考虑矩阵和冻结快照差异。
