# Python 环境文件夹选择（2026-09-29）

## 目标与发现

- 项目工具目录页已支持手动输入现有 venv 或 Conda 前缀，但没有桌面原生目录选择入口。Windows 驱动器路径和 macOS/Linux 用户目录的手输成本较高。
- 现有保存接口会检查 `pyvenv.cfg` 或 `conda-meta/history` 与 Python 可执行文件，无需运行解释器或激活脚本。

## 修改与决策

- 桌面端自定义 Python 环境模式增加原生文件夹选择按钮；选择结果只填写草稿，用户仍须明确保存。
- 选择器仅接受本地绝对路径；取消不更改草稿，调用失败显示错误。
- 异步选择结果按工作区组件代际隔离，切换项目后旧选择不会覆盖新项目草稿。
- 移动和远程客户端不提供原生选择按钮，保留已有只读边界。

## 验证与遗留问题

- `bun run typecheck` 与 `bun run build:react` 退出 0；选择器按钮已进入生成的项目 bundle。
- `bun run check` 退出 0；仓库现存 Biome 提示和设计检查提示仍会显示。
