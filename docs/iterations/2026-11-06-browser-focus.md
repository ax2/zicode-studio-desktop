# Browser keyboard handoff and search dismissal — 2026-11-06

The native WebView2 accelerator callback recognizes only unshifted Control+F and Control+L, handles the event before emitting to the trusted Studio window, and suppresses autorepeat. It never accepts webpage messages as shortcuts. The frontend verifies the active tab and absence of blocking UI both before and after the asynchronous native-to-chrome focus handoff. Trusted-chrome Control+L selects the complete address, while Control+F continues to open the compact find bar.

Escape and the find close button stop the native search, then restore focus to the visible webpage. Programmatic closing for navigation, tab transitions and application switches does not restore focus. An epoch prevents a delayed manual close from stealing focus after reopening, changing tabs or opening a modal. Native focus commands resolve the view through the requesting window's registry and reject hidden tabs. No new top-level Tauri command, webpage IPC or profile schema is added.
