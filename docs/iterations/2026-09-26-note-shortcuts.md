# 2026-09-26 笔记快捷入口隔离

状态：实现与静态检查完成，运行验收待补。本轮不新增或运行测试。

## 发现与设计

- 最近/置顶 ID 使用全局 localStorage 键；切换工作区未清空 pinnedNotes，请求没有作用域或顺序检查，空最近列表还会保留旧内容。
- 改为 scene/workspace 隔离的完整 notebookId/noteId 引用，只持久化引用，不存储标题或正文。使用 IndexedDB 事务更新，避免两个窗口覆盖整个偏好快照。
- 读取按完整引用解析，与正文搜索过滤和列表扫描上限解耦；过期请求不写 UI，失败清空旧标题并允许重试，引用保留。
- 旧全局 ID 不直接展示；用户选择恢复后，仅迁入当前工作区列表中唯一匹配的条目，原旧数据保留。

## 实现记录

- `shortcut-repository.ts` 在独立 IndexedDB 中按 scene/workspace 保存版本化引用；读改写处于单个事务，recent/toggle/import/clear 都在最新记录上应用。仅引用持久化，损坏记录拒绝覆盖。
- `note-shortcuts.ts` 管理按工作区的内存缓存、失败操作队列和请求序列。旧作用域的存储和网络结果不发布到新页面；失败操作按顺序重试，已确认事务不重复执行。
- 普通列表刷新复用当前工作区已加载摘要，缺失引用按 4 个并发读取；显式刷新/重新聚焦逐条重新读取，上限为 8 recent + 16 pinned。空结果清空显示，失败保留引用但不保留旧快捷缓存标题。
- 旧数据显式恢复，只匹配当前返回列表中的唯一 ID；没有宣称扫描完整。旧全局键保持原样，便于其他工作区恢复。
- 新增加载/存储失败/重试、旧入口恢复、二次确认清空当前工作区引用。控制组件按工作区 key 重挂载，避免确认状态跨工作区沿用。
- 置顶状态和 React key 改用 notebookId/noteId 组合；切换同时清空旧筛选、搜索定时器、展开状态和回收站计数。
- notesStore/NotesApp 仅做类型、模块、生命周期和控件接线，核心逻辑在独立模块；同步中英文帮助与导航。

## 边界与待验收

- 偏好保存在当前 origin/应用配置，清除浏览器数据或更换地址后可能不可用；不属于 Host 备份或跨设备同步。

- 笔记移动后旧 notebookId 引用可能失效，保留并提示重试；可在新位置重新置顶或清空旧引用。
