# 帮助链接导航修复

日期：2026-10-02。状态：实现与定向检查完成。

## 发现

帮助文章装饰器拦截所有以 `.md` 结尾的链接，并只按最后一段文件名匹配本地页面。移动访问指南中的 GitHub Termux 文档因此被阻止打开；外部地址与本地页面重名时还会错误打开本地页面。

## 修改

只为当前 manifest 已注册的本地文件链接绑定内部导航，支持 `page.md` 与 `./page.md`。外部 URL、协议相对地址、其他目录文件及未注册文件保留通常的链接行为。新增点击事件回归，验证本地链接触发正确页面加载，外部及其他链接不被本地导航取消。
