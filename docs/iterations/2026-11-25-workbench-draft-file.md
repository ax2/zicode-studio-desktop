# v0.7.9 · 数据工作台草稿文件

在使用冻结 Compute 0.2.0 的「表格转 JSON」「表格转 CSV」或「表格筛选与排序」中，点「下载草稿」可以保留当前编辑的表格和设置。文件由浏览器或 WebView 的下载流程交付，可在以后启动 Studio 时打开同一个工具，选择「从文件恢复草稿…」。核对文件名和大小后选择「替换当前草稿」。可用「撤销上次导入」恢复之前的两个字段。确认后由用户手动执行。

草稿 JSON 使用 `zicode-workbench-draft` 版本 1，含插件 ID、能力 ID、插件版本和两段原始文本。文本中的有效 i64/u64 和换行保持原样，选项允许继续编辑尚未写完的内容。表格和设置分别沿用 8 KiB 与 16 KiB，文件上限 160 KiB，用于容纳 JSON 转义。拒绝无效 UTF-8、未知或重复字段、不支持的版本及其他工具的草稿。选取后改变当前输入、切换工具或丢失原目录权限均不能执行旧确认。

下载文件中的内容是明文。Studio 不会写入应用资料库、自动恢复文件或自动执行工具，文件不包含工作区路径、授权或执行结果。下载、读取与恢复原文件分别由用户操作。

## Windows 验证

- 正式工具中心资源在 1180px 英文浅色、420px 中文深色，各实测三个入口。点下载后在全新浏览会话确认草稿为空，重新选择下载的文件、核对、确认、撤销和再次恢复，随后手动发给生产 Windows Worker。原表格和下载文件均逐字节回读。
- 冻结 Compute 0.2.0 候选 01，WASM SHA256 `136d1afa1ec0dd07f77bba5114f000cd8f8d7c16e2c80fa21418ab7bc9fbf3dc`。实际结果分别核对 u64 最大值、i64 最小值及 TSV 排序。输入事件核对 CRLF 和原始设置。等待执行、确认、取消和撤销均无自动 Worker 调用。
- 235 个定向用例通过，12 个其它可选候选用例未运行。类型、全仓前端检查及中英文词条覆盖通过。草稿保护、未知字段和过期选择有独立回归。实际下载与文件选择事件使用任务专用无头浏览环境，Windows 原生下载或文件对话框仍由集中验收跟踪。

同一工具中心会话中已验证的关闭重开和表格接力继续可用。应用内命名多实例、兼容旧版本和更大输入由 [#28](https://github.com/ax2/zicode-studio-desktop/issues/28) 跟踪。
