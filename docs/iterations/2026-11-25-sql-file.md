# v0.7.9 · SQL 格式化文件导入与结果下载

在工具中心打开冻结 ZiDevTools Text 0.4.1 的「SQL 格式化」，点击「导入 SQL 文件…」。选择的 `.sql` 文件须为 UTF-8 且不超过 8 KiB，UTF-8 BOM 可用。导入只替换 SQL 编辑区，可撤销。点击「执行工具」才格式化，原文件保留。空白、错误后缀、超限、编码无效和读取失败都保留现有输入。

格式化成功后，点击「下载格式化 SQL」。Studio 将本次返回的完整 SQL 文本交给现有下载流程，建议名称为 `formatted-sql-<时间戳>.sql`。改动当前输入后需要重新执行。格式化继续使用通用方言和默认布局。独立版的 PostgreSQL/MySQL/SQLite/SQL Server 选项、缩进、大小写和更大文件仍由 [#28](https://github.com/ax2/zicode-studio-desktop/issues/28) 跟踪。Windows 桌面下载体验及实体系统文件窗口保留集中验收。
