# 2026-09-26 笔记编辑切换保护

状态：实现与静态检查完成，运行验收待补。本轮不新增或运行测试。

## 发现与设计

- 筛选、新建、复制、删除和批量移动仍有忽略保存失败并清空 dirty 的路径。
- 提取共用编辑切换检查，固定作用域，等待保存成功后继续；响应到达时再检查编辑与选择是否变化。
- 删除/移动派发期间禁用当前编辑器，避免已删除的旧内容与新的输入交错；所有请求使用开始时的工作区。
- 批量操作保留失败条目的选择，仅清空确实已移动或删除的当前笔记；切换工作区后停止派发剩余条目。
- 本轮不宣称已实现跨工作区草稿持久恢复或应用关闭时的自动恢复；这些仍需后续推进。

## 实现记录

- `editor-transition.ts` 统一等待保存、检查 dirty、工作区与编辑上下文；导入导出与删除移动互斥。
- `editor-navigation.ts` 接管筛选、新建、复制、创建/选择笔记本和进入采集。新建返回后若编辑上下文变化则保留编辑器。
- `editor-mutations.ts` 接管单篇和批量移动/删除及删除笔记本；操作使用固定工作区，版本优先取已保存编辑器，部分失败只移除成功条目的选择。
- 编辑器使用 inert 和忙碌提示，状态写入也拦截锁定期输入。打开笔记响应和新建响应检查锁定状态。
- `chat-note-capture.ts` 提取聊天保存，固定工作区并在响应到达时保留未保存或已变化的编辑器。
- 回收站读取增加工作区检查，避免操作后的旧刷新污染新工作区。
- 大文件仅保留模块接线、锁定状态及 UI 提示；独立模块均低于 500 行。中英文帮助及文档导航同步。
