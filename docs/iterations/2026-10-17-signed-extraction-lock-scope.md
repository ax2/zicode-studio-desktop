# 签名包解包锁范围（2026-10-17）

## 目标与发现

Studio 已在注册表锁外验签，但签名包解压到暂存目录、读取清单仍在锁内。正式提供方可能交付较大的多工具包；解包期间持锁会使其他插件操作排队。

## 修改

新增 `PreparedSignedInstall`：接收已验签包，在注册表锁外提取到唯一暂存目录并核对完整清单。准备对象在错误或拒绝时清理暂存。Host 先验签和准备，再锁定注册表提交。提交阶段继续重读发布者信任，保留已有版本检查、元数据写入、修复隔离、回滚与撤销行为。未改 DevTools 源码、签名容器协议或提供方候选。
