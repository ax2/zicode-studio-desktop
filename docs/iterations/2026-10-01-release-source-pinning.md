# 跨平台 Release 源码固定

日期：2026-10-01。状态：工作流已修改，远端运行待验收。

## 目标与发现

发布准备、Windows/macOS/Linux 构建此前各自按可移动 tag 检出源码。若 tag 在作业间移动，三个安装包可能来自不同提交，而最后仍满足文件名和数量检查。发布资产摘要核对只证明每个平台上传内容与各自本地文件一致，不能证明三平台构建使用同一源码。

## 修改与决策

- 准备阶段明确检出 `refs/tags/<tag>`，记录已检出的提交 SHA 作为作业输出。
- 三个平台只按该 SHA 检出，避免构建排队期间重新解析 tag。
- 发布阶段再次检出明确的 tag 引用，要求其当前提交仍与准备阶段相同；不同时保留草稿并拒绝公开。既有各平台产物内容核对和四件资产清单门槛保持。
- 这不阻止发布完成后有人移动 tag；仍需仓库侧 tag 保护。真实远端作业和安装包来源尚未验证。

## 验证与遗留

本轮只修改 YAML 与档案，未运行测试或发布。Python YAML 解析通过，`git diff --check` 退出 0；本机没有 `actionlint`，因此未做 GitHub Actions 表达式级检查。需要下一次受控 tag 发布在 Actions 上记录准备输出、三平台检出 SHA 和发布阶段的 tag 核对结果。
