# 2026-09-29 备份元数据一致性

状态：实现与静态检查完成；真实恢复验收待补。

## 发现

备份列表会把目录名覆盖到解析后的元数据 ID；恢复则只核对工作区 ID，并按目录中实际存在的应用来恢复。若快照目录或 `backup.json` 被移动、删改，界面可能显示一个看似正常但不完整的来源。

## 修改

- 列表仅收录元数据 ID 与目录名一致的快照。
- 恢复入口核对元数据 ID 和实际可恢复应用目录清单；缺失、额外或重复声明阻止恢复。
- 完成来源暂存复制后，将实际写入字节数与元数据 `sizeBytes` 对比；不一致时删除暂存并返回错误，不创建恢复前快照或交换当前应用目录。

## 风险与验证

`cargo check --locked --all-targets`、`cargo clippy --locked --all-targets -- -D warnings`、目标文件 Rustfmt 和目标差异空白检查通过。本轮未运行测试或真实桌面恢复。字节数只能发现大小变化，不能证明同长度内容未被修改；跨平台真实文件复制及恢复仍需验收。历史快照若元数据本来与实际内容不一致，会被拒绝恢复，需要人工检查或保留原始目录。
