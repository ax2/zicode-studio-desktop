# 工具直达入口的导航失败收束（2026-10-18）

## 目标与发现

Studio 工具目录的“打开应用”在 React 点击回调中调用异步外壳导航。原实现没有捕获 `activateFromNavigation` 或 View 直达过程的异常，入口返回的 Promise 可能被事件处理器忽略，用户也看不到明确失败提示。这是插件失败不能影响主界面的一个窄边界，不等于整个插件故障隔离已经验收。

## 修改

`public/native/plugins/plugin-shell.js` 的具体工具直达回调将导航、目标/版本复核和 View 定位放进异常捕获，失败时显示固定本地化提示，不展示异常原文；能力调用仍不由此入口触发。`public/i18n.js` 补充中文提示。没有更改插件启用、权限或提供方代码。

## 验证与边界

本地 `plugin-shell.test.js` 35/35 通过，其中故障注入在 `openTool` 抛出私有错误后核对提示不含错误原文、能力调用 0、聊天与工具中心仍可切换。`bun run check` 退出 0，仓库既有 147 条 lint warning、10 条 info 和一个设计提示。本轮未重建 Debug EXE；原生窗口和真实插件故障尚未验收，没有新的界面截图。

当前提供方候选目录只读核对没有 `.zicode-plugin` 正式包；ZiDevTools 完整接受仍 0/154，ZiFile 仍 0/108。用户暂不启用的 JSON 对象插件保持禁用；Inspect 0.1.2 隔离原生安装等待先前单独的即时确认。

测试前后只读空间预算的 `target=30,036,693,723 B`、`.cache/task-scratch=1,411,796,787 B` 和 `UnknownEntries=0` 未变；E 盘空闲 `8,188,063,744 → 8,180,543,488 B`，卷差额未归因于本轮。预算脚本因既有容量和空闲门槛退出 1，未删除文件。
