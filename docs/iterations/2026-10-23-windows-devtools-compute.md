## 如何使用

运行 `D:\work\start-zicode-studio.cmd`，可从首页或顶部“快捷工具”直接打开已收藏工具，也可进入“工具”按名称或用途搜索，再点“打开工具”。表单有 `text`（输入文本）和可选的 `options`（选项）；填好后点击“执行工具”。无需启动独立 ZiDevTools EXE。

- ASCII码表：text填 `0x41`、`65`、`A` 或 `NUL`，也可留空列出128项；options留空。
- 特殊字符与表情：text填查询词或留空；options可填“全部”“标点与排版”“数学与单位”“箭头与状态”“表情”“颜文字”。结果保留完整组合字符。
- 标题字符画：text填 `Hello 42`；options可填单个填充字符，如 `#`。返回art与不支持字符数，标题最多40字符。
- 图片字符画：text填PNG/JPEG/WebP纯Base64；options填输出宽度，如 `80`（8至120）。目前支持小图显式输入，尚无文件选择界面。
- 二维码PNG：text填待编码文本，options留空。2026-10-26当前Windows界面执行后可直接预览图片，并点“下载PNG图片”导出原PNG；“查看图片编码”仍可复制dataUrl。Studio的“预览保存”保留完整结构化结果，与下载PNG图片分别提供。
- 数据质量：选择JSON/CSV/TSV对应操作，text填数据，options留空；检查缺失/null、空白字符串、重复行与类型分布。
- 数据列变换：例如text填 `name,age\n  Alice  ,42`（\n处实际换行），选“列去首尾空白”，options填 `{"format":"csv","column":"name"}`。填null时增加 `"value":"新值"`；重命名value填新列名；选列使用 `{"format":"csv","column":"","keep":["name"]}`。另有大小写、空转null、文本/整数/数字/布尔转换。返回变化报告、结果表和可复制CSV。
- CSV关联：text填左表；options例如 `{"format":"csv","right":"id,team\n1,A","left_key":"id","right_key":"id"}`。支持左连接、内连接、按同名列追加、按行号拼列；类型不强制转换，重复键稳定展开，空键不匹配。
