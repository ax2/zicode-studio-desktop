# v0.7.9 · Base64 文本文件编解码

「Base64 编码」可从本机导入不超过 8 KiB 的 UTF-8 文本。点击「执行工具」后，选择「下载 Base64 文件」即可获得本次 `.base64` 结果。编码保留原文本的 UTF-8 BOM、换行和空白。

「Base64 解码」可导入 8 KiB 内的 Base64 文件，选择器优先显示 `.base64`、`.b64` 和 `.txt`。导入时移除文件开头的 UTF-8 BOM，并将 CR/LF 分隔的 Base64 内容拼接。其余字符和填充仍由现有解码器严格验证。解码结果须为有效 UTF-8，成功后可下载 `.txt`，包括仅含空白和零字节的有效结果。

文件导入可撤销，取消选择或读取失败时保留草稿和原件。执行与下载均须主动点击。输入变化后，原结果的下载入口收起。
