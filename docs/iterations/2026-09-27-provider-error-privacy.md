# 2026-09-27 外部服务错误隐私

状态：本轮实现与定向静态检查完成；全仓类型检查和运行验收待办。

## 发现与决策

- 本地翻译和摘要模型调用返回固定错误码或 HTTP 状态；没有将模型请求正文写入日志。
- 可选 QVeris 模型目录客户端原先将上游错误对象的文本带到异常；金融能力客户端会带上经过模式替换的上游文本，未知网络异常也会拼进错误。上游可回显凭据、请求内容或服务端内部信息，模式替换不能覆盖任意敏感文本。
- 非成功 HTTP 响应只暴露状态码，不读取错误正文；成功响应仍按原有 JSON 与大小规则解析。超时、超限、无效 JSON 和网络异常映射为固定消息，不拼接原始异常。
- 保留 QVeris 作为可选来源，保留现有认证、请求参数和成功响应；不更改金融数据与模型目录格式。

## 工作记录

- QVeris 模型目录同步在非成功 HTTP 响应时直接返回状态，不读取上游错误正文；成功响应保留原有模型解析。超时、超限、无效 JSON 和其他异常统一为固定文本，不拼接上游异常。
- 金融能力客户端同样不读取非成功响应正文；去除正则替换后再显示上游文本的路径，未知网络异常只返回固定错误。已有目录同步断言更新为状态码错误。

- 没有改动凭据读取、请求目标、成功响应数据、计费确认和 QVeris 的可选定位。
