# 签名插件预览与安装前置校验（2026-10-17）

## 发现与修改

签名包预览此前只校验运行时与文件输入声明，没有执行 Studio 完整的清单及 Host profile 兼容性校验。原安装流程又在已有插件冲突、提取清单和版本门槛检查之前写入发布者信任，导致部分拒绝安装仍留下信任状态。

现在签名验证阶段执行与插件注册相同的完整清单校验；安装先检查信任确认、内置插件冲突、解包清单和版本门槛，再持久化新发布者信任。提取后的清单、已装清单或版本解析失败时清理本次 staging。没有修改签名格式、插件协议版本、界面布局或 DevTools 工程。

## 验证

- 签名生命周期定向测试 1/1：schemaVersion 1 错误声明 requiredProfiles，在预览和安装时均被拒绝；试图替换内置插件被拒绝；两种拒绝均未写入发布者信任。随后正常签名安装、升级、回退、撤销仍通过。
- `bun run check:rust:static` 退出 0；Cargo check、严格 Clippy 通过。首次 Clippy 对新增闭包调用报多余借用，修正后重验通过。rustfmt 报仓库已有格式漂移，仅作提示。
- 前后只读存储扫描完整、未知项均为 0：target 29,420,797,353 → 29,420,796,841 B，task-scratch 均为 932,850,915 B；E 盘可用 43,016,835,072 → 42,526,363,648 B。卷空间变化不能归因于此项源码修改；本轮没有清理既有缓存。

## 边界

新发布者的信任仍须在激活前写入，以便重载校验签名安装。激活及元数据写入等更晚的 I/O 失败仍可能留下信任记录，需要后续事务化处理。没有正式 DevTools 签名包，本轮没有真实原生安装或 154 项工具验收；`fullToolsAccepted` 仍为 0/154。没有界面布局变更，无新截图。

后续 [签名安装信任回滚](2026-10-17-signed-trust-rollback.md) 已覆盖本次新增信任的部分晚期失败路径；旧版留存、回滚自身写盘失败仍保留为边界。
