# WebView2 资源更新与清理（2026-09-28）

## 发现

Windows WebView2 脚本已按 SHA-256 校验内置离线安装器，但锁文件换用新文件名时，旧安装器仍留在 `resources/webview2`，会随静态资源映射进入安装包并占用空间。直接复制到最终文件名时，写入中断也可能留下不完整文件。

## 修改

- 校验目标文件名只为当前目录下的 `.exe`，拒绝路径分隔符。
- 从已验证的缓存复制到资源目录的随机临时文件，再核对 SHA-256 并重命名为目标文件；失败时清除临时文件，原目标保留。
- 当前安装器有效或新安装完成后，删除资源目录中的旧文件和残留临时文件；遇到意外子目录则中止，避免递归删除未知内容。
- 非 Windows 目标仍沿用现有 Windows 专用资源清空流程。

## 验证与限制

`node --check`、定向 Biome lint、`bun run check`、离线 MkDocs 严格构建和 `git diff --check` 均通过；全局检查保留现有告警。本轮未运行测试，也未下载或运行 WebView2 安装器。Windows 上的重命名、安装及跨平台打包仍待真实验证。
