# 2026-10-18 插件目录内存投影

## 发现与修改

Studio 的 Pi 工具搜索、能力清单、命令定位和 Worker 内外部插件判断原先会调用完整插件列表。完整列表为每个签名插件读取签名元数据和历史版本目录；当插件数量增长到上百个时，这些磁盘读取会出现在无关工具的查询和执行准备路径中。

这些内部查询现直接使用注册表内的安装清单、场景启用状态和声明的权限。`pi.tools.register` 仍必须在清单中声明且当前场景获准。完整插件列表与 UI 摘要的字段及磁盘读取行为未改；单个插件执行时的签名和模块文件校验也未取消。运行时入口定位不再先扫描完整列表，但仍会校验目标插件本身。
