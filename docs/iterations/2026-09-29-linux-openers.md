# 2026-09-29 Linux 系统打开器选择

## 目标与发现

- 项目外部应用列表原先始终显示 Linux 文件管理器入口，但实际打开只执行 `xdg-open`；缺少该命令时入口无法使用。
- 外链打开也只依赖 `xdg-open`，在提供 GLib `gio` 却未安装 `xdg-open` 的系统上会失败。

## 修改与决定

- Linux 优先使用 PATH 中可执行的 `xdg-open`，缺失时使用 `gio open`；两个入口共用同一选择规则，不调用 Shell 解析路径或 URL。
- 两者均不可用时不展示文件管理器目标；直接调用打开器会得到明确错误。Windows Explorer 与 macOS `open` 路径保持各自系统实现。
- 只检查命令文件存在及可执行权限，不把发现结果等同于桌面环境中实际可打开目标。
