- Pi 资源复用原先只核对版本标记和非空主程序。文档、主题、资源或运行依赖被清理后，构建入口仍会跳过重建并将不完整目录打入安装包。

## 修改与决定

- 已安装复用和新解包提交共用一份基本结构检查：主程序及上述文件须是非空普通文件，资源与依赖目录须为普通目录。新解包缺失时保留旧目录并报告缺失相对路径。
- 这里只做轻量结构检查，不读取整个依赖树；锁定归档的 SHA-256 仍负责下载内容完整性。安装后人为修改文件内容、平台运行行为需要独立验收。
