# 2026-09-27 命令运行选择与聊天分析

状态：实现与静态检查完成，运行验收待进行。上一轮知识交接已有代码和静态检查进展，本轮接续命令排查。

## 目标与设计

- 查看当前 Host 保留的任意运行记录及输出，默认跟随最新；显式选择后固定记录，记录消失时提示，不能静默改为另一条。
- 将当前显示记录作为快照加入同项目聊天草稿，携带运行 ID、目录、状态、时间、退出码、输出与截断/过期标记。
- 已持久化的历史摘要没有命令全文和输出，必须作为缺失材料说明；运行中状态不等于最终结果。
- 只准备草稿，不自动重跑、停止、安装、修改文件或发送模型请求。

## 工作日志

- 已检查运行轮询、历史摘要恢复和输出上限。现有历史 UI 只显示最新记录的输出，准备提取详情并加入选择与分析入口。
- ProjectRunDetails 提取详情、停止动作和输出，补充运行 ID/结束时间，旧 Host 未报告目录时不再猜测为根目录。
- ProjectRunHistory 默认跟随最新，显式选择固定 ID；选中记录消失时显示提示，可恢复跟随。选择历史记录后原停止限制仍生效，已保存摘要不显示伪造命令或输出。
- ProjectRunnerPanel 把运行数据、historyStatus 和前端接收时间合并到按 API/工作区匹配的快照，API 或工作区改变时隐藏旧数据；轮询/操作后对账成功更新接收时间，失败或操作中标记可能过期。
- run-analysis.ts 校验工作区、运行 ID、状态、时间、退出码和文本长度。当前输出每流最多 65536 UTF-16 单元，摘要材料省略命令和输出并使用 saved-summary-only 标记；没有静默截断。
- RunAnalysisButton 交接点击时显示的快照，JSON 材料说明 running/stopping/unknown 不是最终结果；isCurrent 保护工作区、场景和项目路径，通用交接函数继续保护实例/会话和草稿。
- 大型 store、项目入口与 app.js 只增加回调接线，i18n.js 仅补充翻译；中英文帮助、平台说明和导航同步。
