# Stage：Pi 聊天插件结果操作入口（2026-10-17）

## 目标与发现

Text 0.3.0 candidate-03 的真实 Pi/Host 专项已有可用的 Host 文本结果引用，
但聊天卡片只显示工具输出及复制，不能从界面触发“发送到/保存”。
现有插件 View 与手工工具已使用可信父页面的结果面板；本轮复用该面板，
不把桌面令牌或转交授权交给 Pi/插件。

## 修改

- 聊天工具卡片仅对当前实时、成功且带合法 `text/plain` Host 引用的
  Pi 结果显示“使用结果”；业务错误、无效引用和历史卡片不显示入口。
  原始可复制输出保持不变。
- 点击后只向同一 Studio 父页面发内部事件。父页面再次校验引用及来源，
  使用当前工作区/场景/会话身份打开现有保存、接收工具搜索、输入预览与
  独立确认面板。切换实例/会话/工作区后，旧面板不能继续提交；
  用户可直接关闭。Host 仍最终核验引用、来源、授权及目标。
- 增加中英文入口文字，复用已有结果面板样式和协议，没有更改提供方 ABI。
  源码审查发现工具卡片既有按钮样式宽度固定为 24px，因此给文字入口
  单独设置自适应宽度、内边距和可见状态。组件截图复查又发现聊天区
  复用面板时被父子两层高度限制截断；聊天面板现由外层统一滚动，
  高度上限为 50vh，接收工具入口在 1280×720 视口可见。
