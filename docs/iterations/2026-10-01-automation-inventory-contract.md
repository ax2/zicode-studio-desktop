# 自动化跨工作区清单响应边界（2026-10-01）

状态：前端边界与空状态已接入，静态检查通过；真实桌面验收待完成。

## 目标与发现

- 自动化中心通过 Tauri 原生调用读取全部已注册工作区的规则和任务摘要。调用方的 TypeScript 类型不能保证旧版或异常 Host 在运行时返回同样的结构。
- 原页面收到非数组或缺少字段的结果后会直接渲染，可能在 `.map` 或日期格式化时出错；空数组只显示空白列表。

## 修改与决策

- 在清单读取结果进入状态前检查数组、工作区 ID、路径、时间、状态枚举、非负安全整数计数、可选错误码及 ID 唯一性。异常结果进入已有扫描错误分支，保留上一份有效清单。
- 首次读取到空数组时显示“暂无可扫描的已注册工作区”，不把正常空结果写成扫描失败。此更改不触发任务派发，也不改变 Host 调度频率。
