# v0.7.9 · 数值统计

在插件管理审核并启用 ZiDevTools Numeric Statistics 0.1.0 候选后，可从工具中心搜索「数值总和」「算术均值」「中位数」「总体方差」「样本方差」「总体标准差」和「样本标准差」。输入支持逗号、Tab 或换行分隔的 1–64 个实数，最多 4096 UTF-8 字节。样本方差和样本标准差至少需要两个数，空值会提示错误。

默认使用有理数精确计算。可选择近似小数模式。两种标准差的平方根都明确标记为近似。所有操作离线运行，无需文件、网络或模型权限。
