## 本轮设计

- 发现 package.json scripts，按 packageManager 或锁文件选择 npm/pnpm/yarn/bun。
- 启动只接受注册 workspace、任务名和清单指纹，重新读取清单并拒绝过期预览。
- 显示真实脚本内容；用户显式选择运行，包管理器可能执行生命周期脚本。
- 每项目最多一个活动运行，全局最多四个；保留有限的运行历史和 stdout/stderr 尾部。
- Windows 挂起启动后加入 Job Object 再恢复；Unix 新建进程组。停止/应用退出清理进程树。
- 本地桌面可启动和停止；远程客户端沿用 Host 权限边界，仅可查看。
- 后续专项运行验收应使用临时无害项目，不能代替用户执行真实仓库的部署、发布或其他脚本。

## 实现记录

- 新增 `project_tasks/{catalog,process_tree,protocol,mod}.rs`，Host 入口仅做注册项目解析与分发。
- Catalog 只读根清单，限制 256 KiB / 100 个脚本，拒绝逃逸项目的符号链接；
  指纹包含原始清单与选择的包管理器。运行前再次读取，过期预览拒绝执行。
- 管理器来自应用配置的 Bun 或绝对 PATH，排除项目内可执行文件；不会自动安装或强制匹配版本。
- Windows 使用隐藏、挂起进程，在分配 Job Object 后恢复，Job 关闭或显式停止时清理；
  Unix 使用进程组，终止标识只消费一次，避免历史记录释放时重复发送 kill。
- 每项目一个、全局四个活动任务；记录全局最近 40 条，每路 stdout/stderr 尾部上限 64 KiB。
  查询仅返回该项目历史，日志只返回最近运行；数据不写入磁盘。
- `start_project_task` / `stop_project_task` 走 Host mutation 通道并拒绝远程客户端；
  `project_task_catalog` / `project_task_runs` 为读取接口。
- React 项目命令页展示脚本、包管理器、运行/停止、最新日志、退出码和较早状态。
  页面卸载结束轮询，项目切换重新挂载；请求序号避免旧轮询覆盖操作后的状态。
- 生命周期钩子、宿主权限、无交互输入、退出即停止、非持久历史均在中英文帮助中说明。

## 偏差与遗留

- 当前覆盖 JavaScript 包脚本，不含 Cargo、Python、Go、Make 任务或交互终端。
- Unix 进程组不是沙箱；主动新建会话脱离进程组的程序不在此清理保证内。
- 清单指纹用于检测普通编辑导致的预览过期，不提供并发修改的文件系统事务保证。
- 运行状态/日志按 1.5 秒轮询；历史仅保留状态与时间供查看，较早运行的输出不开放检索。
- 下一步先补齐专项生命周期与视觉验收，再扩展多语言任务目录和版本要求诊断。

  拒绝其他设备命名空间。保留脚本名和敏感命令字符限制。
- 探针生成的临时批处理、目录以及错误解析时产生的空 `run` 目录已清理。
