# 2026-10-01 自动化清单持续刷新

状态：实现及前端静态检查完成；实机验收待记录。

## 目标与发现

- 桌面 Host 持续处理全部已注册工作区的定时规则和任务，但自动化中心的跨工作区清单只在首次打开或用户点击“刷新”时读取，长时间停留会显示过时状态。
- 上一轮的请求序号保护能避免旧结果覆盖新结果，却仍会为连续点击发出多个并行的全工作区扫描。

## 修改与决策

- 自动化中心打开期间每 60 秒刷新一次清单；页面从隐藏恢复可见时立即刷新。隐藏期间不做定时扫描，卸载时移除定时器和可见性监听。
- 同一清单读取同时最多运行一次；读取期间到达的手动、定时或可见性刷新合并为一次随后执行的扫描。已有结果在新扫描完成前保留，若已有后续请求则忽略当前结果。
- 读取函数更换或页面卸载后，旧扫描结果不再更新当前视图。失败保留最近一次成功清单，同时显示扫描错误。

## 验证、偏差与风险

- `bun run check`、`bun run typecheck`、`bun run build:react` 与新增 hook 的 Biome 格式检查通过。本轮不新增或运行测试。
- 前端检查仍报告已有的 123 条 warning、7 条 info 和 1 条设计 warning。
- 定时清单只更新页面展示，不改变 Host 调度频率或文件写入行为；系统休眠或页面未显示时不会保证 60 秒刷新间隔。
- 真实桌面隐藏/恢复、多窗口与三平台扫描压力仍待验收。
- 本轮只更新本地源码及档案；未提交、推送或发布。
