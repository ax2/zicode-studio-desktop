# 开发插件预览锁范围（2026-10-17）

## 目标与发现

上一阶段把开发插件目录选择变为只读预览，但 Host 通过注册表锁调用预览，而预览会校验清单并读取包内所有文件计算内容摘要。单包上限 2,048 文件、50 MiB；该扫描持锁会让无关插件操作排队。

## 修改

Host 在锁内只获取受管插件根路径，然后释放锁并执行 `PluginRegistry::preview_developer_package`。预览仍拒绝位于受管根下的源目录，沿用完整清单验证与目录内容摘要。安装命令保留原先的复核，不接受仅凭旧预览直接信任源目录。此变更只在 Studio；DevTools 候选与共享契约未改。

## 验证与边界

定向注册表测试验证预览不安装、预览后改动拒绝和重预览成功。`bun run check:rust:static` 通过，包括严格 Clippy；全库 rustfmt 既有漂移仍为 advisory。此轮未构建新 EXE 或重复做原生截图；上一阶段已在当前 Debug 窗口确认预览卡。锁范围缩短由 Host 调用代码证明，尚无多插件并发延迟的实测基线。

首轮静态检查发现旧实例方法只被测试引用，严格 Clippy 因 dead-code 失败；移除方法并调整测试后，静态检查通过，定向测试 1/1 通过。未放宽检查规则。
