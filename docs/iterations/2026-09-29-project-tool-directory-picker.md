# 项目工具目录选择（2026-09-29）

## 目标与发现

- 项目工具目录页允许最多八个绝对路径，并按顺序置于任务与终端的宿主 PATH 前，但此前只能手动逐行输入。
- 上一轮的 Python 环境选择器已经提供桌面原生文件夹对话框；同一接口可用于工具目录草稿。

## 修改与决策

- 桌面端增加“添加工具目录”按钮，复用本地绝对路径文件夹选择能力。
- 选择结果只加入当前工作区草稿；重复路径不重复加入，达到八个目录时显示现有上限提示。用户仍须明确保存，保存时 Host 继续验证目录。
- 选择器期间暂时禁用编辑和保存；切换工作区后忽略旧选择结果。远程和移动端保持只读。
- Python 环境按钮改用共享的目录选择接口，避免两套原生对话框逻辑。

## 验证与遗留问题

- `bun run typecheck`、`bun run check` 与 `bun run build:react` 均退出 0；仓库现存的 Biome 与设计检查提示仍会显示。
- 未运行测试，也未在 Windows、macOS、Linux 安装包中操作原生对话框。
- 工具目录可执行文件发现仍需三平台实机验收。
