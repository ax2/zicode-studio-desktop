# v0.7.9 · 矩阵计算

在插件管理审核并启用 ZiDevTools Matrix Calculator 0.1.0 候选后，在工具中心搜索「矩阵加法」「矩阵减法」「矩阵乘法」「矩阵转置」「矩阵行列式」「逆矩阵」或「矩阵方程求解」。矩阵输入支持从电子表格粘贴。列用 Tab 分隔，行用换行分隔。每个矩阵最多 8 行、8 列和 4096 UTF-8 字节，每格最多 96 字节。求逆和求解 AX=B 要求 A 可逆，B 可有多列。

默认按有理数精确计算。选择近似模式可使用有限的浮点小数和科学计数法。界面显示可复制的表格文本，原始结果保留精确分子、分母或明确标记的近似值。整个过程离线，不需要文件、网络或模型权限。
