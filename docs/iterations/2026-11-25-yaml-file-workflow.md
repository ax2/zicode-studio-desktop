# v0.7.9 · YAML 与 JSON 文件转换

在工具中心选择「YAML → JSON」或「JSON → YAML」。可粘贴，或选择 8 KiB 以内的 UTF-8 文件。前者接受 `.yaml` 和 `.yml`，后者接受 `.json`，扩展名不区分大小写。可撤销上次导入，取消或文件读取失败时保留草稿。

点击「执行工具」后才转换。成功后点击「下载 JSON」或「下载 YAML」，取得本次完整结果。文件扩展名与输出一致，源文件保留。输入不同于本次执行时需重新运行。
