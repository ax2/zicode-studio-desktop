# 2026-09-30 Poetry 环境结果导入

状态：界面与文档实现，静态检查通过；真实三平台验收待补。

## 目标与发现

Poetry 项目已提供用户主动执行的 `poetry env info --path` 固定任务，但结果只显示在运行记录中；使用该环境执行普通 Python 命令仍需手工复制路径。Host 持久化运行摘要不保存输出，因此只能从当前 Host 会话的完整运行记录读取路径。

## 修改与决策

- 开发环境页新增「使用最近发现的 Poetry 环境」，读取同一工作区、同一子目录最近一次 Poetry 查询；只有该次成功且完整输出仍在当前 Host 会话时才填入草稿，失败后不会回退到旧路径。
- 只接受未截断、单行、非空且看起来是绝对路径的标准输出；不自动运行 Poetry，也不直接保存设置。
- 导入前重新读取当前子目录任务清单，并比对运行时指纹及固定任务；项目清单或已保存的工具配置变化后要求重新查询。
- 用户检查草稿并保存后，Host 沿用现有 Python 环境目录校验。所选环境影响此项目后续普通 Python 命令和新终端；Poetry 固定任务继续自行选择环境。
- 运行输出只在当前 Host 会话可用；重启后需再次主动运行查询。
