# 插件重载的精确任务与授权作用范围（2026-10-17）

## 目标与发现

显式重载插件目录此前无条件清空所有插件的归档游标、模型/HTTP 授权，却不更新内部插件任务状态。注册表已为相同安装保留进程内执行代次，因此可以只处理重载后身份变化或消失的插件；全局撤销会影响未变化插件的工作。

## 修改

- 注册表暴露当前已安装插件的执行代次快照。Host 在重载前后比较，按变更插件 ID 精确失效归档游标、模型/HTTP 授权并撤销活动任务；即使重载返回错误，也对已变化身份执行收敛。未变化插件保持游标、授权和任务。
- 移除已不再使用的 HTTP 授权全局失效方法。未新增插件协议或版本号。

## 验证

- 真实 Host HTTP 插件生命周期专项 1/1：原样重载保留游标和 `running` 任务；修改受管开发包清单版本后重载，旧游标失效、所属任务 `revoked`；无关插件任务仍为 `running`。后续禁用、撤权、卸载原有断言仍通过。
- `bun run check:rust:static` 退出 0，Cargo check 与严格 Clippy 通过；rustfmt 仍报既有 advisory。首次定向测试通过但指出全局 HTTP 失效方法未使用；移除后复跑静态和定向专项均通过。
- 前后只读空间扫描完整、未知项 0：`target` 29,419,072,127 → 29,419,504,255 B；task-scratch 均为 852,978,182 B；E 盘可用 46,113,808,384 → 46,105,047,040 B。没有清理文件，卷空间变化不归因于本阶段。

## 边界与遗留

执行代次由安装身份/清单决定；开发包在同清单下被原位修改的内容身份尚未纳入任务持久恢复判定。Store 写入失败仍为 best effort，工作区关闭尚未协调；生命周期 profile 未发布，真实提供方任务和跨平台运行未验收。DevTools 完整工具接受仍 0/154。

后续进展：受管开发包的进程内内容身份已纳入显式重载比较，见 [受管开发插件内容身份](2026-10-17-plugin-content-identity.md)。任务持久恢复、正式提供方与跨平台边界仍待验收。
