# 2026-09-29 签名插件视图

状态：JS 语法、目标文件 lint 与差异检查通过；真实签名包与跨平台视图待验收。

## 目标与发现

- Rust 插件注册表的 `view_document` 同时允许开发者插件和签名插件，且先校验场景启用、声明的视图及包内 HTML 文件。
- 前端插件 Shell 已把这两类插件交给视图宿主，但宿主 `renderLocation` 只接受 `developer`；签名插件的主区和侧栏因此保持空白。
- 离开视图时的未保存确认和清理也只覆盖开发者插件，签名插件即使标记脏状态也可能直接离开。

## 修改与决定

- 视图宿主接受 `developer` 与 `signed`，共用现有不带同源权限的沙箱 iframe、CSP 和消息桥。
- Shell 对两类外部插件都执行离开确认和实例清理。远程端仍不加载外部插件 HTML，并显示统一的桌面端说明。
- 本轮未新增或运行测试。

## 验证与遗留

- `node --check`、改动 JS 文件的 Biome lint、视图宿主与翻译文件的 Biome check、差异空白检查通过。`plugin-shell.js` 整文件有现存导入排序及格式漂移，本轮未批量改动。
- 真实签名插件的视图声明、权限提示、跨平台 WebView 与未保存离开交互仍待实机验收。
