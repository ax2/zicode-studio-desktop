# v0.7.9 · Java 与 Python 堆栈日志文件

「Java 异常链」和「Django / Python 堆栈」支持导入 8 KiB 以内的本机 UTF-8 日志，文件选择器推荐 .log、.txt 和 .traceback。导入只更新输入草稿，可撤销。取消、无效编码或文件超限时保留当前草稿。读取时去掉文件开头的 UTF-8 BOM，保留内容和原换行，原件字节不变。

点击「执行工具」后离线解析文本。成功后可显式下载同一次调用的完整 JSON。修改输入、切换工具或调用失败时，旧结果的下载入口失效。保持冻结插件的 48 KiB 输出约束，超限时显示错误并保留输入。解析只读取日志文本中的位置和异常关系。

## Windows 验证

- Studio 冻结 Trace 0.1.1 候选逐一核验 352 个文件。既有[真实 Windows Host、Worker 和 Pi 验收](2026-10-18-trace-011-studio.md)含两个操作及十阶段权限生命周期。
- 生产工具中心的独立自动化在 1180px 英文浅色和 420px 中文深色，通过本机测试接线调用生产 Windows Worker 12 次。8 次成功下载的 JSON 与冻结预期及 Worker 输出逐字节一致，覆盖 Java 主异常链和 Suppressed 分支，以及 Python 直接异常原因。其余 4 次均为预期 48 KiB 报告上限拒绝。
- 两工具均通过 8192 字节输入、8193 字节拒绝、无效 UTF-8、取消、撤销和草稿保留。合成日志含 BOM 与 CRLF，十个源文件的字节回读一致。没有外部请求。
- 302 项工具中心与矩阵测试通过，24 项既有跳过。TypeScript、110 条 Tauri 命令权限及 5539 个中文词条检查通过。工具中心资源 SHA-256 4be1b1ed5f059780f452da8a0ce83f8d1744ceaff25d618ba2509656496970fe。
