## 发现与设计

- 原上下文包回调触发聊天激活后立即写入旧 input 引用，没有等待激活、验证项目会话或捕获错误，还会 trim 原草稿。
- 使用与 Git 审查相同的受作用域约束交接函数，保留既有文字和附件，仅准备草稿。
- 按当前知识快照校验引用，拒绝刷新/切换后的旧选择和非法引用；标题与 ID 用结构化 JSON 引用，不插入可执行调用文本。
- 显式说明仅携带引用，笔记正文在用户发送后由模型按 notes_get 读取；读取失败时不得臆测正文或比较结论。
