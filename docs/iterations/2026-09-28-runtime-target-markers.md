# 内置运行时目标标记（2026-09-28）

## 发现

Pi、Bun 和 Windows PortableGit 的资源目录使用 `.version` 跳过重复安装。旧标记只含版本号及二进制存在性；同版本切换 `PI_TARGET_PLATFORM` 时，目录里可能保留上一次目标架构的二进制并被误判为已安装。

## 修改

- 三个脚本的标记均绑定版本、目标键和对应锁文件的资产 SHA-256（Pi 未固定 SHA-256 时记空值）。
- 旧版纯版本号标记自动失配，下一次执行会按当前目标重新准备资源；正常的同目标重复执行仍跳过。
- 目标匹配只决定是否复用；下载资产时仍按各脚本既有的校验流程处理。

## 验证与限制

三个脚本的 `node --check`、定向 Biome lint、`bun run check`、离线 MkDocs 严格构建和 `git diff --check` 均通过。定向 Biome 完整格式检查仍报告 Pi 脚本原有的 CRLF 格式，以及 Bun 脚本一处未改动的排版；未重排整个脚本。本轮未运行测试、下载运行时或制作安装包。新标记不证明目录内文件在安装后未被外部修改；跨平台切换与安装包启动仍待实机验收。
