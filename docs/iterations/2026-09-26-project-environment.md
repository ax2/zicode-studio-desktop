# 2026-09-26 项目开发环境诊断

状态：已实现并通过本机自动验证，视觉与跨平台实机验收待补。
目标是让个人项目具备可复核的开发环境信息，为运行任务提供基础。

## 设计边界

- 识别项目根目录的常用清单与 JavaScript 声明的运行时要求；只读取有界清单，不读取凭据文件。
- 检查宿主启动环境中 Git、Node、Bun、Python、Cargo、Go 的可用性与版本。
- 使用固定参数、绝对可执行路径、超时和输出上限；不执行项目脚本或自动安装工具。
- 检查工作目录使用系统临时目录，避免读取项目工具链覆盖；Rust 自动安装关闭。
- 明确版本仅代表宿主环境，不代表满足全部依赖或已通过项目构建；Pi 显示锁定版本，不宣称健康。
- UI 按需检查、可刷新；项目切换时不显示旧项目报告，清单读取失败与未发现清单区别呈现。

## 实现

- 新增 `project_manifest.rs`、`environment.rs` 和独立协议测试模块，避免在 Host 大文件中
  实现新功能；Host 分发只增加操作接线。
- 项目根目录识别 package.json、Cargo.toml、pyproject.toml、requirements.txt、go.mod、
  CMakeLists.txt。仅解析 JavaScript 清单中的 engines/packageManager，限制 256 KiB；
  不返回脚本内容或其他字段，越界文件与格式错误单独标记。
- Git、Node、Bun、Python、Cargo、Go 并行探测，固定版本参数，每项最多 3 秒，
  每个输出流最多 16 KiB，版本摘要最多 200 字符；不透传原始进程错误。
- 从绝对 PATH 项解析可执行文件，跳过项目内工具、相对 PATH 项和 Windows Store 别名；
  Unix 实现还检查执行权限。保留原始调用名以支持 rustup shim。
- 版本检查清除 Node/Bun/Python 的预加载环境变量；禁止 Rust 自动安装，Go 使用本地工具链。
- 新增项目导航“开发环境”，进入时检查并支持刷新；遵循现有 React/Zustand、设计令牌和
  中英文体系。项目切换和重试期间立即隐藏旧报告，并忽略晚到响应。
- 只增加大型项目页面和 store 的必要接线，新 UI 在独立模块；同步项目 React 与 CSS 构建产物。
