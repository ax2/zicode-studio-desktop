## 初始发现

## 修改及依据

- 命令目录夹具返回请求目录，匹配 Host 目录确认约定；启动夹具返回实际 run 记录，避免把缺失回复当成功。运行器仍拒绝不明确启动结果，未降低产品门槛。
- 环境空状态采用当前“所选目录”文字；保存摘要断言针对 stdout/stderr，不把新增手动目录输入框误认为保存的输出。
- 终端失败启动用例先等待首次列表读取成功再操作，保留产品首次读取门槛。
- 笔记反向链接用例设置当前选中笔记；迟到读取用例使用选择订阅启动的实际两次读取，避免重复手动请求消耗错误的夹具回复。
- 回收站恢复/删除预期携带版本与删除时间。清空用例先读取实际条目，验证逐项 purge 并确认没有调用旧整库清空 API。
- 回收站渲染与失败重试等待实际读取结果；快捷键保存先进入编辑并改变内容；部分批量失败保留失败条目选择供重试。
- **产品修复**：项目概览中 Git 状态、Git 历史和最近命令三个同级面板曾使用相同 workspaceId 作为 key。改为面板类型加 workspaceId，保留工作区切换时重置状态，并消除同级标识冲突。
