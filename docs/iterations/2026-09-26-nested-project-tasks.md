## 目标与设计

- 在已注册工作区内发现包含 JS/Rust/Go/Python 清单的子目录，支持选择目录并运行其中命令。
- 限制扫描深度、目录项与结果数量，跳过依赖、构建输出和隐藏目录；不执行项目文件。
- Host 校验相对路径与真实目录边界，启动时重新读取清单；清单指纹绑定执行目录。
- 工作区仍是并发和历史隔离单位，切换子目录不隐藏正在运行的任务；运行记录展示执行目录。
- 子目录按自己的清单与标准 `.venv` 解析，不推断 monorepo 依赖图或继承父项目运行环境。

## 实现记录

- 独立 `directories.rs` 负责发现和路径解析；Host 大入口仅扩充一处读取路由。
- 新增 `project_task_directories`；清单与启动操作接受可选 `directory`，省略时兼容根目录。
- 相对路径采用 `/`，拒绝绝对路径、父级跳转、空路径段、目录链接和 Windows reparse point。
  读取及启动都重新解析目录；正常文件变更由绑定真实目录的清单指纹检测。
- 扫描深度四层、目录项上限 2048、项目目录上限 64（包含根目录）；忽略隐藏目录、
  node_modules、target、dist、build、vendor、venv、__pycache__、site-packages。
  到达上限或遇到访问问题返回 incomplete，界面保留提示。
- 包管理器宿主查找仍排除整个工作区；Python 显式 `.venv` 按子目录选择，宿主回退也排除整个工作区。
- 独立目录选择组件处理刷新与迟到响应；切换目录先移除旧清单，再请求对应目录的新清单。
  运行历史按工作区保留，最新输出和较早记录均显示执行目录。
- 项目 React 产物已重建；无关场景的生成产物未纳入本轮变更。
