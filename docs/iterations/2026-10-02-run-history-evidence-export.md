# 命令历史导出证据信息（2026-10-02）

## 目标与修改

个人开发平台的运行记录需要可交接、可复盘。本轮补齐现有 JSON 摘要导出的证据信息，而不新增运行命令或输出导出入口。

导出前复用历史响应解析，校验工作区归属、重复 ID、条目字段和读取时间；不把传入的工作区 ID 写入文件。保留既有 format/version 和最多 40 条条目、2 MiB 文件上限。

新增 `timestampUnit: unix-ms`、`source: displayed-history-snapshot` 与 `outputExported: false`。各条目记录快照报告的状态是否为终态、Host 内存输出或仅保存摘要的来源，以及输出是否截断。历史摘要的截断状态为 null，因为 Host 历史记录不保留该信息；不能把默认 false 当作完整输出的证据。命令、参数、stdout 和 stderr 继续排除。
