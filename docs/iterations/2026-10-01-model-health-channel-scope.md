# 模型健康结果渠道作用域工作日志（2026-10-01）

## 目标与发现

模型健康检查可能在用户编辑、禁用或移除渠道后才返回。原有 Host 逻辑会把迟到的健康结果按提供方和模型 ID 无条件写入偏好文件；批量检查还可能据旧请求的 `model_not_found` 自动隐藏模型。连接测试虽在末尾核对渠道修订号，但此时健康写入已经发生。

## 修改与决策

- 发起每个模型检查时记录当前渠道修订号；结果写入前重新读取渠道。渠道变化、禁用或配置暂时不可读时，返回 `unknown` 和刷新提示，不写入旧健康结果。
- 批量检查只对确实返回 `unhealthy` 的当前结果保留原有 404 可见性规则；作用域失效的结果不会触发自动隐藏。
- 设置页在 `unknown` 状态下也显示具体错误，避免只看到“健康状态未知”而错过刷新提示。
- 凭据独立于渠道配置存储；仅改密钥但渠道修订号不变时仍可能留下旧健康结果。跨文件的完全原子性及真实并发行为待后续处理。

后续已增加应用内凭据版本轮换和旧结果拒绝，见[凭据作用域接续日志](2026-10-01-model-health-credential-scope.md)；外部凭据变更及跨文件原子性仍待处理。
