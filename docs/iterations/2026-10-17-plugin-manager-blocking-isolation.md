# 插件管理阻塞操作隔离（2026-10-17）

## 发现与修改

原生插件管理的五个 Tauri `async` 命令直接执行系统目录/文件选择器、包预览校验或注册表文件操作。选择器、50 MiB 上限内的签名包 SHA-256 校验以及安装/回退可能阻塞异步运行线程。现将开发插件选择并安装、签名包选择并预览、签名包安装、回退和发布者撤销，统一提交到项目已有的 `tauri::async_runtime::spawn_blocking`。保留原有 Host 方法、路径/签名/权限门禁和返回值；阻塞任务异常变成明确的命令错误。

## 验证

`bun run check:rust:static` 退出 0，Cargo check 与严格 Clippy 通过；rustfmt 仍提示仓库现存格式漂移。本轮没有改 UI 布局、安装格式、插件协议或应用版本，没有新截图、完整运行副本或 ZIP。

## 限制

静态检查只证明类型与严格 lint 通过。没有在当前原生窗口对系统对话框或大包执行响应性压测；前次隔离桌面尝试的 Windows 文件选择器确认输入问题仍未解决。`spawn_blocking` 不消除注册表互斥锁、操作系统对话框等待或慢盘 I/O，也不保证插件安装可以被安全取消。正式 DevTools 签名包仍未交付，154 项完整工具验收保持 0/154。跨平台实际对话框与故障隔离仍待验收。
