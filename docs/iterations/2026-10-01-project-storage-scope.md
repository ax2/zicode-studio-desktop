# 项目存储视图隔离工作日志（2026-10-01）

## 目标与发现

项目存储扫描属于工作区和选中的子目录。原组件在这两个输入变化时复用 React 状态：新扫描尚未返回前，旧扫描结果与打开目录错误仍可能出现在新项目标题下。已有调用方只按子目录设置组件 key，工作区切换不能清除这段状态。

## 修改与决策

- 存储面板将工作区 ID 与子目录组成视图作用域，并为每个作用域重新建立扫描、错误、重试和打开状态。
- 移除调用方仅按子目录设置的重复 key。旧请求在组件卸载后由已有 effect 清理标志阻止回填。
- 共用的子目录选择器也按工作区 ID 重新建立组件，清除未提交的手动路径草稿、确认状态与错误；已按工作区标记的发现结果保持原有请求核对。
- Host 扫描契约和只读边界不变；页面仍明确显示逻辑大小不是可回收空间。

## 验证与遗留

`bun run typecheck`、`bun run check` 与 `bun run build:react` 均退出 0；仓库静态检查仍报告既有警告。本轮未运行测试；真实多工作区切换和 Windows/macOS/Linux 界面仍待验收。
