# 项目工作概览（2026-09-28）

## 目标与依据

开发者个人平台的项目总览应同时承接代码运行和个人工作。此前总览仅显示项目任务、自动化数量；用户要进入项目工作页才能找到具体条目。现有 `ProjectWork` 快照已经按项目路径或工作区 ID 关联任务与自动化，并将活跃任务排在前面。

## 修改

- 总览展示最多三条项目任务，以及最多三条已启用或待审批的自动化。任务使用原有状态标签；待审批自动化单独标明。
- 条目复用项目工作页已有的打开事件，保留进入完整项目工作页的入口。没有额外查询或新的跨平台 Host 协议。
- 正在刷新时显示状态；部分来源读取失败时说明可能显示上次成功读取的条目，不把空快照误报为没有工作。
- 窄屏改为单列布局；正文只显示标题与状态，不在总览重复长任务说明。

## 验证与风险

TypeScript 类型检查、全局 lint/设计检查、i18n 覆盖、定向 Biome 格式检查、React/CSS 打包及离线严格 MkDocs 构建通过。在线文档构建曾因 PyPI 请求超时中断，随后用本机缓存离线构建成功。本轮未运行测试。工作列表沿用现有快照排序，不能推断优先级或截止时间；跨平台实机和视觉验收仍未完成。
