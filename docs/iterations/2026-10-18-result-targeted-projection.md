# 结果接力的内存插件投影（2026-10-18）

## 发现与修改

结果来源证明、结果捕获类型、确认保存授权原先为单个插件调用完整 `registry.list(scene)`，接收工具搜索也用它遍历插件。完整列表会读取每个签名包的磁盘元数据与保留版本；随着插件增加，无关包可能拖慢结果展示、接力和保存。

单目标路径改用 `execution_plugin(scene,id)` 内存快照。接收搜索仍遍历当前场景的多个插件，但改用 `execution_plugins(scene)`，不读取签名包磁盘元数据。来源证明继续包含目标插件的 manifest、当前场景权限、执行修订及适用时的模块摘要；目标模块的实际完整性校验没有移除。搜索分页、分类、收藏/最近筛选、用户确认和保存授权条件不变。用户选择暂不启用的 JSON 对象候选插件保持禁用。
