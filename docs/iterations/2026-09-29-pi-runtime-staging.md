# 2026-09-29 内嵌 Pi 运行时暂存

## 目标与发现

- Pi 是聊天和扩展功能的内嵌核心运行时。版本更新脚本原先在解压前删除现有运行时；下载成功后若解压或目录展平失败，开发与打包会失去旧版本。
- Bun 与 PortableGit 已使用共用的同卷目录暂存切换逻辑。

## 修改与决定

- Pi 的 ZIP/TAR 解包、目录展平、可执行文件检查、Unix 执行权限与 macOS 临时签名都在暂存目录完成；写入版本标记后才切换目标目录。准备或提交失败会清理暂存并尝试恢复旧目录。
- 复用检查要求主程序为非空普通文件，避免仅凭版本标记与路径存在就跳过损坏资源。
- Windows PowerShell 解压后备路径通过环境变量传递归档和目标目录，不把项目路径拼入 PowerShell 代码，兼容路径中的单引号。
- macOS 临时签名失败仍沿用告警语义；真实签名和多进程启动需在 macOS 验收。

## 验证与遗留

- `node --check scripts/fetch-pi-binary.js`、`bun run check` 与目标差异空白检查通过。未运行下载、解包、测试或三平台实际构建。
- 目录切换不能保证断电事务；缓存下载残片和中断遗留目录仍需独立处理。
- 本轮只更新本地工作树，未发布。
