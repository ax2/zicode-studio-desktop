# 跨平台检查范围与权限门槛（2026-10-02）

## 依据与修改

上一轮完整入口发现九项缺失原生命令权限，而跨平台统一入口没有调用权限规则，可能在相同缺口下给出其他检查通过的报告。本轮将 `tauri-permissions` 作为独立必需步骤纳入 CHECKS，使用 `bun run check:permissions`，沿用独立日志、失败汇总和各平台证据报告。

前端检查从列举部分目录扩展到 `frontend/src` 全目录，覆盖设置、金融、创作工具及所有共享组件；原有选定原生网关和扩展存储用例保留。新增配置回归断言全前端范围和权限失败会使汇总失败。

扩展检查时发现模型下拉夹具在同一容器创建三个 React root。实际应用只创建一次 feed 并刷新状态；用例改为一个 feed 依次观察空、加载和错误状态，消除夹具重复 root 警告并更贴近实际状态切换。

## 验证边界

本机完整前端与跨平台入口配置用例：82 个文件、717 条通过；类型、静态规则和独立权限规则通过，39 个原生命令声明完整。静态规则仍有既有 124 条 warning、7 条 info 和终端生成代码设计 advisory。本轮未重编译 Rust。

这里只验证新的前端范围及权限步骤本机行为，没有重跑包含 Rust/Python/Go 的完整 check:platform，也未触发云端四个 runner。真实三平台执行、WebView 和安装验收仍待完成。
