# 笔记云同步

在「设置 → 笔记云同步」登记当前工作区的 HTTPS WebDAV 信息。保存、刷新、生成恢复码只处理本机配置，不会连接云端。配置完整后，点击“立即同步”，核对已保存的地址、账号和同步库 ID，再确认执行一次同步。

## 配置与运行

1. 填写 HTTPS WebDAV 地址与用户名，地址不包含内嵌账号密码、查询参数或片段。
2. 新建云端笔记库时，保留新生成的同步库 ID，并生成恢复码、妥善另存。已有云端库应使用原 ID 与原恢复码，不能重新生成密钥冒充恢复。
3. 输入云端密码，保存配置。密码与恢复密钥保存在专用系统凭据服务，界面不会再次回显已存值。留空只在连接身份完全未变时保留原凭据。
4. 点击“立即同步”，核对保存的连接后确认。未保存的表单不能启动同步。下载与上传都只在这次明确操作中执行，没有定时或启动自动联网。

单个同步对象最多 8 MiB，一次快照最多 64 MiB、10,000 条记录，索引最多 2 MiB；超限停止并保留原资料。

同步范围包括已保存的笔记本、笔记、附件与删除记录；未保存草稿和 Studio/模型凭据不在范围内。云端正文和索引均加密；WebDAV 服务仍可见连接账号、对象大小和访问时间。传输协议探测条件写入支持，无法可靠防止覆盖的服务会停止同步。

同步时可以继续编辑笔记。旧快照与当前本地版本不同时，不会覆盖期间的新编辑；用户可再次手动同步。不同工作区各有任务，重复启动同一工作区会被拒绝。

设置页关闭不会取消已明确启动的任务。用户可点击“取消同步”；Studio Host 退出也会中断任务并等待资源释放。已送到服务器的请求可能先于取消生效，不能承诺远端完全没有写入。下一次手动运行会通过条件请求重新核对、复用持久加密队列。重启后不会自动重试；状态页不会把上次进程未观察到的结果当作成功。

## 状态与保护

| 状态 | 处理方式 |
| --- | --- |
| 未配置、缺少凭据或普通隔离资料禁用系统凭据 | 禁止开始；保留原设置和笔记 |
| 正在同步 | 可继续编辑；可取消这次运行 |
| 同步成功 | 已完成本次已保存资料的合并与本地事务写回 |
| 本地编辑已变化 | 保留新编辑，拒绝旧快照覆盖；再次手动同步 |
| 配置或授权改变 | 旧任务不应用下载结果；刷新后按当前配置重试 |
| 存在冲突 | 保留本地与云端两侧，不自动选边；本批尚未提供冲突选择界面 |
| 凭据被拒绝、网络错误、服务器要求等待 | 显示实际运行结果，保留笔记及待传队列；限流遵守持久等待期限 |
| 云端索引丢失、无法解密或不支持可靠条件写入 | 停止操作，避免将异常当作空库覆盖 |

凭据读取仅使用已保存配置的引用，并复核调用者提交的配置版本。网络等待期间不持设置锁；本地捕获/写回时，调用方取得与配置保存共用的锁并核对版本，写回完成后释放。这样配置保存与旧任务应用结果不能跨越同一版本栅栏。Notes 插件授权、工作区关闭状态和 Host 生命周期也会在启动及应用前复核；这不撤回之前已经发出的授权请求。

## 数据位置与测试范围

配置位于固定系统资料目录的 `notes-sync` 子目录，不随程序版本号变化。个人配置保留既有工作区摘要路径；显式命名测试资料按测试名称与工作区隔离配置、凭据和锁，不回退读取个人/其他测试名。普通隔离资料默认禁用系统凭据。

配置 JSON 只保存连接信息和秘密引用。保存会保留旧版本及其凭据引用，失败只清理本次新建的候选凭据；笔记与历史配置不因保存失败而删除。配置历史尚无恢复管理界面。

本批自动化使用自有本机 WebDAV 服务、合成笔记与合成凭据，不连接用户云服务。真实云服务与两台实体设备由 [#25](https://github.com/ax2/zicode-studio-desktop/issues/25) 跟踪。完整冲突选择、恢复管理等剩余界面继续由 [#24](https://github.com/ax2/zicode-studio-desktop/issues/24) 跟踪；持久队列和单次任务证据见 [#23](https://github.com/ax2/zicode-studio-desktop/issues/23)。
