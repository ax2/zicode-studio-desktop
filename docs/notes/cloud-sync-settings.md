# 笔记云同步配置

在「设置 → 笔记云同步」登记当前工作区的 WebDAV 信息。**目前只交付配置和独立系统凭据保管，实际同步任务尚未接入。** 保存、刷新或生成恢复码都不会连接 WebDAV，也不会读取、上传或改写笔记、草稿及附件。

## 设置方式

1. 填写 HTTPS WebDAV 地址与用户名。地址不要包含账号密码、查询参数或片段。
2. 新建云端笔记库时，保留新生成的同步库 ID，并点击“生成恢复码”。勾选“显示恢复码”后可复制并妥善保管。
3. 输入云端密码，保存同步配置。密码和恢复密钥分别进入专用系统凭据，界面只显示是否已保管，不回显已存值。
4. 在另一台设备准备配置时，使用同一同步库 ID、同一恢复码及对应云端账号。不要为已有的云端库重新生成恢复码。此步骤只登记本机设置，不会拉取笔记。

密码或恢复码输入留空时，仅在地址、用户名和同步库 ID 均未改变的情况下保留原凭据。修改连接身份不会自动挪用旧凭据，需重新输入。已有密钥保存后，生成按钮保持禁用；如果确实要使用其它已有库，应明确填写对应 ID 和恢复码。

普通隔离资料禁用系统凭据，设置页会说明并禁止保存或生成。显式命名测试资料与日常资料使用不同凭据范围；同一资料中的不同工作区也不共用密码和恢复密钥。模型/Pi 的凭据索引不包含这些云同步密钥。

## 状态含义

| 状态 | 含义 |
| --- | --- |
| 尚未配置 | 当前工作区没有已保存的同步配置 |
| 配置已保存，缺少凭据 | 连接信息存在，需补充云端密码或恢复码 |
| 系统凭据暂不可用 | 目前无法确认凭据是否可读，原配置保留；不会误报为“缺失” |
| 隔离资料未启用系统凭据 | 当前运行方式禁止使用系统凭据，不会读取日常凭据 |
| 配置和凭据已保存，尚未同步 | 本机配置完整，尚未启动任何云端任务；不表示登录或云服务已验证 |
| 暂时无法读取状态 | 配置无法安全读取或工作区不可用，保留原文件，不当作空配置重置 |

现在没有可真实观察的暂停、网络等待、限流或远端账号失效状态，界面也不显示假的“立即同步/暂停”按钮。这些状态随 [#23](https://github.com/ax2/zicode-studio-desktop/issues/23) 的实际任务接线交付；真实云服务和两设备验证由 [#25](https://github.com/ax2/zicode-studio-desktop/issues/25) 跟踪。

## 数据保留

配置位于固定系统资料目录下独立的 `notes-sync` 子目录，按工作区摘要隔离，不随程序版本号改变。非秘密元数据只保存连接信息和凭据引用；密码和恢复密钥不写入 JSON、笔记或模型配置。

保存使用版本核对与独立锁，再原子替换当前配置；并发旧窗口需刷新后重试。成功替换前保留旧配置，成功后保留历史版本和旧凭据引用。失败清理只涉及本次新建的候选凭据，不删除旧凭据，也不更改原笔记。配置历史目前没有恢复管理界面，不将文件保留当作已交付的用户恢复操作。

总体范围与剩余冲突管理、恢复入口见 [#24](https://github.com/ax2/zicode-studio-desktop/issues/24)。
