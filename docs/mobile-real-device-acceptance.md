## TalkBack 走查指引（人工，2026-08-06）

设备已配对且会话可用时，按以下步骤人工走查（完成后把结果反馈给我记录）：

1. 开启 TalkBack：系统设置 → 无障碍 → TalkBack（打开后界面进入朗读模式）；
2. 在 Chrome 打开 ZiCode 会话页（已配对设备直接用完整会话 URL）；
3. 单指右滑依次聚焦并核对播报：
   - 顶部连接状态：应播报"已连接到你电脑上的 ZiCode"与"直连"（徽标
     `aria-label`）；离线/重连时播报对应状态与"重试"按钮；
   - 消息输入框：播报"输入消息，或使用 / 调用技能…"；
   - 发送按钮：播报"发送消息"；
   - 底部导航：对话/项目/笔记/文件/更多（当前页面提示）；
   - 消息列表：历史消息、工具卡片（"展开工具详情"）、"最新消息 ↓"按钮；
4. 验证交互：双击激活发送、双指滚动消息列表、"更多"面板打开/关闭焦点
   循环、系统返回可关闭面板；
5. 预期问题反馈项：播报顺序错乱、控件无名称、焦点丢失、双击无效。
