# 移动端真机联合验收清单

本文汇总第 42–93 轮（2026-08）各轮审计后仍待 Android/iOS 真机验证的条目，作为发布前
的联合验收执行清单。标记规则：`[ ]` 未验证，`[x]` 已验证，`[n/a]` 不适用。每项注明
首次提出该待验项的轮次，便于回溯上下文。

## 1. 系统能力与平台行为

- [ ] Android/iOS PWA 被系统实际回收后，从主屏幕重新启动的会话/草稿恢复与浏览器配额
  行为（第 42 轮前）。
- [ ] Android 系统返回键 / iOS 边缘返回手势与各历史层联动：左侧抽屉、图片选择器、插件
  移动菜单、命令面板（第 46 轮起）。
- [ ] 第三方键盘 + 惯性滚动 + 流式输出的组合行为（第 42 轮前）。
- [ ] 分屏 / 横屏 / 页面缩放的组合布局（第 42 轮前）。
- [ ] 低内存 Android/iOS 设备上 300 条历史渲染峰值与超长图片解码内存（第 42 轮前）。
- [ ] 系统级 CA 信任、后台保活、主屏幕启动（第 42 轮前）。
