# ZiCode Studio Desktop v0.5.7

本版更新内嵌 Pi 并完善 Windows 浏览器的日常使用。

- 内嵌 Pi 与扩展 SDK 更新到 1.5.2，README 同步更新。
- 新增本地阅读模式和网页选区翻译入口，保留已有翻译草稿，翻译仍需手动提交。
- 完善书签文件夹路径、嵌套搜索和键盘焦点，关闭或切换编辑前保护未保存内容。
- 支持页面缩放快捷键、数字快捷键切换标签，以及在资源管理器中定位已完成下载。
- 修复下载列表恢复后仍显示读取错误的问题，保留用户操作失败提示。

Windows 提供 x64 安装程序，macOS 提供 Apple Silicon 与 Intel DMG，Linux 提供 x64 AppImage 和 Debian 包。已有资料继续使用固定目录。请通过本页安装包升级，签名自动更新尚未开启。

视觉资产模块仍在独立开发和验收中，本版不包含其未验收入口。跨平台安装包由 GitHub 构建检查，以上浏览器新增交互主要在 Windows 验证。
