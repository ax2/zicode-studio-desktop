# v0.5.3 发布验证记录

状态：修复 v0.5.2 Unix Clippy 阻断；本地门槛和新标签发布进行中。

## 固定标签的验证历史

- v0.5.0：Windows 长路径、历史目录快照字节转换阻断；草稿未公开。
- v0.5.1：跨平台 Rust 测试的输出声明反例、Unix 归档夹具输入及 Apple Silicon 受限空间扫描阻断；草稿未公开。
- v0.5.2：Linux 与 Apple Silicon 各 665 项 Rust 测试和 1 项集成测试通过，Windows Rust 与真实 Pi/Host 检查通过；Linux 和 Apple Silicon 的严格 Clippy 发现 `ocr.rs` 中 Windows 专用导入在 Unix 未使用。草稿未公开。

- `AtomicBool` 保持跨平台导入，`Ordering`、`Duration`、`Instant` 仅在 Windows 导入；不改 OCR 行为。
- 本机 `bun run check:rust:static` 完成 Cargo check 和严格 Clippy；格式检查仍为建议级历史漂移。
- v0.5.2 本地 Release 候选曾在 1442×931 深色主题原生窗口检查工具中心，代表截图在技术博客同名阶段目录；该截图不是 v0.5.3 安装包验收。
