# ZiCode Studio Desktop v0.6.5

本版面向 Windows 10/11 x64，集中交付模型配置和 JSON 文件工具的改进。发行版本统一为 **0.6.5**，与此前沿用 0.6.4 元数据的本机开发候选区分。

## 模型选择

- 浏览器助手默认继承 Pi 的模型，也可为浏览器单独选择模型；切换不会改写聊天会话的模型。
- 视觉资产中心保留已有图像模型配置，可保存多个配置并切换使用。
- 日常资料和显式命名测试资料分别使用自己的模型凭据。普通隔离资料仍禁用凭据；命名测试资料需要同时指定 `--isolated-profile <绝对路径>` 和 `--test-profile <名称>`，不会回退读取日常凭据。

模型登记不等于已经激活真实服务。使用前需为对应资料和提供方录入有效凭据，并选择兼容模型；生成仍由用户主动发起，可能产生提供方费用。配置操作不自动发起生成。本轮已验证实际 Pi 与本机合成 HTTP 路由，没有把它当作真实供应商调用、额度或账单验收。范围与证据见 [#79](https://github.com/ax2/zicode-studio-desktop/issues/79) 和 [命名测试资料 PR #81](https://github.com/ax2/zicode-studio-desktop/pull/81)。

## JSON 文件工具

新增确认后执行的 JSON 文件格式化、压缩和校验。每份 UTF-8 输入最多 1 MiB，完整结果最多 8 MiB。原文件保持只读，保存结果需要再次确认；语法错误与不支持的深度、重复键或数值精度分别提示。

这三个入口由独立 ZiDevTools `com.zicode.devtools.json-file` 插件交付，**需要单独导入插件包**，安装或升级 Studio 本身不会自动安装该插件。已有 JSON 文件路径查询和有序/无序对比保留。候选包与结果摘要、实际 Windows Host/Worker 及 8 MiB 输出保存证据见 [#28](https://github.com/ax2/zicode-studio-desktop/issues/28#issuecomment-6967725289) 和 [插件说明](../plugins/json-file-transform.md)。本次子范围不代表全部 ZiDevTools 工具已经完整交付。

## Pi 与使用说明

继续内嵌 **Pi 1.5.2**，扩展 SDK 保持一致。2026-11-18 核对的上游最新稳定版与现有版本、摘要锁一致，因此不重复升级同一版本。README 更新浏览器、视觉资产、快捷工具、托盘和模型配置说明，明确源码功能与公开安装包的区别。[版本核对与兼容证据](../iterations/2026-11-18-pi-stable-audit.md)

## 升级与资料

仅构建和发布 Windows 安装包。通过 GitHub Release 的安装包手动升级，继续使用独立于程序版本的固定资料目录；无需迁移到新的版本目录。笔记和附件仍属于原工作区，备份时应同时保留工作区与配置目录。[数据位置说明](../desktop-persistent-data.md)

签名自动更新仍未启用，按 [#32](https://github.com/ax2/zicode-studio-desktop/issues/32) 继续推进。发布前的 Windows 安装包摘要、版本及对应源码由 [#86](https://github.com/ax2/zicode-studio-desktop/issues/86) 记录，安装包尚未形成时不宣称其已通过验证。复用各功能已验证且适用于本次源码的收据，不安排主会话例行发版后复验。

## 已知问题与后续

- 本地模型的多网页比较仍有引用与信息缺口归属不稳定的问题，已长期暂缓优化，功能和已有结果保留，见 [#78](https://github.com/ax2/zicode-studio-desktop/issues/78)。这不影响独立模型配置继续交付，也不代表所有模型回答都已验收。
- 提供方独立版的 Explorer 背景菜单可见探针读取到无效菜单句柄，专项检查仍是失败，见 [#80](https://github.com/ax2/zicode-studio-desktop/issues/80)。该路径不参与 Studio JSON 插件运行；未把失败标为通过，后续由独立专项处理。
- 其他未完成能力继续按 [GitHub Project 版本计划](https://github.com/users/ax2/projects/4/views/5) 的对应 Issue 推进，不将本次功能交付扩大为完整浏览器、视觉资产或工具目录验收。
