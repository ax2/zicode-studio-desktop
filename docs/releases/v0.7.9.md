## 工具中心

- 本地插件在安装后可继续审核、授权和启用，并从同一张卡片打开工具。目录变化时按回车重载，焦点会回到原工具。原工具已经移除时，焦点停在工具中心入口。授权或启用失败会在原卡片显示原因，可重试或保留停用。[目录与键盘 #758](https://github.com/ax2/zicode-studio-desktop/pull/758) · [授权启用 #730](https://github.com/ax2/zicode-studio-desktop/pull/730)

## 文件工具

- 文件编码检测和转换支持最多 8 MiB 输入，七种源和目标编码可分别选择。转换后回读核对文字，另存前可核对 BOM、大小与 SHA-256，输出最多 16 MiB。[编码转换与安装说明](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/iterations/2026-11-17-encoding-multi-target.md)
- JSON 文件可格式化、压缩或校验，原文件保持完整。JSON 对比支持逐份选入最多 1 MiB 的文件和精确的大整数、小数比较。YAML 与 JSON 转换会拒绝重复键或不能精确写出的数字。[JSON 文件](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/plugins/json-file-transform.md) · [JSON 对比 #714](https://github.com/ax2/zicode-studio-desktop/pull/714) · [YAML 与 JSON #705](https://github.com/ax2/zicode-studio-desktop/pull/705)

## 新增独立插件入口

- **时区工作台**支持搜索来源和目的时区，按顺序换算到最多八个目的地，显示夏令时重复或空缺，并提供逐行复制。[时区工作台 #744](https://github.com/ax2/zicode-studio-desktop/issues/744)
- **时钟备份检查**可确认读取 v1 至 v3 的本机 JSON，核对计时器、闹钟、提醒和世界时区等摘要，保留原件。[时钟备份检查](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/iterations/2026-11-26-clock-backup.md)
- **ZiDevTools 插件清单预览**可核对独立版声明式 JSON 的包身份、SHA-256 和最多 64 项工具声明。预览隐藏请求地址及正文，并保留原件。[清单预览](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/iterations/2026-11-26-plugin-manifest-preview.md)

独立插件按各工具的说明获取、核对并在插件管理安装。所需资源在工具中心按次确认。[插件获取和核验](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/plugins/devtools-public-delivery.md)

可在应用内检查更新。Windows 升级继续沿用固定资料目录。
