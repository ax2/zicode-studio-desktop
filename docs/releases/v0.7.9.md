## 工具中心

- 本地插件在安装后可继续审核、授权和启用，并从同一张卡片打开工具。目录变化时按回车重载，焦点会回到原工具。原工具已经移除时，焦点停在工具中心入口。授权或启用失败会在原卡片显示原因，可重试或保留停用。[目录与键盘 #758](https://github.com/ax2/zicode-studio-desktop/pull/758) · [授权启用 #730](https://github.com/ax2/zicode-studio-desktop/pull/730)
- 工具中心可先选择一份文件，再按名称寻找已启用的工具。选中工具后，确认共享与执行分开。离开会清掉未确认的文件。[单文件接力 #765](https://github.com/ax2/zicode-studio-desktop/pull/765)

## 文件工具

- 文件编码检测和转换支持最多 8 MiB 输入，七种源和目标编码可分别选择。转换后回读核对文字，另存前可核对 BOM、大小与 SHA-256，输出最多 16 MiB。[编码转换与安装说明](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/iterations/2026-11-17-encoding-multi-target.md)
- JSON 文件可格式化、压缩或校验，原文件保持完整。JSON 对比支持逐份选入最多 1 MiB 的文件和精确的大整数、小数比较。YAML 与 JSON 转换会拒绝重复键或不能精确写出的数字。[JSON 文件](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/plugins/json-file-transform.md) · [JSON 对比 #714](https://github.com/ax2/zicode-studio-desktop/pull/714) · [YAML 与 JSON #705](https://github.com/ax2/zicode-studio-desktop/pull/705)
- Inspect 0.1.5 可在原上限内完成已实测的密集平级数值 YAML 转换，保留高精度与重复键检查。复杂或深层文档仍可能触及原执行上限。[YAML 插件 #771](https://github.com/ax2/zicode-studio-desktop/pull/771)

## 新增独立插件入口

- **时区工作台**支持搜索来源和目的时区，按顺序换算到最多八个目的地，显示夏令时重复或空缺，并提供逐行复制。[时区工作台 #744](https://github.com/ax2/zicode-studio-desktop/issues/744)
- **时钟备份检查**可确认读取 v1 至 v3 的本机 JSON，核对计时器、闹钟、提醒和世界时区等摘要，保留原件。[时钟备份检查](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/iterations/2026-11-26-clock-backup.md)
- **ZiDevTools 插件清单预览**可核对独立版声明式 JSON 的包身份、SHA-256 和最多 64 项工具声明。预览隐藏请求地址及正文，并保留原件。[清单预览](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/iterations/2026-11-26-plugin-manifest-preview.md)
- **离线向量比较**支持确认两份 JSON 向量文件或一份包含两个向量的本机响应。可查看维度、范数、余弦相似度和欧氏距离，结果不回显向量。每份文件最多 256 KiB，另有结构复杂度限制。[离线向量比较](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/iterations/2026-11-26-offline-embedding.md)
- **批量改名预览**可确认一个目录，预览最多 64 个名称的替换、前后缀和目标冲突，保留原文件和目录。**文本流程配方检查**可查看最多 16 步的本机配方及进出材料。[改名预览](https://github.com/ax2/zicode-studio-desktop/blob/1ce8b78d72dc3c9567b9cd723acee78467c07109/docs/iterations/2026-11-25-batch-rename-preview.md) · [配方检查](https://github.com/ax2/zicode-studio-desktop/blob/1ce8b78d72dc3c9567b9cd723acee78467c07109/docs/iterations/2026-11-25-flow-recipe-inspection.md)
- **备忘备份提取 Markdown**可从一份本机备份确认另存单条普通备忘，保留原换行。**保持原尺寸转换图片**可在静态 PNG、JPEG、WebP 之间转换并另存单张图片，保留源图像素宽高，最多 1,600 万像素。[备忘提取](https://github.com/ax2/zicode-studio-desktop/blob/1ce8b78d72dc3c9567b9cd723acee78467c07109/docs/iterations/2026-11-26-memo-backup-extract.md) · [图片转换](https://github.com/ax2/zicode-studio-desktop/blob/1ce8b78d72dc3c9567b9cd723acee78467c07109/docs/iterations/2026-11-26-image-original-size-convert.md)

独立插件按各工具的说明获取、核对并在插件管理安装。所需资源在工具中心按次确认。[插件获取和核验](https://github.com/ax2/zicode-studio-desktop/blob/main/docs/plugins/devtools-public-delivery.md)

## 内置博客

- 文章编辑器可直接预览未保存的 Markdown。返回编辑会保留正文和选区，图片显示替代文字。支持 Astro 和 Hugo 文章。[草稿预览 #792](https://github.com/ax2/zicode-studio-desktop/pull/792)
- Git 推送报错后，如果原提交实际上已到达远端、另一台机器又提交了新内容，重试会识别已送达的提交，保留当前草稿。发生真正的分叉时仍提示处理。[同步恢复 #795](https://github.com/ax2/zicode-studio-desktop/pull/795)
