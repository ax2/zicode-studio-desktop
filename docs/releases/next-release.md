# 下一版本发布要求

## 视觉资产中心入口（用户要求，2026-11-12）

下一个正式版本必须包含视觉资产中心的可见、可打开入口。本次选定 v0.5.9，仅交付 Windows。0.5.7 的排除决定仅描述该历史版本，不能沿用为下一版本的排除依据。

当前开发工作区已有 `com.zicode.visual-assets` 核心应用登记、位于 Notes 之后的主侧栏入口、应用目录入口、按需加载接线及 React 构建条目。这些代码在开发工作区存在，不等于已进入发布源码或安装包；发布时必须显式纳入所需前后端代码、权限、样式和构建产物。

发布前必须完成：

- [ ] 在下一版本选定源码中核对入口登记、导航、加载器、React 功能包、Host 实现与命令权限完整，不能只加入一个空入口。
- [ ] 在实际 Windows 候选包中，普通启动后可看到中文“视觉资产”入口，无需隐藏设置或开发参数。
- [ ] 点击可打开图库，空图库有可用界面；验证样图导入、缩略图和预览，没有缺失资源或 Host 命令错误。
- [ ] 与浏览器来回切换正常，退出重开后仍可进入图库；使用隔离资料验收，不改写用户资料。
- [ ] 发布说明明确包含入口及本次可用范围，列明仍在开发的模型审核等能力；不将入口交付等同于 ADR 0008 全部完成。
- [ ] 保存候选包版本、源码修订和实际运行验收记录。若验收未通过，应修复或向用户说明缺口，不能静默移除入口后仍宣称满足本项要求。

用户随后明确授权推进下一版，在当前 Windows 实际验证通过后发布；本次据此准备 v0.5.9。非 Windows 构建仍不在授权范围。ADR 0008 的其余高级流程不作为本次已完成能力。功能范围与现有证据见[视觉资产开发记录](../visual-assets/development.md)。
