# ZiCode Studio Desktop v0.6.3

Windows x64 候选版本，正式发布前以当前 Windows 安装包和项目验收结果为准。

- 修复安装器遇到运行中的 Studio 时可能强制结束进程的问题。新安装器会停止本次操作；交互模式显示提示。旧 MSI 安装需要手动迁移，安装器不会自动调用旧卸载程序。
- 安装器覆盖升级时保留现有资料位置；实际 Windows 旧版升级、安装器及数据保留以 [#64](https://github.com/ax2/zicode-studio-desktop/issues/64) 和 [#66](https://github.com/ax2/zicode-studio-desktop/issues/66) 的验收记录为准。

其他事项见 [GitHub Project](https://github.com/users/ax2/projects/4)。
