# ZiCode Studio Desktop v0.6.2

Windows x64 候选版本，正式发布前以当前 Windows 安装包验收结果为准。

- 增加全局剪贴板翻译入口与浮窗；实际快捷键、双向翻译和结果交接仍在验证，见 [#56](https://github.com/ax2/zicode-studio-desktop/issues/56)。
- 浏览器选区导入翻译时保留页面来源。网页助手到本机模型的链路已实测，引用正确性仍待验证，见 [#57](https://github.com/ax2/zicode-studio-desktop/issues/57)。
- 改进 Windows 验收候选的资源导出；正式候选的下载与安装包清单一致性仍待验证，见 [#61](https://github.com/ax2/zicode-studio-desktop/issues/61)。

其他项目事项和最终版本范围见 [GitHub Project](https://github.com/users/ax2/projects/4)。正式发布前会核对安装、启动和固定资料的升级保留情况。
