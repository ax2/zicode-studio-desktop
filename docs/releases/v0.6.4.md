# ZiCode Studio Desktop v0.6.4

本版面向 Windows x64，发布范围由对应的 GitHub Milestone 和候选验收记录维护。

## 浏览器

- 浏览器进程或主页面渲染进程退出后保留标签及其地址、固定、缩放和静音设置。重新加载时重建失效页面。
- 后台标签右键菜单增加挂起，重新选中时恢复原控制器。音频、下载、加载中的网页和正在处理 Studio 操作的标签保持运行。

## 文件工具

- 批量文件校验支持确认后流式读取最多 64 个本机文件，显示进度并可取消。结果包含 SHA-256、SHA-512，可保存完整 JSON 报告。
- 校验清单支持从授权文件生成和按授权目录复核。报告可将原文件引用接力给编码工具，接收端确认后主动执行。
- 编码检查和转换支持最多 8 MiB 输入。转换支持 UTF-8、UTF-16 LE、UTF-16 BE、GB18030、Big5、Shift_JIS 和 Windows-1252，结果另行确认保存。
- 新增 JSON 文件路径查询、有序及无序对比。每份 UTF-8 JSON 最多 1 MiB，结果最多 8 MiB，可完整预览并另存为 `.json`。无序模式保留重复数组元素的计数。

文件工具通过独立 ZiDevTools 插件交付。当前验收使用 Files 0.2.0 候选 01、Encoding 0.4.0 候选 03、Checksum Manifest 0.2.0 候选 01、JSON File Compare 0.1.0 候选 02。每个包均带独立逐文件收据，范围和进度由 #28 跟踪。

## 笔记同步基础

持久加密传输复用已准备的密文，恢复限流等待并与本地笔记事务共同恢复合并基线。网络等待释放普通编辑所需的锁，远端返回后再次检查资料库身份和内容版本。设置、凭据和真实云端验收由 #24、#25 继续推进。

## 验收进度

当前为集成候选。原生文件对话框、实际 WebView2 故障与挂起、Windows 安装升级和资料保留由主会话统一验收。验证源码、程序及独立插件摘要见 [#70](https://github.com/ax2/zicode-studio-desktop/issues/70)。

后续需求按 [GitHub Project 版本计划](https://github.com/users/ax2/projects/4/views/5) 推进。
