## 界面布局与工具导航

视觉图库把更多空间留给图片预览，搜索保留在图片上方，语义检索、集合和备份可按需展开。邮箱、任务、笔记、自动化、设置和工具中心统一了标题、控件和间距。窄窗口打开工具时直接显示正文，桌面上的翻译和文档导入等单用途工具收回空侧栏。六种主题均提高了主按钮文字对比度，键盘操作时有清晰的焦点边框。可查看[改版截图](https://github.com/ax2/zicode-studio-desktop/tree/f76cc944/docs/evidence/ui-255)。

## 启动、浏览器与对话恢复

启动失败时，窄窗口也能读完整的错误，并用键盘打开重启指引。浏览器暂时无法读取资料时，可从错误提示直接重试并恢复保存的标签。对话中加载更早的消息会保留正在阅读的位置。

## 邮箱文件夹与离线搜索

在内置邮箱中，可以选择 Gmail 标签或 IMAP 文件夹，阅读已缓存的正文，也可以把搜索限定在当前标签或文件夹。Studio 会按账号和文件夹保存同步位置。重启后仍能离线浏览，重新连接时会核对新增、变更和移出的邮件。

## 收发附件

收到附件时，点击下载并选择保存位置。撰写邮件时，可以从本机选择附件，在草稿里核对文件名、大小或移除附件。重启后可继续编辑草稿，确认发送后才会向邮件服务传输附件。

## 获取 ZiDevTools 插件

[按需获取指南](https://github.com/ax2/zicode-studio-desktop/blob/336950b4ba77bbd2f7bb0aa3f1863807de6e94f1/docs/plugins/devtools-public-delivery.md) 列出九个可独立获取的开发插件候选，包括版本、目录和核验命令。可以只下载所需插件，在安装前逐文件核对。

## 内置 Pi 已更新至 1.6.0

Windows 版随附 Pi 1.6.0，扩展 SDK 同步更新。Studio 使用随应用提供的运行时，无需另行安装 Pi。

## 视觉资产格式验证

本次使用 PNG、JPEG 和 WebP 样本验证了引用导入和托管导入。三种格式均能生成预览，恢复后的原件逐字节一致。动画 GIF 已通过导出与回读验证。

## 图库标注与中文查询

图库支持逐图生成画幅和明暗标签，也可以配置模型扩展中文查询词。Studio 在本机根据文件名、人工标签和已确认标签排序，按结果打开图片。模型识别仍需逐图确认，建议审核后才进入索引，可以撤销机器标注。升级和备份恢复已验证人工标签与原件保留。真实模型的中文检索召回率、延迟和图像标注质量仍待验证。

## 本地 Windows 构建

本地 Debug 构建会将本次界面资源放到 EXE 实际读取的位置。再次构建时会复用内容相同的资源。
