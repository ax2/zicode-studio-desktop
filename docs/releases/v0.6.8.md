# ZiCode Studio Desktop v0.6.8

## 浏览器

可以把标签栏放在窗口左侧，用键盘调整标签顺序，把相关网页保存为命名标签组。多个浏览器窗口分别记住自己的标签和选中页；关闭后可以恢复。[窗口与标签](https://github.com/ax2/zicode-studio-desktop/issues/11)

需要同时登录两个账号时，可以新建命名浏览资料。临时浏览可使用隐私窗口。在站点设置中可以查看和撤销当前网站的权限，也可以分别清理站点存储和主机专属 Cookie。清理前需要确认，其他浏览资料和父域共享 Cookie 保留。[资料与隐私](https://github.com/ax2/zicode-studio-desktop/issues/12)

## 笔记

笔记本的排列顺序纳入同步。更改同步设置后，可以预览配置历史，确认后恢复到本机。真实 WebDAV 服务与两台实体设备之间的恢复仍在跟踪。[排序与配置恢复](https://github.com/ax2/zicode-studio-desktop/issues/118)

## 邮箱

在工具中心搜索「邮箱」即可打开或固定入口。可以管理账号并保存本地草稿，重开后仍可继续编辑。此版交付本地草稿工作流程，Gmail 和阿里邮箱的联网收发由邮箱路线图继续跟踪。[邮箱入口与草稿](https://github.com/ax2/zicode-studio-desktop/issues/114)

## Windows 验收范围

本期完成清单包含对已有功能补做的实测，包括托盘直达工具、窄窗与窗口恢复、剪贴板快捷翻译。对应事项保留了各自的实测版本和结果。[快捷工具](https://github.com/ax2/zicode-studio-desktop/issues/30) · [窗口与托盘](https://github.com/ax2/zicode-studio-desktop/issues/35) · [快捷翻译](https://github.com/ax2/zicode-studio-desktop/issues/56)
