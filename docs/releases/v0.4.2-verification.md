  使用认证的草稿查询；只兼容已观测的文件名空格转点并拒绝歧义；
  保留架构、版本、大小和 SHA-256 检查。
- macOS 使用临时配置添加 `beforeBundleCommand`，先检查 relay 架构并 ad-hoc 签名，
  再由 Tauri 签名应用；打包后完整应用 deep/strict 验证和包内 Pi/Bun 启动作为门槛。
  发布基础设施与应用分别绑定 workflow SHA 和 release SHA，不改变应用标签。
- 相关29项脚本回归通过，lint/design 无新增 warning；模拟签名检查不代替真实 macOS 验证。
