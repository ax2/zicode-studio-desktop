# ZiCode Studio Desktop v0.6.9

## 浏览器

按住 Ctrl 点击链接，或用鼠标中键点击，可以在后台新建标签，继续阅读当前页面。右键菜单可选择在前台或后台打开。普通新窗口和具名登录窗口仍会切到前台。[后台标签 #159](https://github.com/ax2/zicode-studio-desktop/issues/159)

网站对浏览器类型有特殊要求时，可以在浏览器选项中为当前浏览资料设置 User-Agent。设置从新开的标签页生效，已打开的页面需重新打开。清空设置即可恢复默认值。普通资料会记住这个选择，隐私窗口关闭后会清除临时设置。[浏览器身份设置 #179](https://github.com/ax2/zicode-studio-desktop/issues/179)

## 内置邮箱

从工具中心打开「邮箱」，选择阿里邮箱或 Gmail 账号。已缓存的邮件可离线阅读，回复草稿按账号保存，重启后可继续编辑。发送前可核对收件人和正文；发送结果不确定时会保留记录，避免自动重发。[邮箱路线图](https://github.com/ax2/zicode-studio-desktop/issues/135)

阿里邮箱通过 IMAP 和 SMTP 收发。Gmail 分别申请读取和发送授权。Windows 实测已覆盖本机协议交互、离线正文、账号隔离和草稿恢复；真实服务的验证范围见下方已知问题。[阿里邮箱验收](https://github.com/ax2/zicode-studio-desktop/issues/115) · [Gmail 验收](https://github.com/ax2/zicode-studio-desktop/issues/116)
