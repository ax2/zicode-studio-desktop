## 浏览器

- 浏览历史搜索失败时保留上次结果和筛选范围，分页和删除沿用正在显示的查询。Escape 可先取消清空确认。下载列表翻页保留焦点，新下载的文件会出现在列表中。
- 网页助手能读到开放式网页组件和同源内嵌页中的正文，同段的链接、强调、行内代码和标点保持原来的顺序。可选取表格、链接和识别出的图片文字加入笔记或草稿，也可以单独剪藏内嵌页中的选区。
- 同一网页可为多个 Chat 会话分别保留问题。旧预览不能交接到已切换的会话。多标签比较重新读取后需复核新的摘录。收起比较面板会取消本轮读取，所选标签保留。翻译可选择目标语言和正文范围。
- 关闭正在刷新的网页助手后，侧栏保持关闭。再次读取时可恢复该网页和对话的未提交问题。
- 网页 PDF 和 PNG 截图保存后，可从浏览器的下载列表查找原件。PDF 阅读支持按页跳转和页内查找，网页和 PDF 的缩放设置分别生效。阅读模式在改变窗口宽度时保留阅读位置。
- 站点设置确认显示目标范围、进度及失败反馈。权限列表读取失败时，可留在重试按钮继续用键盘操作。
- 标签搜索处理输入法确认按键时保留输入焦点。页内查找中，回车会激活当前聚焦的按钮。输入框里用回车和 Shift+回车切换匹配。切换界面语言时，地址栏和导航控件随之更新。

## 其他改进

- 本地插件重装时按已核验的发布者或包来源决定是否保留上一次授权。来源变化或请求新增权限时会重新审核。
- 本地只读存储检查更快，继续显示不完整的扫描项。
- 工具中心补齐多项文件导入、处理和保存流程，包括 JSON 字符串转义和还原、文本统计、Base64、SQL 以及数据合并。各工具在入口显示其支持的文件和处理范围。

## Windows 升级

可从应用内检查和安装更新。已有笔记、书签和其他本地资料继续使用原有资料位置。
