## 浏览器

- 浏览历史搜索失败时保留上次结果和筛选范围，分页和删除沿用正在显示的查询。Escape 可先取消清空确认。下载列表翻页保留焦点，新下载的文件会出现在列表中。
- 网页助手能采集开放式网页组件和同源内嵌页中的正文、可见链接、表格和图片资料。同段的链接、强调、行内代码和标点保持原来的顺序。可选取表格、链接和识别出的图片文字加入笔记或草稿，也可以单独剪藏内嵌页中的选区。
- 同一网页可为多个 Chat 会话分别保留问题。旧预览不能交接到已切换的会话。多标签比较重新读取后需复核新的摘录。收起比较面板会取消本轮读取，所选标签保留。读屏软件可以识别比较区域的展开状态。切换到笔记保存时，比较区域会同步收起，已选标签保留。将单页总结、问答或多页比较存入笔记和产物时，保留实际分享正文或选区的截短提示。翻译可选择目标语言和正文范围。
- 关闭正在刷新的网页助手后，侧栏保持关闭。再次读取时可恢复该网页和对话的未提交问题。
- 网页 PDF 和 PNG 截图保存后，可从浏览器的下载列表查找原件。PDF 阅读支持按页跳转和页内查找，网页和 PDF 的缩放设置分别生效。阅读模式在改变窗口宽度或字号时保留阅读位置。
- 站点设置确认显示目标范围、进度及失败反馈。权限列表读取失败时，可留在重试按钮继续用键盘操作。
- 输入法候选按键会留在标签搜索、页内查找和代理设置对应的输入框中。页内查找中，普通回车会激活当前聚焦的按钮。输入框里用回车和 Shift+回车切换匹配。切换界面语言时，地址栏和导航控件随之更新。

- 浏览器菜单可以打开明确选取的本机 PDF，每个文件最多 64 MiB。文档在临时标签中查看，关闭标签即释放；浏览历史和启动恢复不保存本机 PDF。
- 页内查找暂时读取失败后，会恢复同一查询的匹配计数。确认有效的上一处和下一处按钮保持可用。
- 多页比较结果直接显示每份已审核正文或选区的截短状态，收起审核区后仍可查看。

- 网页剪藏读取笔记本或保存失败时，键盘焦点会回到原操作，可直接重试。笔记本、标题和剪藏范围保留。

## 其他改进

- 本地插件重装时按已核验的发布者或包来源决定是否保留上一次授权。来源变化或请求新增权限时会重新审核。
- 本地只读存储检查更快，继续显示不完整的扫描项。
- 工具中心补齐多项文件导入、处理和保存流程，包括 JSON 字符串转义和还原、文本统计、Base64、SQL 以及数据合并。各工具在入口显示其支持的文件和处理范围。

## Windows 升级

可从应用内检查和安装更新。已有笔记、书签和其他本地资料继续使用原有资料位置。
