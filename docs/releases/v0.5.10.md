# ZiCode Studio Desktop v0.5.10 — Windows 候选

此版本仍为草稿候选。须完成安装包来源校验、真实 Windows 运行与升级保留验收后，才能公开发布和设置 Latest。

本版整合以下修复：

- 浏览器窄窗口中的原生文件选择：修正网页边界，并在极窄窗口提供全屏入口。选择文件仍需显式提交，不会自动上传。
- 笔记：通知不再挡住保存按钮；移动笔记后保留附件与快捷入口，带来源记录的旧链接可继续定位；中断移动可恢复；折叠多级笔记本后键盘导航跳过隐藏条目。
- 备份：确认恢复后在下一次启动离线执行，保留恢复前资料和持久恢复记录；失效请求可明确撤销，关闭确认窗口默认保留请求。

继续保留 v0.5.9 已交付的视觉资产中心入口、图库导入和预览。人物换装、风格转换及通用图像生成仍在 v0.6.0 计划中，不计入本版完成范围。

仅提供 Windows x64 安装包。固定数据位置不随版本改变；安装包升级与普通启动路径仍须在本候选中验证。自动更新签名未配置，发布后仍使用手动安装方式。

验收与剩余范围见 [候选验证记录](https://github.com/ax2/zicode-studio-desktop/blob/v0.5.10/docs/releases/v0.5.10-verification.md)、[Project #4](https://github.com/users/ax2/projects/4) 以及 #5、#7、#22、#31。
