# ZiCode Studio Desktop v0.5.6

本版继续完善 Windows 内置浏览器。已有应用资料沿用固定目录，安装升级后可继续使用原有笔记和浏览资料。

## 新增与改进

- 下载面板支持确认、保存、取消、失败重试和移除历史记录。按文件名或来源网址搜索完整历史，保留分页和已下载文件。
- 浏览器可在地址栏直接搜索，可选择搜索引擎。支持固定标签、查找标签、显示网站图标、全屏、关闭标签恢复，以及更紧凑的标签切换和关闭操作。
- 窗口控件移到共用顶栏，窄窗口恢复位置经过调整。网页右键菜单提供书签、下载、前进后退等操作，并复用原生菜单项。
- 书签支持 HTML 导入与导出，书签和历史可在后台标签打开。历史支持记录网页内部的地址变化。
- 可将已审阅的正文或选区保存为笔记并保留来源，也可将多个已加载页面的内容整理到未发送的 Pi 对话草稿。

## 平台与安装

- Windows 提供 x64 安装程序。内置浏览器使用 WebView2。登录弹窗回传和视觉资产中心继续开发。
- macOS 提供 Apple Silicon 和 Intel 安装包，Linux 提供 x64 AppImage 与 Debian 安装包。
- 请通过本页安装包升级。签名自动更新尚未开启。
