# ZiCode Studio Desktop v0.5.4

本版汇集 Windows 日常使用改进和内置浏览器的首批可用功能。应用数据使用固定资料目录，版本更新不切换笔记资料库。

## 主要变化

- Windows 内置多标签浏览器，支持地址导航、历史记录、收藏、标签排序、最近关闭恢复、页面查找、缩放及静音；默认进入浏览器，可在设置中调整。
- 修复网页被应用界面覆盖而空白的问题。打开收藏、菜单或命令面板时保留当前页面图像，关闭后恢复同一网页；扩展原生右键菜单。
- 紧凑的共用顶栏；快捷工具与连接状态移至左侧。工具可直接进入并在标签上关闭，隐藏日常使用中的项目和场景层级。
- 改进笔记编辑稳定性、长标题显示、悬停操作、笔记本排序和展开状态，以及保存冲突恢复。跨笔记本移动同时保留附件，并拒绝覆盖目标已有附件。
- 改进 Windows 托盘、关闭后恢复窗口、硬件信息展示和快捷翻译；温度采集仍需用户显式启用及本机支持。
- 扩展独立工具插件的本地接入、结果查看、文件校验及导出工作流。

## 使用范围

- 内置网页浏览使用 Windows WebView2；macOS 和 Linux 的内置网页引擎尚未交付。
- 下载管理仍在开发，本版继续阻止网页下载。网站权限、多账号、复杂登录弹窗、完整浏览器扩展和 AI 自动操作不在本版已验收范围。
- 网页正文和选区可提取、预览，并由用户放入对话草稿；不自动发送给模型。云端笔记同步尚无完整可用的设置流程。
- 工具目录中的局部能力通过不代表全部工具完整验收，范围见 [工具接入清单](https://github.com/ax2/zicode-studio-desktop/blob/v0.5.4/docs/plugins/devtools-all-tools.md)。
- Windows 安装程序尚未做 Authenticode 签名，macOS 尚无 Developer ID 公证；签名自动更新未开启，请使用发布页安装包更新。

本版保留现有资料目录选择。升级前后的实际数据核对和各平台构建结果另存发布验收记录；未完成的功能不会因版本发布而计为验收完成。
