# ZiCode Studio Desktop v0.6.1

Windows x64 版本。

- 新的工具启动器支持搜索、分类浏览、收藏与最近使用。翻译默认出现在常用工具首位，也可从托盘和快捷键打开。
- 翻译工作台支持从浏览器选区导入、取消等待和重试。替换已有草稿前会请求确认。
- 网页助手在宽窗并排显示，在窄窗放到网页下方。可预览来源，把当前页问题、总结或多标签比较送入 Chat 草稿。发送由你确认。
- 视觉资产中心新增人物换装、风格转换、文生图和图生图。生成结果可先审核再保存，保留原图与生成来源。

后续单独跟进全局剪贴板翻译浮窗、浏览器助手的模型引用复验及翻译来源标记、工具结果另存补验、视觉服务商账单与后台性能测量。已有入口和本版行为的验证进度见 [GitHub Project](https://github.com/users/ax2/projects/4)。

使用下方 Windows x64 安装包手动升级。升级前先保存正在编辑的内容并退出旧 Studio。应用沿用固定资料位置。
