# ZiCode Studio Desktop v0.5.1

本版汇集 v0.4.2 之后的开发成果，并修复首次 v0.5.0 发布构建中暴露的跨平台源码检出问题。v0.5.0 未公开发布；功能范围与详细边界见 [v0.5.0 阶段说明](v0.5.0.md)。

## 本次变化

- 内嵌 Pi 更新到锁定的 1.3.0，改进工作区、工具中心、命令面板、插件按需加载、结果传递、托盘和 Windows 资源管理器入口。
- 对历史 Zi DevTools 目录快照保留原始字节，使其在 Windows、macOS 与 Linux 检出后均可通过来源哈希校验。
- Windows 发布工作流在检出深层冻结插件夹具前启用 Git 长路径支持。

## 验收边界

- Zi DevTools 全目录目标为 154 项，正式完整接收仍为 **0/154**；逐项原因见[接入清单](../plugins/devtools-all-tools.md)。JSON Object 候选按用户决定保持禁用。
- ZiFile 独立插件目标为 108 项，正式完整接收仍为 **0/108**；见[接口与范围](../plugins/desktop-entry-zifile.md)。
- Windows 原生界面有部分实际验证；其他平台的人工使用、提供方算法等价性、正式插件签名和完整跨工具工作流仍待验收。
- Windows 安装包未做 Authenticode 签名；macOS 使用 ad-hoc 签名，尚无 Developer ID 签名与公证。签名自动更新尚未启用。

发布资产由工作流提供 Windows x64 NSIS 安装 EXE、macOS Apple Silicon/Intel DMG，以及 Linux x64 AppImage/DEB。本地 Windows 保留完整 `target/release` 运行目录和 EXE，不生成应用 ZIP。
