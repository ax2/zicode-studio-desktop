# v0.5.2 发布验证记录

状态：修复 v0.5.1 Rust 门槛失败；本地定向验证和新标签发布进行中。

## 前两个固定标签的结果

- v0.5.0：Windows 首次检出因冻结夹具路径过长失败；Linux/Apple Silicon 因历史目录快照字节转换而来源哈希失败。草稿未公开。
- v0.5.1：Windows、Linux 与 macOS 前端和快照检查通过；Rust 测试中，过时输出声明反例在各平台失败，Linux 的归档进程测试报 `worker_protocol_error`，Apple Silicon 的限额空间扫描测试漏列 Debug 分支。草稿未公开。

## v0.5.2 修复

- 将不合法 `additionalProperties` 反例改为数组，保留当前允许对象子声明的协议行为。
- Unix 归档测试进程读取完请求输入后再输出固定事件流，避免未消费输入触发管道错误。
- 空间扫描每轮目录批次由 64 缩至 32，让限额预算下的 Debug 与 Release 分支均有机会获得样本。
