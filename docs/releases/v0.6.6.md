# ZiCode Studio Desktop v0.6.6

本版面向 Windows 10/11 x64，增加手动笔记云同步和网页分析产物保存，并改进浏览器、更新入口与系统信息。

## 笔记云同步

- 在设置的“笔记云同步”登记 HTTPS WebDAV 地址、用户名和同步库 ID，将密码与恢复密钥保存在独立的 Windows 系统凭据中。日常资料和命名测试资料各自保留配置与凭据，保存配置不会开始同步。[配置入口 #97](https://github.com/ax2/zicode-studio-desktop/pull/97)
- 点击“立即同步”，核对已保存的目标后确认，才开始同步已保存的笔记本、笔记、附件和删除记录；草稿及 Studio 凭据留在本地。可取消当前任务，并区分连接失败、凭据失效、限流、冲突和配置变化。[操作入口 #100](https://github.com/ax2/zicode-studio-desktop/pull/100) · [任务接线 #102](https://github.com/ax2/zicode-studio-desktop/pull/102) · [同步队列 #23](https://github.com/ax2/zicode-studio-desktop/issues/23)
- 同步等待网络时仍可编辑和保存；旧结果不会覆盖期间的新编辑。离开设置不会取消任务，退出 Studio 会停止本次任务，重启后需再次手动发起，复用已保存的待同步队列。

第二台设备需使用相同的库 ID 和恢复码。真实云服务及两设备验收继续由 [#25](https://github.com/ax2/zicode-studio-desktop/issues/25) 跟踪；本次采用合成笔记库和本机 WebDAV 验证，不宣称已完成真实服务验收。冲突保留双方改动，冲突处理界面仍待后续完善。[云同步使用说明](../notes/cloud-sync-settings.md)

## 浏览器与窗口

- 已有网页摘要或分析可主动保存到产物中心，并重新打开。产物保留回答、页面标题、URL 和时间；保存过程不再次读取网页或调用模型。保存失败可重试，切换模型配置失败时也保留已有回答和对应模型身份。[#101](https://github.com/ax2/zicode-studio-desktop/pull/101)
- 标签菜单支持输入首字定位；使用输入法和修饰键时保留原有键盘操作。[#88](https://github.com/ax2/zicode-studio-desktop/pull/88)
- 摘录长网页时保留完整字符，选区达到长度上限时显示缩短提示。[#91](https://github.com/ax2/zicode-studio-desktop/pull/91)
- 浏览网页时默认关闭 WebView2 通用表单自动填充，仍可手动填写表单。[#96](https://github.com/ax2/zicode-studio-desktop/pull/96)
- 可用键盘在窗口控制按钮之间移动。窄窗从“更多”打开命令面板后，按 Esc 把焦点还给可见入口。[#90](https://github.com/ax2/zicode-studio-desktop/pull/90)

## 更新与系统信息

- 手动更新入口直达最新公开稳定版。切换渠道、检查失败或没有可安装更新时，清除过期的安装按钮与发行说明。[#92](https://github.com/ax2/zicode-studio-desktop/pull/92)
- Windows 时钟大幅回拨后，系统信息图表从新的时间继续采样。[#93](https://github.com/ax2/zicode-studio-desktop/pull/93)

## 从公开版本升级

v0.6.3～v0.6.5 此前仍为发行草稿。本版同时包含这些集成改动，详情见 [v0.6.3](v0.6.3.md)、[v0.6.4](v0.6.4.md) 和 [v0.6.5](v0.6.5.md) 的历史范围及验证记录。文件校验、编码和 JSON 文件工具由独立 ZiDevTools 插件交付，需要单独导入对应插件包；升级 Studio 不会自动安装插件。

## 升级与后续

通过 GitHub Release 安装包手动升级，继续使用独立于程序版本的固定资料目录；笔记、附件和配置无需迁移到新的版本目录。[资料位置](../desktop-persistent-data.md)

本版仅构建 Windows x64。安装包、源码与摘要以 [#98](https://github.com/ax2/zicode-studio-desktop/issues/98) 的实际记录为准；签名自动更新继续由 [#32](https://github.com/ax2/zicode-studio-desktop/issues/32) 跟踪。

本地模型多网页比较的引用及缺口归属优化仍长期暂缓，功能与已有结果保留，见 [#78](https://github.com/ax2/zicode-studio-desktop/issues/78)。其他未完成的浏览器、视觉资产和工具能力继续按 [GitHub Project](https://github.com/users/ax2/projects/4) 的对应事项推进，本版不代表这些模块已完整验收。
