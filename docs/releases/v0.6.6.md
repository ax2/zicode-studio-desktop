# ZiCode Studio Desktop v0.6.6

## 笔记

设置中新增“笔记云同步”。可以登记 WebDAV 地址、用户名和同步库 ID，并将密码与恢复密钥保存到 Windows 系统凭据库。第二台设备接入同一笔记库时需要相同的库 ID 和恢复码。日常资料与命名测试资料各自保留连接配置及凭据；保存配置不会连接云服务。实际传输和取消由 [#23](https://github.com/ax2/zicode-studio-desktop/issues/23) 跟踪。[配置交付 #97](https://github.com/ax2/zicode-studio-desktop/pull/97)

## 浏览器与窗口

- 标签菜单支持输入首字定位；使用输入法和修饰键时保留原有键盘操作。[#88](https://github.com/ax2/zicode-studio-desktop/pull/88)
- 摘录长网页时会保留完整字符，选区达到长度上限时会显示缩短提示。[#91](https://github.com/ax2/zicode-studio-desktop/pull/91)
- 浏览网页时默认关闭 WebView2 通用表单自动填充，仍可手动填写表单。[#96](https://github.com/ax2/zicode-studio-desktop/pull/96)
- 用键盘可以在窗口控制按钮之间移动。窄窗从“更多”打开命令面板后，按 Esc 会把焦点还给可见入口。[#90](https://github.com/ax2/zicode-studio-desktop/pull/90)

## 更新与系统信息

- 手动更新入口直达最新公开稳定版。切换渠道、检查失败或没有可安装更新时，会清除旧版安装按钮与发行说明。[#92](https://github.com/ax2/zicode-studio-desktop/pull/92)
- Windows 时钟大幅回拨后，系统信息图表会从新的时间继续采样。[#89](https://github.com/ax2/zicode-studio-desktop/issues/89)

本版发布目标为 Windows x64。软件签名自动更新继续由 [#32](https://github.com/ax2/zicode-studio-desktop/issues/32) 跟踪，安装包和公开发行状态见 [#98](https://github.com/ax2/zicode-studio-desktop/issues/98)。
