# ZiCode Studio Desktop v0.5.0

ZiCode Studio Desktop 是持续开发中的跨平台个人开发者平台。本版汇集 v0.4.2 之后的工作区、插件、工具与桌面入口改进。

## 本次变化

- 内嵌 Pi 更新到锁定的 1.3.0，并同步 Studio 扩展 SDK；各平台使用对应的内嵌运行资产。
- 工具中心与命令面板支持具体工具和应用分层查找、来源和分类筛选、收藏、最近使用及按需打开。工具目录可以展示插件的 View 操作入口；打开操作后仍由当前插件页面确认定位。
- 扩展插件权限、安装预览、清单与版本复核、Worker 隔离、超时与取消处理。工具结果可在用户明确确认后传递到其他工具或保存；新增文本、图片、JSON 与资源结果的接收支持。
- 增加工具模式、托盘生命周期与 Windows 资源管理器文件和文件夹入口。文件路径只作为启动意图，读取、执行和写入仍由 Studio 可信界面逐步确认。
- 改进项目存储、任务中心及后台插件任务的状态展示；命令面板打开插件工具失败时显示安全的错误提示。

## 验收边界

- Zi DevTools 全目录目标是 154 项，现有冻结候选完成了部分 Host、Worker、Pi 与界面验证，正式完整接收仍为 **0/154**；逐项缺口见[接入清单](../plugins/devtools-all-tools.md)。JSON Object 候选遵从用户决定保持禁用。
- ZiFile 通过独立插件接入的目标仍在推进，完整接收为 **0/108**，详见[接口与范围](../plugins/desktop-entry-zifile.md)。
- Windows 原生界面已有部分路径的实际验证；macOS/Linux 的人工使用、全部提供方算法等价性、正式插件签名与完整多工具工作流仍需继续验收。各平台构建以本标签的 Actions 记录为准。
- Windows 安装包未做 Authenticode 签名；macOS 使用 ad-hoc 签名，尚无 Developer ID 签名与公证。签名自动更新尚未启用。

发布资产按现有工作流提供 Windows x64 NSIS 安装 EXE、macOS Apple Silicon/Intel DMG，以及 Linux x64 AppImage/DEB。本地 Windows 保留完整 `target/release` 运行目录和 EXE，不生成应用 ZIP。
