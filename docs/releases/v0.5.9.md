# ZiCode Studio Desktop v0.5.9

本版面向 Windows x64，新增视觉资产中心的完整入口，并改善浏览器下载管理。

- 左侧笔记下方提供“视觉资产”入口，应用目录也可打开。包含本地图库、图片导入、缩略图与预览所需的界面、Host、权限和功能包；首次打开时按需加载。
- 下载状态更新现在能覆盖最近 100 条历史之外的旧下载，避免结束后仍显示“下载中”。较旧轮询结果不会覆盖新的状态。
- 下载操作切换、失败及记录移除后保留合理的键盘焦点，不覆盖用户主动转到搜索框的焦点。
- 修复 Windows CI 的 JSON 插件验收输入，继续使用完整冻结收据核验。
- 视觉资产 Worker 使用项目统一的 Windows 子进程启动接口，并保留受限 Job、超时与输出限额。
- 内嵌 Pi 保持 1.5.2。固定数据目录不随版本号变化；无需迁移现有笔记和其他资料。

视觉资产中心是长期核心模块。模型确认、审核与来源查看等高级流程仍在开发；本版入口交付不代表全部 ADR 0008 规划完成，不自动调用收费模型。

本版仅构建 Windows 安装包。自动更新签名尚未启用，请使用安装包升级。发布前的候选安装包与实际 Windows 验收证据另见本版验证记录。
