# ZiCode Studio Desktop v0.6.7

## 软件更新

- 手动打开 GitHub 下载页或检查版本时可以继续工作。有可安装更新或安装正在进行时，设置页才提示先保存工作。[#106](https://github.com/ax2/zicode-studio-desktop/pull/106)
- 支持进度事件的下载会立即显示最新收到的数据。服务端没有提供总大小时，显示下载状态。[#107](https://github.com/ax2/zicode-studio-desktop/pull/107)

## 笔记备份与恢复

在笔记的「数据管理」中选择「导出全部笔记本备份」，可保存正文、回收站笔记和附件。如果其中任何一项无法完整读取，Studio 会报告失败。备份是明文 JSON，请保存在自己控制的位置。导入时会新建笔记本，保留原有内容。[恢复步骤和大小限制](https://github.com/ax2/zicode-studio-desktop/blob/v0.6.7/docs/notes/local-backup-and-recovery.md)

已在 Windows 隔离资料中分别从 JSON 和离线目录副本恢复，并逐字节核对附件。真实云服务的双设备恢复仍由 [#25](https://github.com/ax2/zicode-studio-desktop/issues/25) 跟踪。

## 笔记同步冲突

手动同步发现冲突时，可逐项查看本机和远端版本，选择保留本机、远端或双方。确认后，选择只保存在本机；需要上传时，再手动同步一次。[冲突管理 #24](https://github.com/ax2/zicode-studio-desktop/issues/24)

## 从早期公开版本升级

此版本线包含手动笔记同步、网页分析保存及此前的浏览器改进。笔记同步需先配置 WebDAV，再确认同步目标。已有网页摘要和分析可以直接保存到产物中心。升级继续使用原有固定资料位置。[v0.6.6 功能说明](https://github.com/ax2/zicode-studio-desktop/blob/v0.6.6/docs/releases/v0.6.6.md) · [资料位置](https://github.com/ax2/zicode-studio-desktop/blob/v0.6.6/docs/desktop-persistent-data.md)

本版面向 Windows x64。[备份恢复 #25](https://github.com/ax2/zicode-studio-desktop/issues/25) · [发布计划 #108](https://github.com/ax2/zicode-studio-desktop/issues/108)
