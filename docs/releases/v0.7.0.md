# ZiCode Studio Desktop v0.7.0

## 离线搜索邮件

在工具中心打开「邮箱」，输入发件人、主题或已下载正文中的文字。默认搜索当前账号的收件箱，也可以选择所有本地账号。结果显示发件人和所属账号，点开即可阅读已缓存的正文。仅缓存邮件摘要时，结果会提示正文尚未下载。搜索和打开缓存均可离线使用。[邮箱搜索 #117](https://github.com/ax2/zicode-studio-desktop/issues/117)

关闭邮箱连接时，默认保留已下载的邮件供离线阅读。也可以在断开连接时或之后，单独清理这个账号的本机缓存。清理前会要求确认，草稿、投递记录和其他账号的邮件都会保留。

## 制作 GIF 动图和文字表情包

在视觉资产的动画面板排好帧并预览，在导出格式中选择 GIF。图集和多张图片组成的帧序列均可导出。GIF 会保留循环或单次播放设置，帧时长按 10 毫秒取整，最短 10 毫秒。低于 50% 不透明度的像素会变为透明，其余像素显示为不透明。导出保留原始图片。[动画导出 #43](https://github.com/ax2/zicode-studio-desktop/issues/43)

制作表情包时，可输入多行中英文配文，从三种位置和三档字号中选择，然后预览文字在动画各帧上的效果。导出的 GIF 和恢复后的动画任务都会保留配文。

## Windows 终端

关闭终端时，Studio 会等待该终端启动的进程退出，再报告关闭成功。如果进程未能及时退出，界面会提示关闭失败。[终端进程退出 #200](https://github.com/ax2/zicode-studio-desktop/issues/200)
