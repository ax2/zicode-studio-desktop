## 文件工具与另存

文件摘要、校验清单、文件编码、JSON 文件查询与对比、JSON 文件格式化可按需下载和安装。各包都有独立的核验收据，文件编码检查支持最多 8 MiB 输入。工具可经确认接力使用原文件。取消系统另存对话框后会回到保存预览，便于继续调整位置或文件名。保存结果使用独立文件，原件保留。[插件下载与校验](https://github.com/ax2/zicode-studio-desktop/blob/4f826d5c601407535654b0021a888d9eb49db14b/docs/plugins/devtools-public-delivery.md)

## Windows 托盘与软件更新

修复关闭到托盘后，左键无法恢复窗口、右键无法打开菜单的问题。常用菜单项增加彩色图标并按功能分组。系统信息改为固定入口，打开详情页后才采集硬件数据。更新提醒会查找最新公开稳定版本。

## 博客与笔记导入

从左侧打开博客并选择 Astro 站点的源码目录，即可新建编辑文章、搜索分类和标签、管理首页精选，以及核对所选文件后通过 Git 同步。Hugo 站点也可编辑使用 YAML 元数据的 Markdown 文章，管理日期、分类和标签。新建 Hugo 文章默认保存为草稿。笔记可导入 Joplin JEX、Evernote ENEX、Markdown、HTML 和 TXT。

## 网页摘录与图中文字

网页助手可独立预览可读取的同源内嵌页面，包括正文、选区、表格与来源。主页面及可读取内嵌页面中的图片可逐张使用 Windows 本机 OCR。选中识别结果后，可将文字和图片来源一并保存在网页剪藏中。

## 导航与工具界面

左侧导航改用彩色图片，缩小常态尺寸并简化轮廓，悬停时适度放大。专用工作区和内置工具的布局也已统一，Windows OCR 工具使用一致的控件间距和状态样式。

## Windows 本地构建

从 Git 链接工作树构建时，可复用主工作树已准备好的 Pi、便携 Git、Bun 和 WebView2 运行时。
