# ZiCode Studio Desktop v0.5.11 — Windows 候选

此版本仍为草稿候选，待安装包来源校验和当前 Windows 的实际升级验证完成后发布。

- 修复浏览器窄窗口中的原生文件选择器；极窄窗口可从全屏入口选择文件，上传仍需显式提交。
- 改进笔记编辑、保存提示、多级列表键盘导航、移动后的附件和来源链接恢复。
- 笔记本删除加入事务恢复：目录移动失败时回滚，重启可继续恢复；遇到外部日志变更时保留现场并报告冲突。
- 修复 Host 关闭时连接服务尚未释放的问题，使工作区关闭等待实际资源释放。
- 备份恢复在确认后的下一次启动离线执行，并保留恢复前资料和恢复记录。

保留 v0.5.9 已有的视觉资产中心入口、图库导入和预览。人物换装、风格转换和通用图像生成继续按 v0.6.0 计划推进，不属于本次交付范围。

仅提供 Windows x64 安装包。保留固定资料位置；升级、重启和备份恢复以最终安装包验证。独立测试账号中的普通资料选择和资料目录缺失两项验收，经用户明确决定暂缓，不作为本次发布阻挡，也不记作已通过。自动更新签名未配置，发布后使用手动安装方式。

v0.5.10 为未发布的失败候选，其标签和失败记录保留；本候选以新版本记录后续修复。完整范围仍按 [Project #4](https://github.com/users/ax2/projects/4) 的 #5、#7、#22、#31 执行，不移动未完成事项来绕过验收。

验证范围见 [候选验证记录](https://github.com/ax2/zicode-studio-desktop/blob/v0.5.11/docs/releases/v0.5.11-verification.md)。
