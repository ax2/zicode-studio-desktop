# 图像模型标注

图库中的每张素材都可以单独展开“图像模型标注”。当前场景的视觉资产插件需要允许网络访问。点击“载入图像模型”后从场景配置中选择支持图像输入的模型。模型配置中的 input 数组需包含 image，服务需兼容 OpenAI Chat Completions 的图像内容格式。

点击“确认发送缩略图”，在原生窗口中核对文件名、模型及服务地址后决定是否发送。每次确认限当前图片。请求包含固定中文标注指令和预览中的单张 PNG 缩略图，Host 对照界面已展示预览的 SHA-256。服务仅收到缩略图和指令，工作区路径、文件名、人工标签及原件保留在本机。

成功返回后，库中显示一份待审核建议及其模型来源。可以逐项勾选，再采纳或丢弃。采纳会替换本图上一份已采纳的模型标注；丢弃新建议保留上次采纳的结果。每张图、每个原件摘要最多保存一份草案和一份采纳记录。撤销已采纳的模型标注后，人工标签以及“本机预览标注”仍可使用。语义检索只匹配已采纳的模型标签。

备份会保存来源模型、服务源地址、时间、缩略图摘要和标签。含图像模型标注表的快照使用版本 12，恢复时需要支持此格式的 Studio。源图及缩略图遵循原图库的托管或引用策略。
