# 视觉资产中心 P0 验收原型

本轮在 Windows 调试专用入口验证托管导入。入口只接受显式给定的绝对资料目录，首次运行要求目录为空。SQLite 使用回滚日志与立即事务，串行化同一图库的恢复和写入。重复导入产生独立资产与首版修订，共享按 SHA-256 寻址的原件和缩略图。每页最多 50 条，下一页从上一页最后一个资产 ID 继续。

Worker 从暂存文件读取，Windows Job Object 限制一个子进程和 256 MiB 内存，父进程退出时终止子进程。父进程最多等待 10 秒。当前输入上限为 24 MiB、4096 × 4096，输出为最多 256 × 256 的 PNG。输入按文件头识别，仅启用 PNG、JPEG、WebP 解码。动画 PNG 和 WebP 会被拒绝。

从仓库根目录执行，复用项目 target，确保当时没有其他完整构建。

```powershell
cargo build --manifest-path src-tauri/Cargo.toml --locked --bin visual-assets-probe
pwsh -NoProfile -File docs/visual-assets/verify-probe.ps1 -Probe target/debug/visual-assets-probe.exe -Sample <本地样图>
```

验收脚本覆盖导入意图、暂存完成、仅原件发布、全部文件发布、Catalog 提交后五处进程退出，以及坏图、字节与尺寸上限、重复导入、原件摘要、跨页浏览和缩略图解码。旧原型图库首次迁移会扫描专用目录。迁移后按单笔持久导入日志恢复，普通分页不再遍历原件。该流程覆盖进程退出，系统断电和存储介质损坏需单独验收。

调试入口另提供 `backup <空的绝对目标目录>` 与 `restore <快照目录>`。备份用 SQLite 保留写锁固定 Blob 引用，在第二个只读连接上执行 `VACUUM INTO` 生成一致 Catalog，再逐份核对原件 SHA-256 和大小。Catalog 本身是完整资产/修订/Blob 清单，旁边的小型 `manifest.json` 记录格式版本、图库 ID、Catalog 摘要及资产/Blob 数量。检查完成后将暂存目录更名为 `snapshot`。当前备份会阻止图库写入，尚未接入产品后台任务或增量备份。

恢复只创建新的图库目录，拒绝覆盖已有图库；复制 Catalog 并验证摘要、完整性和外键，再核对每份原件，通过受限 Worker 重建缩略图，最后发布目录。中途失败的 `pending-*` 目录保留作为证据，不能冒充已完成快照或图库；恢复中断后可在同一个隔离资料中重新执行恢复，普通打开会先提示未完成恢复。清理或断点续传尚未实现。脚本另覆盖备份 4 处、恢复 3 处进程退出和发布后的重新打开。所有图片检查只在后台解码，不调用图片查看器。

Studio 资料目录、可信入口与受调用者约束的预览句柄已接入；正常窗口端到端验收仍待完成。仍需扩大静态格式拒绝边界与路径替换验证，将快照备份恢复接入产品，并测量 Windows 图形界面中与浏览器并用的性能。百万条元数据测试只证明分页查询方案，不能代替真实文件规模验收。后续阶段以 ADR 0008 为准。

## 2026-11-10 · Windows 验收
