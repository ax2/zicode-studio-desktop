# 移动端体验

ZiCode Studio Desktop 的移动端不是桌面三列布局的等比缩小，而是保留同一套信息
架构、一次只展示一个主要工作面。

发布前真机联合验收清单（汇总第 42–93 轮待验项）见
[移动端真机验收清单](mobile-real-device-acceptance.md)。

## 当前运行边界

当前形态是桌面 Host 加手机浏览器客户端，**不是把 Pi 安装到 Android/iOS 本地运行**。
远程访问默认关闭；用户在桌面“设置 → 远程访问”明确启用并重启后，Host 才会在私有
局域网地址启动 HTTPS/WSS。关闭状态仍只监听 `127.0.0.1`。

Pi 上游已经支持通过 Termux 在 Android 本机独立运行命令行版本；该能力不等于 ZiCode
移动端支持本机 Runtime。当前 ZiCode 不会发现、连接或管理 Termux 中的 Pi，也不会把
桌面场景、会话、凭据和插件隐式同步到它。iOS 尚无对应的本机运行方式。产品当前的
移动形态仍是：Pi 与工作区运行在受信任的桌面主机，手机作为经过配对的远程客户端。

安全远程入口的约束已经落地：非回环 WebSocket 不能伪装成桌面客户端，远程
HTTP 数据请求必须携带设备令牌，远程设备不能创建新的配对凭据，浏览器也只会向
同源 Host 请求附加令牌。外部 WebSocket Origin 必须与实际发布的 HTTPS 地址完全匹配。
配对交换限流、设备列表、最近活动时间、撤销状态和主动连接终止已经完成。

首次连接先在手机打开设置页显示的 HTTP 信任引导地址，只能获取公共 CA 证书与安装
说明；主应用和数据 API 不在该 HTTP 端口提供。安装前必须把手机页面的 CA 指纹与桌面
设置逐字核对。CA 私钥只保存在操作系统凭据库，公开证书保存在应用数据目录；服务器
叶证书按当前私有网卡地址签发，CA 身份保持稳定。

## 信息架构映射

| 桌面区域 | 手机呈现 | 交互规则 |
| --- | --- | --- |
| 导航 | 底部应用栏 | 固定对话、项目、笔记、文件和更多；点击应用同时进入该应用并打开功能区 |
| 功能区 | 左侧抽屉 | 顶部按钮或应用图标打开；遮罩、Esc 关闭；选择内容后自动关闭 |
| 主视图 | 全宽内容区 | 对话、笔记编辑器、设置内容和帮助文章保持一致的主视图语义 |
| 文件面板 | 右侧抽屉 | 不挤压主视图，保留独立关闭按钮 |

## 对话与软键盘

- 页面高度同时提供 `100vh` 回退和 `100dvh` 动态视口支持。
- Composer 位于底部应用栏之上，并尊重 `safe-area-inset-bottom`。
- 消息滚动底部安全区由 Composer 实际高度、间距和移动导航高度共同计算。
- 只有输入区保持焦点且可见视口高度缩小至少 100px 时，才判定软键盘已出现；单纯
  的自动聚焦不会误隐藏底部导航。键盘出现后读取 Visual Viewport 的高度与 `offsetTop`，
  将 Composer 放在实际可见区域底边，同时把顶部偏移和键盘遮挡量加入消息滚动安全区。
- 同时监听 Visual Viewport 的 `resize` 与 `scroll`；iOS 因输入焦点平移页面时，顶部按钮
  和 Composer 会跟随新的可见边界。失焦后清除动态偏移并恢复底部导航。
- 模型菜单在手机上使用左右安全边距和视口高度上限，避免从 Composer 向屏幕外溢出。
- 模型菜单以整个 Composer 卡片为锚点向上展开，不覆盖输入框；搜索、空状态和思考
  强度的动态文案跟随当前语言。
- 模型目录尚在请求时显示“正在加载模型”，完成后原位刷新并恢复搜索焦点；失败状态
  提供重试操作，避免把网络等待误解为未配置渠道。
- 手机“添加图片”拆分为系统拍照与相册选择；选中的大图在有界压缩完成前显示处理状态并
  锁定发送，避免文字先发送而照片丢失。预览删除按钮在触屏上保持可见的 40px 目标。

## 应用一致性

Notes、Help 和 Settings 不再各自发明一套手机导航：它们都把目录或设置项渲染到同一
功能区抽屉，把选中内容渲染到主视图。

- Notes 保留“笔记本 → 笔记”的树形层级，选择笔记后自动回到编辑器。
- Help 的目录树可以完整滚动，文章在主视图使用紧凑边距。
- Settings 在功能区使用纵向类别列表，避免桌面端横向标签样式进入窄抽屉。
- 命令面板改为底部弹层，会话搜索接近全屏显示；通知、配置编辑器、二维码和原生
  对话框都限制在安全区内。
- 命令面板和会话搜索会把 Tab / Shift+Tab 焦点保留在当前弹层中；Esc 只关闭最上层
  弹层并恢复触发控件，第二次 Esc 才关闭其后的功能区抽屉。
- 底部栏不再依赖横向滚动寻找设置和帮助。任务、自动化、金融、产物、命令、插件管理、
  设置和帮助集中在“更多”面板；面板支持遮罩关闭、Esc、焦点循环和焦点恢复。
- 远程手机在常规设置中可显式启用任务完成提醒。只有已跟踪任务从运行转为结束、页面仍
  隐藏且权限仍有效时才发送；锁屏文案不包含对话、文件名或工作区数据。

## 断点与可访问性

- `≤ 768px`：启用手机 Shell；高度不超过 520px 的粗指针设备也启用横屏手机 Shell。
- `≤ 420px`：进一步压缩 Composer 标签和插件管理卡片。
- 抽屉按钮维护 `aria-controls`、`aria-expanded`，遮罩维护 `aria-hidden`。
- 抽屉打开时 Esc 会关闭并把焦点返回触发按钮；从手机断点返回桌面时自动恢复功能区，
  避免三栏布局停留在不可操作的收起状态。
- 主要导航、目录和输入工具按钮采用 40–48px 的最小触控尺寸。
