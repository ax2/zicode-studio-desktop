# 可用性改进总览（2026-08-23）

## 用户可见的改进

### 数据安全与回收站

- 项目删除 = 应用数据进回收站（用户项目文件永不删除）；回收站支持恢复、
  彻底删除、清空，条目显示「N 天后自动清除」，超 30 天自动清理。
- 删除/恢复/清空均有本地化错误提示；全局工作区与智能收件箱不可删除。
- 工作区备份：创建/列表/恢复/删除闭环，恢复前自动先备份当前状态。

### 任务与自动化

- 任务中心产品化：定时任务（每天/间隔）、手动任务、执行模式（自动/需
  审批）、「立即运行」、编辑/归档/删除。
- 手动任务默认目标项目 = 当前工作区；无目标项目时给出明确提示。
- 自动化模板预填（每日技术简报等）、创建/编辑/删除闭环。

### 笔记与文章

- 笔记：嵌套笔记本、图标、标签、预览大纲、多选移动、拖拽、自动保存
  状态提示、回收站。
- 文章：保存状态指示（保存中/未保存/已保存时间）、中文标题 slug 兜底 +
  改进提示、Markdown 工具栏、公众号/博客发布。

### 对话与移动端

- 对话：模型下拉、思考强度、工作模式（问一问/做一做/想一想）、结果面板
  （文件/产物/变更）、「最新消息」按钮、宽表格/代码隔离滚动。
- 桌面→手机：二维码配对、relay 路由、移动端触控基线（40px 按钮）、
  返回手势、草稿加密保存。

### 新手引导与文档

- 各应用首次引导卡（CTA 均有实际行为）；帮助中心「快速开始」升级为完整
  新手路径；快捷键/界面/移动端文档与实际实现核对一致。
